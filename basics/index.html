lab1_setup ~/basics/starter

Follow Lab 1 (set up your development environment) in this web lab. Check the Python version, try interactive mode (REPL), type() and type conversion, then create and activate a virtual environment .venv.실습 1(개발 환경 준비)을 이 웹 실습실에서 따라 한다. Python 버전을 확인하고, 대화형 모드(REPL)와 type()·형 변환을 시험한 뒤 가상 환경 .venv를 만들어 활성화한다.

Steps실행 순서

  1. python3 --version

    This lab's Python is 3.14.10. Only the number differs from the 3.12.4 on the slides; what you learn is the same. On a Windows PC the command is usually python or py.이 실습실의 Python은 3.14.10이다. 슬라이드의 3.12.4와 숫자만 다를 뿐 배우는 내용은 같다. Windows PC에서는 명령이 보통 python 또는 py다.

  2. printf '%s\n' '2 + 3' 'print("hi")' 'type(3.14)' 'exit()' | python3 -i

    This feeds input into the REPL. After each >>> you see, in order, the value of the expression 5, the print output hi, and <class 'float'>. If you type just python3 yourself, the same >>> prompt appears, and exit() leaves it.REPL에 입력을 흘려 넣은 모습이다. >>> 뒤에 식의 값 5, print 결과 hi, <class 'float'>가 차례로 나온다. 직접 python3만 입력하면 같은 >>> 프롬프트가 뜨고 exit()로 나온다.

  3. python3 -c 'print(type(42), type(3.14), type("hi"), type(True), type(None))'

    The five basic data types int, float, str, bool and NoneType are printed.다섯 가지 기본 자료형 int, float, str, bool, NoneType이 출력된다.

  4. python3 -c 'print(int("42"), int(3.9), float("3.5"), float(7), str(42) + "!", bool(0), bool(""), bool(None), bool(5))'

    int(3.9) truncates rather than rounds, giving 3, and float(7) gives 7.0. Only 0, the empty string and None are False; 5 is True.int(3.9)는 반올림이 아니라 버려서 3이 되고, float(7)은 7.0이 된다. 0·빈 문자열·None만 False이고 5는 True다.

  5. python3 -u - <<'EOF' 2>&1 | grep -v -e '^Traceback' -e '^ ' print("3" + "3") print(int("3") + 3) print("3" + 3) EOF

    "3" + "3" is the concatenation 33; converted with int it is 6. Adding a string and an integer raises a TypeError, as in the last line (the start of the Traceback is hidden with grep)."3" + "3"은 이어 붙인 33, int로 바꾸면 6이다. 문자열과 정수를 더하면 마지막 줄처럼 TypeError가 난다(Traceback 앞부분은 grep으로 숨겼다).

  6. python3 -u -c 'print(int(float("3.5"))); print(int("3.5"))' 2>&1 | grep -v -e '^Traceback' -e '^ '

    "3.5" has to go through float to become the integer 3. Calling int("3.5") directly raises ValueError: invalid literal for int()."3.5"는 float을 거쳐야 정수 3이 된다. int("3.5")를 바로 하면 ValueError: invalid literal for int()가 난다.

  7. mkdir -p ~/python-week1 && python3 -m venv --without-pip ~/python-week1/.venv && ls ~/python-week1/.venv/bin

    The virtual environment folder .venv is created, and activate and python appear inside bin. This lab has no pip, so --without-pip is added. On a real PC, python3 -m venv .venv is enough.가상 환경 폴더 .venv가 생기고 bin 안에 activate와 python이 보인다. 이 실습실에는 pip이 없어 --without-pip을 붙였다. 실제 PC에서는 python3 -m venv .venv면 된다.

  8. . ~/python-week1/.venv/bin/activate which python python --version deactivate which python

    After activation, python points to ~/python-week1/.venv/bin/python; after deactivate it is /usr/bin/python again. If you activate it yourself without deactivate, (.venv) appears in front of the prompt.활성화하면 python이 ~/python-week1/.venv/bin/python을 가리키고, deactivate 뒤에는 다시 /usr/bin/python이 된다. deactivate 없이 직접 활성화해 보면 프롬프트 앞에 (.venv)가 붙는다.

The terminal in this lab plays the role of VS Code's built-in terminal (Ctrl+` / Cmd+`), and instead of the ▶ Run button you run a file with python3 filename.py. In the BusyBox shell the source command is written as . (a dot).VS Code 설치, Python 확장 설치, 인터프리터 선택, Google Colab 노트북 만들기는 브라우저 밖 실제 PC에서 하는 단계다. 이 실습실의 터미널은 VS Code의 내장 터미널(Ctrl+` / Cmd+`) 역할을 하고, ▶ Run 버튼 대신 python3 파일이름.py로 실행한다. source 명령은 BusyBox 셸에서 . 으로 쓴다.

hello ~/basics/starter

Lab 2: print Hello, World! and Hello, Python!, store your name, major and date in variables and print them with labels, then pass several values to print() to make Week 1 of 16.실습 2: Hello, World!와 Hello, Python!을 출력하고, 이름·전공·날짜를 변수에 담아 레이블과 함께 출력한 뒤 print()에 여러 값을 넘겨 Week 1 of 16을 만든다.

Steps실행 순서

  1. python3 hello.py; echo "exit=$?"

    The starter code is only comments, so it prints nothing and exits normally (exit=0). Your task is to fill in the TODOs.시작 코드는 주석뿐이라 아무것도 출력하지 않고 정상 종료(exit=0)한다. TODO를 채우는 것이 과제다.

  2. python3 ../solutions/hello.py

    Output of the sample solution. Values passed with commas, as in print("Name:", name), are separated by one space each, and the last line is Week 1 of 16.예시 답안의 출력이다. print("Name:", name)처럼 쉼표로 넘긴 값 사이에는 공백이 하나씩 들어가고, 마지막 줄은 Week 1 of 16이다.

  3. python3 - <<'EOF' print("Hello", "World") print("A", "B", sep="-") print("same line", end=" ") print("continues") EOF

    sep="-" changes the separator to give A-B, and end=" " puts a space instead of a newline, so the next print continues on the same line.sep="-"는 구분자를 A-B로 바꾸고, end=" "는 줄바꿈 대신 공백을 넣어 다음 print가 같은 줄에 이어진다.

  4. python3 - <<'EOF' name, score = "Kim", 95.5 print(f"{name} scored {score}") print(f"{score:.1f} pts") print(f"{1234567:,}") EOF

    {name} inside the f-string is replaced by its value. :.1f gives one decimal place, and :, adds thousands separators (1,234,567).f-string 안의 {name}이 값으로 바뀐다. :.1f는 소수 한 자리, :,는 천 단위 쉼표(1,234,567)다.

  5. python3 -c 'print("Hello, World!)'

    As in the experiment on the slides, leaving out the closing quotation mark gives SyntaxError: unterminated string literal, and the ^ mark points to the problem. Not a single line of the program runs.슬라이드의 실험처럼 닫는 따옴표를 빼면 SyntaxError: unterminated string literal이 나고 ^ 표시가 문제 위치를 가리킨다. 프로그램은 한 줄도 실행되지 않는다.

Fill in the TODOs with nano hello.py, press Ctrl+O (save) and Ctrl+X (exit), then run python3 hello.py again. Replace the name, major and date with your own.nano hello.py로 TODO를 채우고 Ctrl+O(저장), Ctrl+X(종료) 후 python3 hello.py로 다시 실행한다. 이름·전공·날짜는 자기 정보로 바꾼다.

calc ~/basics/starter

Lab 3: read two numbers with input(), convert them to float, and print their sum, difference, product and the quotient to two decimal places with f-strings.실습 3: 두 수를 input()으로 받아 float로 바꾸고 합·차·곱과 소수 둘째 자리까지의 몫을 f-string으로 출력한다.

Steps실행 순서

  1. printf '8\n2\n' | python3 calc.py; echo

    The inputs 8 and 2 are piped in beforehand. The starter code prints only the two prompts and no results. You can also run python3 calc.py yourself and type the numbers on the keyboard.입력 8과 2를 파이프로 미리 넣었다. 시작 코드는 두 프롬프트만 출력하고 계산 결과는 없다. 직접 python3 calc.py로 실행해 키보드로 입력해도 된다.

  2. printf '8\n2\n' | python3 ../solutions/calc.py

    The input is not shown on screen, so the two prompts run together on one line. Because the values were converted to float, a decimal point appears, as in 8.0 + 2.0 = 10.0.입력이 화면에 보이지 않아 프롬프트 두 개가 한 줄에 붙어 나온다. float로 바꿨으므로 8.0 + 2.0 = 10.0처럼 소수점이 붙는다.

  3. printf '7\n3\n' | python3 ../solutions/calc.py

    The quotient is 2.333..., but {a / b:.2f} shows it as 2.33.몫은 2.333...이지만 {a / b:.2f} 때문에 2.33으로 표시된다.

  4. printf -- '-6\n2\n' | python3 ../solutions/calc.py

    Negative numbers work as well: -4.0, -8.0, -12.0, -3.00.음수도 그대로 계산된다: -4.0, -8.0, -12.0, -3.00.

  5. python3 -c 'a, b = 7.0, 2.0; print(a // b, a % b, a ** b)'

    The three operators from the challenge: floor division 3.0, remainder 1.0, exponent 49.0. When both operands are floats, the result is a float too.도전 과제의 세 연산자: 정수 나눗셈 3.0, 나머지 1.0, 거듭제곱 49.0. float끼리 계산하면 결과도 float다.

  6. printf '8\n0\n' | python3 -u ../solutions/calc.py 2>&1 | grep -v -e '^Traceback' -e '^ '

    If the second number is 0, the sum, difference and product are printed, but the division stops with ZeroDivisionError: division by zero. Handling this is covered in the 'Files, Exceptions and JSON' chapter.두 번째 수가 0이면 합·차·곱은 출력되지만 나눗셈에서 ZeroDivisionError: division by zero로 멈춘다. 이 처리는 '파일·예외·JSON' 장에서 다룬다.

Python Overview

What Is Python?

Python was created by Guido van Rossum and first released in 1991. Its features are:

  • It is a high-level, general-purpose language. The syntax is clear and readable, and reads almost like English.
  • It is an interpreted language. Code runs line by line, with no separate compile step.
  • It is dynamically typed. You do not declare a type when you create a variable.
  • Besides a huge standard library, there are more than 500,000 packages on PyPI.
  • The current version is Python 3. Python 2 was retired in 2020.

The slides compare the same greeting in Python and Java. Python needs two lines, while Java needs a class and a main method to be declared.

# Python reads almost like English
name = "Python"
print("Hello,", name)

# Java needs a lot more to say the same
# public class Main {
#     public static void main(String[] a) {
#         System.out.println("Hello, Java");
#     }
# }

Why Learn Python?

Python is used in many fields. In data and AI, with pandas, NumPy, matplotlib, scikit-learn, PyTorch and TensorFlow, it has become the default language of data science. In web and automation, it is used for web frameworks such as Django, Flask and FastAPI, and for scripts, bots, web scraping and glue code between systems. It is also widely used in education and scientific computing, games, DevOps and cloud tooling, and is consistently #1 in language rankings.

Another important point is that its beginner-friendly syntax lets you focus on problem solving instead of language details. In this course, both the core syntax and the project use Python alone.

How Python Runs Your Code

Source code (.py) is first compiled to bytecode, and this bytecode is executed by the Python Virtual Machine. This happens automatically, so to you it feels as if the file runs directly. There are three ways to use Python.

  • Interactive mode (REPL): type python3 in a terminal and the >>> prompt appears. Enter statements one at a time and see the results instantly. Leave with exit().
  • Script mode: save the code in a file and run it with python3 file.py.
  • Notebook mode (Colab, Jupyter): code runs cell by cell, combining both styles.
$ python3 --version
Python 3.12.4

Variables and Data Types

Variables

A variable is a name that refers to a value stored in memory. It is created by an assignment of the form name = value; there is no declaration keyword. Assigning again changes the value, and can even change the type. You can also assign to several variables at once using commas.

age = 20
height = 175.5
name = "Kim"
is_student = True

age = age + 1          # 21
age = "twenty-one"     # now a string!

# Multiple assignment
x, y = 10, 20
MAX_SCORE = 100        # a constant

Variable names follow these rules:

  • Only letters, digits and the underscore (_) are allowed, and a name cannot start with a digit.
  • Names are case-sensitive. age and Age are different variables.
  • Keywords such as if, for and class cannot be used as names.
  • By convention, variables use snake_case and constants use UPPER_CASE.

Check a value's type with type(x). For example, type(3.14) gives <class 'float'>. The type decides which operations are allowed. "3" + "3" concatenates the strings into "33", but "3" + 3 tries to add a string and an integer, so it is an error (TypeError). You can check the five types and this error yourself in lab1_setup.

Input and Output

Output with print()

print() writes values to the screen. If you pass several values separated by commas, they are printed separated by one space. sep= changes the separator, and end= changes the line ending (default: newline).

An f-string (f"...") is the modern way to embed values directly in text. A variable or expression written inside braces is replaced by its value. You can also add a format specifier inside the braces: {x:.2f} gives two decimal places, and {n:,} adds thousands separators.

print("Hello", "World")          # Hello World
print("A", "B", sep="-")         # A-B
print("same line", end=" ")
print("continues")

name, score = "Kim", 95.5
print(f"{name} scored {score}")  # Kim scored 95.5
print(f"{score:.1f} pts")        # 95.5 pts
print(f"{1234567:,}")            # 1,234,567

You can see the output of this code in the hello example.

Input with input()

input(prompt) shows the prompt, waits until the user types something, and returns what they typed. The returned value is always a string, even when the user types a number. So to do arithmetic, you must first convert it with int() or float(). "3" + "4" is not 7 but the concatenation "34".

name = input("Your name: ")
print(f"Hi, {name}!")

age = input("Your age: ")
print(type(age))      # <class 'str'>
print(age + 1)        # TypeError!

age = int(input("Your age: "))
print(age + 1)        # works now

The typical pattern for reading a number is n = int(input("Number: ")).

The example steps in this lab pipe the input in beforehand, as in printf '8\n2\n' | python3 calc.py. Done this way, the values you enter are not shown on screen, so the prompts run together on one line. If you want to type the input on the keyboard yourself, run just python3 calc.py, type a value and press Enter.

Python 개요

Python이란

Python은 Guido van Rossum이 만들어 1991년에 처음 공개한 언어입니다. 특징은 다음과 같습니다.

  • 고수준 범용 언어입니다. 문법이 간결하고 읽기 쉬워 거의 영어 문장처럼 읽힙니다.
  • 인터프리터 언어입니다. 별도의 컴파일 단계 없이 코드를 한 줄씩 실행합니다.
  • 동적 타이핑 언어입니다. 변수를 만들 때 자료형을 선언하지 않습니다.
  • 방대한 표준 라이브러리에 더해, PyPI에 50만 개가 넘는 패키지가 있습니다.
  • 현재 버전은 Python 3입니다. Python 2는 2020년에 지원이 끝났습니다.

슬라이드는 같은 인사말을 Python과 Java로 비교합니다. Python은 두 줄이면 되지만, Java는 클래스와 main 메서드를 선언해야 합니다.

왜 Python을 배우는가

Python은 여러 분야에서 쓰입니다. 데이터와 AI 분야에서는 pandas, NumPy, matplotlib, scikit-learn, PyTorch, TensorFlow가 있어 데이터 과학의 기본 언어로 자리 잡았습니다. 웹과 자동화 분야에서는 Django, Flask, FastAPI 같은 웹 프레임워크와 스크립트, 봇, 웹 스크래핑, 시스템 사이를 잇는 접착 코드에 쓰입니다. 그 밖에도 교육과 과학 계산, 게임, DevOps, 클라우드 도구에 널리 쓰이며 언어 순위에서 꾸준히 1위를 차지합니다.

Python이 코드를 실행하는 방법

소스 코드(.py)는 먼저 바이트코드로 컴파일되고, 이 바이트코드를 Python 가상 머신이 실행합니다. 이 과정은 자동으로 일어나므로 사용자는 파일을 바로 실행하는 것처럼 느낍니다. Python을 쓰는 방식은 세 가지입니다.

  • 대화형 모드(REPL): 터미널에 python3를 입력하면 >>> 프롬프트가 나타납니다. 문장을 하나씩 입력하면 결과가 즉시 나옵니다. exit()로 빠져나옵니다.

  • 노트북 모드(Colab, Jupyter): 셀 단위로 코드를 실행하므로 두 방식을 섞은 형태입니다.

변수와 자료형

변수

변수는 메모리에 저장된 값을 가리키는 이름입니다. 이름 = 값 형태의 대입문으로 만들며, 선언 키워드는 없습니다. 다시 대입하면 값이 바뀌고, 자료형까지 바뀔 수도 있습니다. 쉼표를 써서 여러 변수에 한 번에 대입할 수도 있습니다.

age = 20
height = 175.5
name = "Kim"
is_student = True

age = age + 1          # 21
age = "twenty-one"     # now a string!

# Multiple assignment
x, y = 10, 20
MAX_SCORE = 100        # a constant

변수 이름에는 다음 규칙이 있습니다.

  • 문자, 숫자, 밑줄(_)만 쓸 수 있고 숫자로 시작할 수 없습니다.
  • 대소문자를 구별합니다. age와 Age는 다른 변수입니다.
  • if, for, class 같은 키워드는 이름으로 쓸 수 없습니다.
  • 관례상 변수는 snake_case, 상수는 UPPER_CASE로 씁니다.

기본 자료형

자료형예설명
int42, -7, 0정수. 크기 제한이 없습니다.
float3.14, 2.0, 1e-3실수(64비트 부동소수점)
str"hello", 'a'문자열. 작은따옴표나 큰따옴표로 감쌉니다.
boolTrue, False논리값. 첫 글자가 대문자입니다.
NoneTypeNone값이 없음을 나타냅니다.

값의 자료형은 type(x)로 확인합니다. 예를 들어 type(3.14)는 <class 'float'>입니다. 자료형에 따라 할 수 있는 연산이 정해집니다. "3" + "3"은 문자열을 이어 붙여 "33"이 되지만, "3" + 3은 문자열과 정수를 더하려 하므로 오류(TypeError)입니다. lab1_setup에서 다섯 자료형과 이 오류를 직접 확인할 수 있습니다.

입력과 출력

print()로 출력하기

print()는 값을 화면에 출력합니다. 여러 값을 쉼표로 넘기면 공백 하나로 구분해 출력합니다. sep=는 구분자를, end=는 줄 끝 문자(기본값은 줄바꿈)를 바꿉니다.

f-string(f"...")은 문자열 안에 값을 직접 넣는 현대적인 방법입니다. 중괄호 안에 변수나 식을 쓰면 그 값으로 바뀝니다. 중괄호 안에 형식 지정자를 붙일 수도 있습니다. {x:.2f}는 소수점 아래 두 자리, {n:,}는 천 단위 쉼표를 붙입니다.

print("Hello", "World")          # Hello World
print("A", "B", sep="-")         # A-B
print("same line", end=" ")
print("continues")

name, score = "Kim", 95.5
print(f"{name} scored {score}")  # Kim scored 95.5
print(f"{score:.1f} pts")        # 95.5 pts
print(f"{1234567:,}")            # 1,234,567

이 코드의 출력은 hello 예제에서 확인할 수 있습니다.

input()으로 입력받기

input(prompt)는 프롬프트를 보여 주고 사용자가 입력할 때까지 기다린 뒤, 입력한 내용을 돌려줍니다. 돌려주는 값은 사용자가 숫자를 입력해도 항상 문자열입니다. 그래서 계산하려면 먼저 int()나 float()로 바꿔야 합니다. "3" + "4"는 7이 아니라 이어 붙인 "34"입니다.

name = input("Your name: ")
print(f"Hi, {name}!")

age = input("Your age: ")
print(type(age))      # <class 'str'>
print(age + 1)        # TypeError!

age = int(input("Your age: "))
print(age + 1)        # works now

숫자를 입력받는 전형적인 형태는 n = int(input("Number: "))입니다.

이 실습실의 예제 단계는 printf '8\n2\n' | python3 calc.py처럼 입력을 미리 파이프로 넣어 실행합니다. 이렇게 하면 입력한 값이 화면에 보이지 않아 프롬프트가 한 줄에 이어 붙어 나옵니다. 키보드로 직접 입력하고 싶으면 python3 calc.py만 실행하고 값을 입력한 뒤 Enter를 누르면 됩니다.

형 변환

함수입력 → 출력참고
int()"42" → 42, 3.9 → 3실수의 소수 부분은 버립니다. int("3.5")는 오류입니다.
float()"3.5" → 3.5, 7 → 7.0정수와 숫자 문자열을 받습니다.
str()42 → "42", 3.5 → "3.5"숫자를 문자열과 이어 붙일 때 필요합니다.
bool()0, "", None → False그 밖의 값은 모두 True입니다.

산술 연산에서는 암묵적인 변환이 일어납니다. int + float의 결과는 float입니다. 반면 문자열과 숫자 사이의 변환은 프로그래머가 직접 해야 합니다. 예를 들어 "3.5"를 정수로 만들려면 int(float("3.5"))처럼 두 단계를 거칩니다. lab1_setup의 형 변환 단계에서 int(3.9)가 3이 되는 것과 int("3.5")의 ValueError를 확인해 봅니다.

실습 3: 입력과 계산

input()으로 두 수를 입력받아 합, 차, 곱, 몫을 출력합니다. 몫은 f-string으로 소수 둘째 자리까지 표시합니다.

# calc.py
a = float(input("First number: "))
b = float(input("Second number: "))
print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b:.2f}")

float()로 바꿨기 때문에 8과 2를 입력하면 8.0 + 2.0 = 10.0처럼 소수점이 붙습니다. 7과 3이면 몫 2.333...이 2.33으로 표시됩니다. 시작 코드는 두 입력을 문자열 그대로 받아 두었으므로, 이를 float로 바꾸는 것부터 시작합니다.

도전 과제는 두 가지입니다. 첫째, 정수 나눗셈 //, 나머지 %, 거듭제곱 **도 출력해 봅니다. 둘째, 두 번째 수가 0이면 어떻게 되는지 확인합니다. 합·차·곱은 출력되지만 나눗셈에서 ZeroDivisionError로 프로그램이 멈춥니다. 이 오류를 처리하는 방법은 '파일·예외·JSON' 장에서 다룹니다. 두 가지 모두 calc 예제에서 실행해 볼 수 있습니다.

실습 4: BMI 계산기

BMI는 몸무게(kg)를 키(m)의 제곱으로 나눈 값입니다. 키를 cm로, 몸무게를 kg으로 입력받아 키를 m로 바꾼 뒤 BMI를 소수 한 자리로 출력합니다.

# bmi.py
height_cm = float(input("Height (cm): "))
weight = float(input("Weight (kg): "))
height_m = height_cm / 100
bmi = weight / (height_m ** 2)
print(f"Height: {height_m:.2f} m")
print(f"Weight: {weight:.1f} kg")
print(f"Your BMI is {bmi:.1f}")

175 cm, 70 kg으로 시험하면 BMI는 22.9여야 합니다(bmi). '연산자·문자열·조건문' 장의 내용을 미리 써 보는 도전 과제로, BMI에 따라 분류도 출력해 봅니다. 아시아·태평양 기준으로 18.5 미만은 Underweight, 18.5–22.9는 Normal, 23–24.9는 Overweight, 25 이상은 Obese입니다.
