This chapter is about loops. We learn for, range() and while as ways to do the same task many times, and trace how an accumulator variable changes on each iteration and when a loop stops. Review: One Student's Result

An if statement selects which block runs. A score of 60 or more is a pass.

score = 75
if score >= 60:
    print("Pass")
else:
    print("Fail")
# Output: Pass

But what if there are 30 students? Instead of copying the same code 30 times, we repeat the same processing with a loop.

for: One Value at a Time

Place the sequence after the in that follows for. On each iteration, the next value goes into the variable. The colon and four-space indentation define the body of the loop. After the last value is processed, the loop ends and the code outside the indentation runs.

for letter in "ABC":
    print(letter)
print("Done")

# Output
# A
# B
# C
# Done

Integer Ranges with range()

range(stop) starts at 0. range(start, stop) includes start. In either case, the stop value is always left out. A range represents a sequence of integers; it is not a list.

for i in range(3):
    print(i)
# 0, 1, 2 on separate lines

for i in range(1, 4):
    print(i)
# 1, 2, 3 on separate lines

Steps & Reverse Ranges

The third argument is the step. A negative step counts backwards. If the direction does not match, the range is empty and the body never runs, and a step of 0 raises a ValueError.

for i in range(2, 7, 2):
    print(i)
# 2, 4, 6

for i in range(3, 0, -1):
    print(i)
# 3, 2, 1

for i in range(3, 0):
    print(i)
# No output

In the first steps of even_sum you can print five ranges, one per line, and also see the ValueError from range(1, 5, 0).

Accumulating a Total

Initialize the variable total, which holds the sum, before the loop. total += n is the same as total = total + n. Print the final result after the loop ends.

total = 0
for n in range(1, 6):
    total += n
print(total)
# 15

The question on the slides is "What happens if total = 0 is put inside the loop?" Then it goes back to 0 on every iteration, so only the 5 added in the last iteration remains. Run both cases in even_sum.

while: Repeat While True

while tests the condition before running the body. If the condition is false from the start, the body never runs. To end the loop, the body must change the value used in the condition.

count = 1
while count <= 3:
    print(count)
    count += 1
print("Done", count)
# 1
# 2
# 3
# Done 4

Execution Order & Infinite Loops

It proceeds in this order: initialize, check the condition, run the body, check the condition again.

countcount <= 3Action
1TruePrint 1
2TruePrint 2
3TruePrint 3
4FalseExit the loop

Without count += 1, the condition stays true and the loop never ends. Stop a running loop with Ctrl+C in a terminal, or with the Stop button in Colab. Ctrl+C also works in this lab's terminal.

break: Exit the Loop

Consider repeating input until the user asks to stop. break exits the nearest loop that encloses it. If the input is q, it skips the echo output and leaves the loop.

while True:
    text = input("Message (q: quit): ")
    if text == "q":
        break
    print("Input:", text)
print("Done")

In input_sum this code is saved to a file, and you can see the result of entering hello, hi and q in turn.

continue: Skip This Iteration

continue skips the remaining statements in the current iteration and moves on to the next iteration. When you use it in a while loop, be careful not to skip, by mistake, the update statement that makes the loop stop.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

# Output
# 1
# 2
# 4
# 5

Choosing for or while

  • To process each character in a string: for
  • To repeat a fixed number of times: for with range()
  • To repeat while a condition holds: while
  • Both loops can contain if statements.

Choose which loop to use in the following three cases and explain why. (1) Printing each character of a word, (2) reading messages until the user enters q, (3) printing the 7 times table from 1 to 9. The natural choices are, in order, for over a string, while because the end point is not known in advance, and for with range() because the count is fixed.

Nested Loops

When the outer loop chooses a group, the inner loop goes through all of its own values from start to finish for each outer value. The example below prints six pairs. Indentation decides which statement belongs to which loop.

for row in range(1, 3):
    for col in range(1, 4):
        print(row, col)
# 1 1
# 1 2
# 1 3
# 2 1
# 2 2
# 2 3

Tracing Nested Loops

Finish the inner loop completely before advancing the outer loop one step. For each new row, col starts again from 1. With 2 rows and 3 columns, the body runs six times.

Outer rowInner col values
11, 2, 3
21, 2, 3

After both loops finish, row is 2 and col is 3. A loop variable keeps the last value it received.

After printing one table, extend the program to print all the tables as well. The outer loop chooses the table, and the inner loop chooses the factor. After each table, print one empty line. Put this part after the input validation block so that it always runs.

for table in range(2, 10):
    for factor in range(1, 10):

Star Patterns: Rows & Columns

Use one outer iteration for each row. Row 1 has 1 star, row 2 has 2, and so on. print("*", end="") continues on the same line without a line break, and the print() after the inner loop ends the current row.

for row in range(1, 4):
    for col in range(row):
        print("*", end="")
    print()
# *
# **
# ***

Lab 4 Checks & Common Mistakes

  • Height 1 produces exactly one row with one star.
  • Height 4 gives four rows, 10 stars in total.
  • Height 10 gives ten rows.
  • Heights 0 and 11 print only the Invalid height message.

There are three common mistakes. Writing the outer loop as range(1, height) drops the last row. Putting print() inside the inner loop prints one star per line. Writing the inner loop as range(height) gives a square instead of a triangle. In stars you can count the stars and reproduce two of these mistakes yourself.

Common Loop Mistakes

  • range(1, 10) includes 1 through 9, not 10.
  • Initialize the accumulator before the loop.
  • Put the final summary output outside the loop.
  • A while loop needs a statement that changes the condition, or a way to exit.
  • Put the print() that ends a row after the inner loop.

Before running, predict the first iteration, the last iteration and the final output. When debugging, temporarily print the loop variable and the accumulator.
