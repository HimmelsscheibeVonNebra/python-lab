Python Overview

What Is Python?

Python was created by Guido van Rossum and first released in 1991. Its features are:

  • It is a high-level, general-purpose language. The syntax is clear and readable, and reads almost like English.
  • It is an interpreted language. Code runs line by line, with no separate compile step.
  • It is dynamically typed. You do not declare a type when you create a variable.
  • Besides a huge standard library, there are more than 500,000 packages on PyPI.
  • The current version is Python 3. Python 2 was retired in 2020.

The slides compare the same greeting in Python and Java. Python needs two lines, while Java needs a class and a main method to be declared.

# Python reads almost like English
name = "Python"
print("Hello,", name)

# Java needs a lot more to say the same

#     public static void main(String[] a) {

Why Learn Python?

Python is used in many fields. In data and AI, with pandas, NumPy, matplotlib, scikit-learn, PyTorch and TensorFlow, it has become the default language of data science. In web and automation, it is used for web frameworks such as Django, Flask and FastAPI, and for scripts, bots, web scraping and glue code between systems. It is also widely used in education and scientific computing, games, DevOps and cloud tooling, and is consistently #1 in language rankings.

Another important point is that its beginner-friendly syntax lets you focus on problem solving instead of language details. In this course, both the core syntax (weeks 1–8) and the team project (weeks 9–16) use Python alone.

How Python Runs Your Code

Source code (.py) is first compiled to bytecode, and this bytecode is executed by the Python Virtual Machine. This happens automatically, so to you it feels as if the file runs directly. There are three ways to use Python.

  • Interactive mode (REPL): type python3 in a terminal and the >>> prompt appears. Enter statements one at a time and see the results instantly. Leave with exit().
  • Script mode: save the code in a file and run it with python3 file.py.
  • Notebook mode (Colab, Jupyter): code runs cell by cell, combining both styles.
$ python3 --version
Python 3.12.4
$ python3              # interactive mode
>>> 2 + 3
5
>>> print("hi")
hi
>>> exit()
$ python3 hello.py     # script mode
Hello, World!

Check your version with python3 --version. On Windows the command is usually python or py. This web lab's Python is 3.14.10, so only the version number differs; everything you learn in this course works the same. You can try checking the version and using interactive mode yourself in the lab1_setup example.

Virtual Environments with venv

A virtual environment gives each project its own Python packages, isolated from the system. For example, even if two projects need different versions of pandas, they do not conflict. venv is built into Python, so there is nothing extra to install. Always activate the virtual environment before pip install; VS Code detects the .venv folder automatically. When you use Git, add .venv/ to .gitignore and share a requirements.txt instead.

# 1. Create (inside your project folder)
$ python3 -m venv .venv
# 2. Activate
$ source .venv/bin/activate     # macOS/Linux
> .venv\Scripts\activate        # Windows
# 3. Install packages
(.venv) $ pip install requests
# 4. Leave the environment
(.venv) $ deactivate

This lab has no network and no pip, so you cannot pip install. You can still go through creating and activating a virtual environment exactly as it is, using python3 -m venv --without-pip. After activation, the python command points to the interpreter inside .venv, and after deactivate it goes back to the original (lab1_setup). In the BusyBox shell, use the equivalent . command instead of source.

Variables and Data Types

Variables

A variable is a name that refers to a value stored in memory. It is created by an assignment of the form name = value; there is no declaration keyword. Assigning again changes the value, and can even change the type. You can also assign to several variables at once using commas.

age = 20
height = 175.5
name = "Kim"
is_student = True

age = age + 1          # 21
age = "twenty-one"     # now a string!

# Multiple assignment
x, y = 10, 20
MAX_SCORE = 100        # a constant

Variable names follow these rules:

  • Only letters, digits and the underscore (_) are allowed, and a name cannot start with a digit.
  • Names are case-sensitive. age and Age are different variables.
  • Keywords such as if, for and class cannot be used as names.
  • By convention, variables use snake_case and constants use UPPER_CASE.

Check a value's type with type(x). For example, type(3.14) gives <class 'float'>. The type decides which operations are allowed. "3" + "3" concatenates the strings into "33", but "3" + 3 tries to add a string and an integer, so it is an error (TypeError). You can check the five types and this error yourself in lab1_setup.

Input and Output

Output with print()

print() writes values to the screen. If you pass several values separated by commas, they are printed separated by one space. sep= changes the separator, and end= changes the line ending (default: newline).

An f-string (f"...") is the modern way to embed values directly in text. A variable or expression written inside braces is replaced by its value. You can also add a format specifier inside the braces: {x:.2f} gives two decimal places, and {n:,} adds thousands separators.

print("Hello", "World")          # Hello World
print("A", "B", sep="-")         # A-B
print("same line", end=" ")
print("continues")

name, score = "Kim", 95.5
print(f"{name} scored {score}")  # Kim scored 95.5
print(f"{score:.1f} pts")        # 95.5 pts
print(f"{1234567:,}")            # 1,234,567

You can see the output of this code in the hello example.

Input with input()

input(prompt) shows the prompt, waits until the user types something, and returns what they typed. The returned value is always a string, even when the user types a number. So to do arithmetic, you must first convert it with int() or float(). "3" + "4" is not 7 but the concatenation "34".

name = input("Your name: ")
print(f"Hi, {name}!")

age = input("Your age: ")
print(type(age))      # <class 'str'>
print(age + 1)        # TypeError!

age = int(input("Your age: "))
print(age + 1)        # works now

The typical pattern for reading a number is n = int(input("Number: ")).

The example steps in this lab pipe the input in beforehand, as in printf '8\n2\n' | python3 calc.py. Done this way, the values you enter are not shown on screen, so the prompts run together on one line. If you want to type the input on the keyboard yourself, run just python3 calc.py, type a value and press Enter.

Implicit conversion happens in arithmetic: int + float gives a float. Between strings and numbers, however, conversion is the programmer's job. For example, to turn "3.5" into an integer you go through two steps, as in int(float("3.5")). Lab 3: Input & Calculation

Read two numbers with input() and print their sum, difference, product and quotient. Show the quotient to two decimal places with an f-string.

# calc.py
a = float(input("First number: "))
b = float(input("Second number: "))
print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")
print(f"{a} / {b} = {a / b:.2f}")

Because the values are converted with float(), entering 8 and 2 gives a decimal point, as in 8.0 + 2.0 = 10.0. With 7 and 3, the quotient 2.333... is shown as 2.33. The starter code reads the two inputs as plain strings, so start by converting them to float.

There are two challenges. First, also print floor division //, remainder % and exponent **. Second, see what happens when the second number is 0. The sum, difference and product are printed, but the program stops at the division with a ZeroDivisionError. How to handle this error is covered in Week 5. You can run both in the calc example.

Lab 4: BMI Calculator

BMI is weight (kg) divided by the square of height (m). Read the height in cm and the weight in kg, convert the height to m, and print the BMI to one decimal place.

# bmi.py
height_cm = float(input("Height (cm): "))
weight = float(input("Weight (kg): "))
height_m = height_cm / 100
bmi = weight / (height_m ** 2)
print(f"Height: {height_m:.2f} m")
print(f"Weight: {weight:.1f} kg")
print(f"Your BMI is {bmi:.1f}")

Tested with 175 cm and 70 kg, the BMI should be 22.9 (bmi). As a challenge that previews Week 2, also print a category based on the BMI. By the Asia-Pacific standard, below 18.5 is Underweight, 18.5–22.9 is Normal, 23–24.9 is Overweight, and 25 or above is Obese.
