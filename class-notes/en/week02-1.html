Review: Expression, Value & Type

An Expression Produces a Value

An expression is evaluated to produce a value. The type of that value determines which operations are allowed. Before running the code, predict both the value and its type, then check with type().

print(8 + 2)              # 10
print(type(8 + 2))        # int
print(8 / 2)              # 4.0
print(type(8 / 2))        # float
print("8" + "2")          # 82
print(type("8" + "2"))    # str

Confirm that the result of / is always a float, even when both operands are integers, and that + on strings is not addition but concatenation.

Review: Input, Types & Output

input() returns a string, even for numeric input. Numeric text must be converted with int() or float() before you can calculate with it. An expression combines values and operators.

a = "12"
b = "3"
print(a + b)                  # 123
print(int(a) + int(b))        # 15

price = 12.5
quantity = 3
total = price * quantity
print(f"Total: {total:.2f}")  # Total: 37.50

Tracing Input Conversion

Treat raw as text read from input(). strip() removes surrounding whitespace, and int() creates an integer from numeric text. Converting a value does not change the original raw. With repr(), the spaces are shown as they are inside the quotes.

raw = " 12 "
clean = raw.strip()
number = int(clean)
print(repr(raw))      # ' 12 '
print(repr(clean))    # '12'
print(number + 3)     # 15
print(clean + "3")    # 123

The last two lines give different results because number is an integer and so is added, while clean is a string and so is concatenated.

Arithmetic Operators

+ and - add and subtract, and * multiplies. / performs division, // is floor division, which rounds the quotient down to an integer, % gives the remainder, and ** raises a power. Floor division rounds down, so -7 // 3 is -3, not -2. Division or remainder by zero raises an error.

a, b = 7, 3
print(a + b)     # 10
print(a - b)     # 4
print(a * b)     # 21
print(a / b)     # 2.333...
print(a // b)    # 2
print(a % b)     # 1
print(a ** b)    # 343

minutes = 135
print(minutes // 60)   # 2 hours
print(minutes % 60)    # 15 minutes

Exercise: Hours & Student Groups

Convert 185 minutes into hours and minutes, and pack 29 students into groups of 4 to find the number of full groups and the number of students left. Both calculations use // and %. The expected answers are 3 hours 5 minutes, and 7 groups with 1 student left.

minutes = 185
hours = minutes // 60
left = minutes % 60
print(hours, left)           # 3 5
print(hours * 60 + left)     # 185

students = 29
groups = students // 4
left = students % 4
print(groups, left)          # 7 1
print(groups * 4 + left)     # 29

The quotient counts complete units, and the remainder counts what is left over. Get into the habit of checking that quotient × divisor + remainder equals the original value. Repeat with 180 minutes and 28 students. You can run these calculations in operators.

Comparison Operators

== tests equality and != tests inequality. <, <=, > and >= compare sizes. Comparisons return True or False. Be careful to distinguish =, which assigns, from ==, which compares. Chaining comparisons lets you check a range at once.

score = 85
print(score == 85)          # True
print(score != 85)          # False
print(score >= 60)          # True
print(score < 60)           # False
print(0 <= score <= 100)    # True

print("85" == 85)           # False
# Convert input before comparing.

The string "85" and the integer 85 are not equal. Values read from input must be converted before comparing.

Inclusive & Exclusive Boundaries

A boundary that accepts the endpoint, like <=, is called an inclusive boundary, and one that rejects the endpoint, like <, is called an exclusive boundary. Compare the two results at 0 and 100.

score = 100
print(0 <= score <= 100)    # True
print(0 < score < 100)      # False
score = 0
print(0 <= score <= 100)    # True
print(0 < score < 100)      # False
score = 101
print(0 <= score <= 100)    # False

When testing a score range, test just below, at and just above each endpoint. This principle carries over to the boundary tests of the grade classifier in Session 2.

Logical Operators

and is true only when both conditions are true, or is true when at least one condition is true, and not reverses the truth value.

age = 20
has_id = True
print(age >= 18 and has_id)   # True
print(age < 18 or has_id)     # True
print(not has_id)             # False

n = 0
print(n != 0 and 10 / n > 2)
# False: 10 / n is never evaluated.

Boolean Results & Short-Circuiting

Summing up the four combinations: and is true only when both inputs are true, and or is false only when both inputs are false.

print(True and True)      # True
print(True and False)     # False
print(False and True)     # False
print(False and False)    # False
print(False or True)      # True
print(False or False)     # False

Once the result is already decided, Python does not evaluate the remaining operand. This is called short-circuiting. In A and B, if A is false, B is skipped. Using this, the earlier condition acts as a "guard" that keeps the later expression safe. n != 0 and 10 / n > 2 above never divides by zero, and the code below never takes text[0] from an empty string, so neither raises an error.

text = ""
print(text != "" and text[0] == "A")
# False: text[0] is not evaluated.

Precedence & Assignment Updates

** has the highest precedence, followed by * / // %, then + -. Below those come the comparison operators, then not, and and or, in that order. Use parentheses to make the intended grouping clear. +=, -= and *= update an existing variable.

print(2 + 3 * 4)        # 14
print((2 + 3) * 4)      # 20
print(-2 ** 2)          # -4
print((-2) ** 2)        # 4

score = 80
score += 5
print(score)            # 85

# Which output do you expect?
print(True or False and False)
# True

-2 ** 2 is -4 because ** is evaluated before the sign -, giving -(2 ** 2). In the last expression and comes first, so it is True or (False and False), that is, True.

Strings & Indexing

A string is a sequence of characters. The first character has index 0, and negative indices count from the end. len(text) returns the number of characters. Using an index outside the string raises an IndexError.

text = "Python"
#       012345
print(len(text))    # 6
print(text[0])      # P
print(text[2])      # t
print(text[-1])     # n
print(text[-2])     # o
# text[6] raises IndexError
# ""[0] also raises IndexError

Valid Indices & Empty Strings

For a string of length n, the nonnegative valid indices are 0 through n − 1. In a non-empty string, -1 refers to the last character. In a one-character string, the first and last characters are the same. An empty string has no valid index at all.

text = "Code"
print(len(text))    # 4
print(text[0])      # C
print(text[3])      # e
print(text[-1])     # e

text = "A"
print(text[0] == text[-1])   # True

# "Code"[4] raises IndexError.
# ""[0] raises IndexError.

In string_basics you can see that text[6] and ""[0] really do raise IndexError: string index out of range. Preventing indexing into an empty string is the key point of the string processing lab in Session 2.

String Slicing

text[start:stop] is the substring that includes start and excludes stop. If start is omitted it starts from 0, and if stop is omitted it goes to the end. The third value is the step, and [::-1] reverses the string. A slice that goes past the end does not raise an error; it simply cuts as far as the string goes.

Strings are immutable values. Changing a single character, as in text[0] = "J", is not allowed, so you build a new string with the change and assign it again.

text = "Python"
print(text[0:2])     # Py
print(text[2:])      # thon
print(text[:4])      # Pyth
print(text[::2])     # Pto
print(text[::-1])    # nohtyP
print(text[:99])     # Python

# text[0] = "J" is invalid.
text = "J" + text[1:]
print(text)          # Jython

Exercise: Reading Slices

Write the selected indices on paper first. Remember that the stop index is left out. With a positive step, if start and stop are equal the result is an empty string, and with repr() the empty result shows as two quotation marks.

text = "PYTHON"
print(text[1:4])          # YTH
print(text[:3])           # PYT
print(text[-3:])          # HON
print(text[1::2])         # YHN

print(repr(text[2:2]))    # ''
print(text[:99])          # PYTHON

String Methods & Membership

String methods do not change the original string; they return a new result.

  • strip() removes whitespace from both ends.
  • lower() and upper() change the case.
  • replace(old, new) returns the replaced string.
  • split() splits a string into a list of strings.
  • in checks whether a substring is contained. It is case-sensitive.
raw = "  Hello Python  "
clean = raw.strip()
print(clean)                          # Hello Python
print(clean.lower())                  # hello python
print(clean.upper())                  # HELLO PYTHON
print(clean.replace("Python", "AI"))  # Hello AI
print(clean.split())                  # ['Hello', 'Python']
print("Python" in clean)              # True
print("python" in clean)              # False

A Text-Cleaning Pipeline

While you are learning, storing intermediate results in variables makes it easy to check each step. strip() affects only the two ends, while replace() can also change spaces inside the string. Each method returns a new string, so the original raw value stays as it was.

raw = "  Hello Python  "
clean = raw.strip()
lowered = clean.lower()
slug = lowered.replace(" ", "-")
print(repr(raw))
# '  Hello Python  '
print(clean)      # Hello Python
print(lowered)    # hello python
print(slug)       # hello-python

Joining Text & Formatting Values

+ joins strings and * repeats them. To join a number to a string with +, you must convert it with str(). An f-string puts an expression inside braces, and .2f shows two decimal places. Before comparing user input, normalize it, for example with strip().lower().

name = "Mina"
score = 87.5
print("Hi, " + name)            # Hi, Mina
print("-" * 5)                  # -----
print("Score: " + str(score))
print(f"{name}: {score:.2f}")   # Mina: 87.50

answer = " YES "
print(answer.strip().lower() == "yes")
# True

Worked Example: A Receipt

Keep prices numeric while calculating, and format them only when showing them on screen. A format such as .2f changes only the displayed text; it does not change the number stored in total.

item = "Notebook"
price = 2.5
quantity = 3
total = price * quantity
print(f"Item: {item}")
print(f"Quantity: {quantity}")
print(f"Total: {total:.2f}")
print(total)    # 7.5, still numeric

Conditionals: if & else

if runs the indented block when the condition is true, and else runs when that condition is false. The if and else lines end with a colon (:), and each level of indentation is four spaces. The code after the block runs whichever branch was taken.

age = 17
if age >= 18:
    print("Adult")
else:
    print("Under 18")
print("Check complete")
# Output:
# Under 18
# Check complete

Tracing a Branch

Evaluate the condition before reading the branches. Exactly one of the if/else blocks runs, and the final print outside the indentation always runs. Change age to 18 and trace it again (the first step of conditionals runs both 17 and 18).

age = 17
print("Start")
if age >= 18:
    print("Adult")
else:
    print("Under 18")
print("Done")
# Start
# Under 18
# Done

Multiple Branches with elif

elif checks another condition when all the earlier conditions were false. Only the first matching branch runs, and the final else, which is optional, handles every remaining case. Grade thresholds are checked from highest to lowest.

score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(grade)    # B

Separate if Statements & elif

Separate if statements each evaluate their own condition, so several blocks can run. An if/elif chain stops at the first matching branch. Use a chain for mutually exclusive categories such as grades, and separate checks when you want to print several messages together.

score = 95
if score >= 90:
    print("A")
if score >= 80:
    print("B")
# Both A and B are printed above.

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
# Only A is printed by this chain.

Validation & Nested Conditions

Validate a value before using it. A nested if runs inside another branch. The code below uses a guard to prevent division by zero, and only when the division was done does it check again whether the result is negative.

a = float(input("First number: "))
b = float(input("Second number: "))
if b == 0:
    print("Cannot divide by zero")
else:
    result = a / b
    if result < 0:
        print("Negative result")
    print(f"Result: {result:.2f}")

In this lab we assume that numeric input arrives in the required format. How to handle input that cannot be converted to a number, such as "abc" (exception handling), comes later. In conditionals this code is run with 7, 0 and with -6, 4.

Validation Before Classification

Reject values outside the allowed range first, and keep the normal decision inside the valid case. Test negative, zero and valid positive values.

tickets = -1
if tickets < 0:
    print("Invalid quantity")
else:
    if tickets == 0:
        print("No booking")
    else:
        print(f"Booked: {tickets}")
# -1: Invalid quantity
# 0: No booking
# 2: Booked: 2

Common Mistakes

  • To test equality, use ==, not the assignment =.
  • A missing colon or wrong indentation breaks the block.
  • To compare as numbers, convert the string first.
  • "False" is a non-empty string, so bool("False") is True.
  • When you use or, compare both cases explicitly.
choice = "paper"

# Incorrect: "scissors" is truthy.
if choice == "rock" or "scissors":
    print("This always runs")

# Correct:
if (choice == "rock"
        or choice == "scissors"):
    print("Rock or scissors")

The incorrect code is read as (choice == "rock") or "scissors". Even if the left side is false, the "scissors" on the right is a non-empty string and is treated as true, so the whole condition is always true.

Debugging Exercise: A Discount

A discount should apply only to student or senior customers, but the program below applies it to every customer. Explain which part of the condition is always true, fix the condition, and test it with all three kinds of customer.

customer = "adult"
price = 100
if customer == "student" or "senior":
    price *= 0.8
print(price)    # 80.0: incorrect for adult

# Expected after repair:
# adult: 100
# student: 80.0
# senior: 80.0

The solution is to compare customer explicitly in both cases. Run the fixed code with adult, student and senior, and explain when the indented update statement runs.

customer = "adult"
price = 100
if (customer == "student"
        or customer == "senior"):
    price *= 0.8
print(price)    # 100

In conditionals you can run the code before and after the fix side by side for the three customers. Before the fix, adult also gets 80.0; after the fix, it gets 100.
