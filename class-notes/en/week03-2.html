What Is a Function?

Repeated Code, Different Inputs

The two calculations below follow the same rule; only the input values differ. A function gives such a calculation a reusable name, and the caller can pass different inputs each time it calls it.

price = 20
quantity = 3
print(price * quantity)   # 60

price = 12
quantity = 5
print(price * quantity)   # 60

Functions: A Name for a Task

A function is a named block of code that runs when it is called. The slides use a cafe analogy. Defining is writing down the recipe once, calling is placing an order so that it is made by that recipe, and reusing is ordering again with different input. The answer to the question "If you only write down the recipe, does coffee get made?" is "No." In the same way, a function does not run just because it is defined.

Function Inputs and Results

Arguments supply the input values, the function does the task, and return hands the result to the caller. For example, total_price(20, 3) returns 60. Some functions take no arguments. A function that does not explicitly return a value returns None.

Defining and Calling Functions

Defining a Function

def starts a function definition. Write the name of the task, and put the parameters inside the parentheses. The colon and indentation define the body. Defining a function does not run its body.

def greet():
    print("Hello!")
# No output until the function is called.

greet()
# Hello!

Calling a Function

Parentheses make a function call. Execution goes into the function body and, when the body finishes, comes back to where it was called. In this session's scripts, functions are defined before they are called. Each call runs the body again.

def greet():
    print("Hello!")

print("Before")
greet()
greet()
print("After")
# Before
# Hello!
# Hello!
# After

Parameters & Arguments

Parameters are the names written in the function definition, and arguments are the values the caller passes. On each call, the arguments are bound to the parameters. Inside the function, parameters behave like local variables.

def show_total(price, quantity):
    print(price * quantity)

show_total(20, 3)    # 60
show_total(12, 5)    # 60
# Parameters: price, quantity
# Arguments in the first call: 20, 3

Returning a Result

return sends a value back to the caller. The returned result can be stored in a variable or used directly in an expression. return ends the current function call right there.

def total_price(price, quantity):
    return price * quantity

amount = total_price(20, 3)
print(amount)        # 60
print(amount + 5)    # 65

Cafe Challenge: Where Is My Coffee?

Before running it, vote on what drink will hold. Will it be "Americano" or None?

def cafe():
    print("Americano")

drink = cafe()
print(drink)

Americano appears on screen, but that is only the print inside the function displaying it like an announcement; drink holds None. In the words of the slides, "you can't drink an announcement." If you change the print inside cafe() to return, the value comes back to the caller and drink holds "Americano". Run both versions in is_even.

Displaying and Returning

print() displays information on screen, and return gives a value to the caller. A function can also return a value without printing anything. If another calculation needs the result, choose return.

def show_double(number):
    print(number * 2)

def double(number):
    return number * 2

shown = show_double(4)   # Displays 8
saved = double(4)        # No output
print(shown)             # None
print(saved + 1)         # 9

Missing Return Values

A function that runs to its end without reaching a return returns None. A bare return with no value also gives None. Check that every execution path that should return a result has a return. None is a special value, not the string "None".

def broken_double(number):
    result = number * 2
    # Missing: return result

answer = broken_double(4)
print(answer)    # None
# answer + 1 would raise TypeError.

Ways to Pass Arguments

Positional & Keyword Arguments

Positional arguments bind in parameter order. Keyword arguments name the parameter directly, which makes the meaning of the call clear. In this session's functions, positional arguments come before keyword arguments.

def total_price(price, quantity):
    return price * quantity

print(total_price(20, 3))
print(total_price(price=20, quantity=3))
print(total_price(quantity=3, price=20))
print(total_price(20, quantity=3))
# Every call prints 60.

Default Parameter Values

A default supplies a value when the caller omits the argument. If the caller explicitly gives another value, it overrides the default. Put parameters without defaults before parameters with defaults. Today's examples use only simple numeric defaults.

def power(base, exponent=2):
    return base ** exponent

print(power(3))               # 9
print(power(2, 3))            # 8
print(power(5, exponent=0))   # 1

Local Variables & Scope

In this session's examples, a name assigned inside a function is a local variable. A local variable is separate from a variable of the same name outside. Pass results explicitly as return values; the functions we write today do not use global state.

number = 10

def add_one(number):
    result = number + 1
    return result

print(add_one(3))   # 4
print(number)       # 10
# print(result) would raise NameError.

The number inside the function received 3 as a parameter, but the outer number is still 10. The result created inside the function cannot be used outside once the call has ended. The first step of sum_to runs through to the last line and shows NameError: name 'result' is not defined.

Break & Midpoint Check

  1. Does defining a function run its body? No. It runs only when called.
  2. What is the difference between a parameter and an argument? A parameter is a name written in the definition; an argument is a value passed in the call.
  3. What does a function without a return statement return? None.
  4. After the call ends, can the caller use a local variable directly? No. Get the values you need back with return.

Next is how to wrap a loop in a function.

A Loop Inside a Function

A function body can contain a loop. Initialize the accumulator afresh on each call, and put the return after the loop so that it returns the completed sum. This version assumes n is an integer of 0 or more.

def sum_to(n):
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(5))    # 15
print(sum_to(3))    # 6
print(sum_to(0))    # 0

The Barista Who Leaves Early

Three customers are waiting for coffee. How many messages does the code below print? Vote for 0, 1 or 3, then trace the first iteration.

def serve():
    for number in range(1, 4):
        return f"Coffee for {number}"

print(serve())

The answer is one, Coffee for 1, because return ends the current function call immediately. The slides then ask: what happens if you change the return inside the loop to print and the last line to serve()? Then the loop runs to the end and all three messages are printed.

return Ends the Whole Function

return exits the function, ending any loop inside it as well. This differs from break, which exits only the nearest loop. Returning inside a loop can stop the accumulation too early.

def too_early(n):
    total = 0
    for value in range(1, n + 1):
        total += value
        return total    # Wrong indentation

print(too_early(5))     # 1, not 15
print(too_early(0))     # None

too_early(0) is None because the loop never runs, so the return is never reached. You can check both results in sum_to.

A Function's Input and Output Rules

Before coding, define the allowed inputs and the expected output. sum_to accepts integers of 0 or more, and if a negative number comes in it returns None as a signal of invalid input. We assume the caller passes an integer; handling type errors comes later.

def sum_to(n):
    if n < 0:
        return None
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(-1))   # None
print(sum_to(5))    # 15

Combining Small Functions

A function's return value can become another function's argument. Keep each function's purpose clear. The example below calculates a price and then adds a fee.

def total_price(price, quantity):
    return price * quantity

def add_fee(amount, fee=5):
    return amount + fee

subtotal = total_price(20, 3)
final = add_fee(subtotal)
print(final)    # 65

Common Function Mistakes

  • Writing a function name without parentheses does not call it.
  • Passing too few required arguments raises a TypeError.
  • Printing a value does not send it back to the caller.
  • A return inside a loop can end the task too early.
  • Local variables cannot be used directly outside the function.

For each bug, look at the function definition, the call and the return value in turn. The first two mistakes are reproduced in the last step of power. Without parentheses you see only <function total_price at ...>, and leaving out one argument gives a missing 1 required positional argument error.
