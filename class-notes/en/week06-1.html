Act 1 · Files: Teach Your Program to Remember

print() talks; a file remembers. The screen is not storage; the disk is. A file is your program's memory: what you write today is still there tomorrow. In fact, you have already been using files: prices_2026.csv is a file too.

open(): Three Moves and One Trap

open(path, "w") creates a file and returns a file object. f.write(text) puts a string into the file and does nothing more. f.close() hands the file back to the system. If you forget close(), the file may be left empty or locked. Trap: write() adds no newline, so you have to write "\n" at the end of each line yourself.

report = open("summary.txt", "w")
report.write("CODE week high: 10800")
report.write("\n")
report.close()
print("Saved summary.txt")

with: The Door That Closes Itself

with open(...) as f: closes the file when the block ends. Even if an error occurs inside the block, the file is closed on the way out. No forgotten close(), no locked file, no half-written report. From this slide on, every open() is written with with.

lines = ["CODE 10800", "TEA 4800"]
with open("summary.txt", "w") as f:
    for line in lines:
        f.write(line + "\n")
print("Saved summary.txt")

Predict: if you run this script twice, how many lines will summary.txt have? The answer is in the "Modes" section below.

Reading: Three Ways to Drink from a File

read() gives the whole file as one string (the whole glass at once). readlines() gives a list of lines (poured into cups). for line in f: reads one line at a time and saves memory (one sip at a time). If you leave out the mode, the default is "r", that is, reading. Trap: every line ends with "\n", so you have to remove it with strip(). Otherwise "buy\n" is not equal to "buy".

with open("trades.csv") as f:
    header = f.readline()
    print(header.strip())         # date,ticker,...

with open("trades.csv") as f:
    print(len(f.readlines()))     # 11 with header

11 is 10 trades plus 1 header line. On the journal_by_hand page you can confirm the same number with wc -l trades.csv.

Anatomy of a CSV Line

strip() removes the hidden "\n" at the end, and split(",") cuts the line into a list of fields. Every field is a string, even "3", so turn it into a number with int(). This is exactly what read_csv does.

with open("trades.csv") as f:
    f.readline()
    line = f.readline()

fields = line.strip().split(",")
print(fields[1], fields[2],
      int(fields[3]) * int(fields[4]))
# TEA buy 50000

The output is the first trade of the week: 10 shares × 5000 won.

Modes: r Reads, w Wipes, a Adds

  • "r" reads. If the file does not exist, you get a clear FileNotFoundError.
  • "w" writes from scratch. It wipes the file before writing. Every time.
  • "a" appends. The old lines stay and new lines are added at the end.
  • A report that replaces itself uses "w"; a journal that grows uses "a".
with open("journal.txt", "a") as f:
    f.write("2026-03-09,CODE,buy,2,10900\n")

The answer to the earlier prediction: even after two runs, there are still 2 lines, because "w" wiped the first run's contents before the second run wrote.

Act 2 · Classes: You Already Talk to Objects

The dot is a sentence: "this thing, do what you know." In "CODE".upper() the string knows how to shout in capitals, in closes.mean() the Series knows how to average, and in f.write(...) the file knows how to save. An object combines data with the behavior that fits that data. Today we design such objects ourselves.

Blueprint and Buildings: class Position

class Position: draws a blueprint for a new kind of object. __init__ runs every time a Position is created, and self, the object being built right now, is always the first parameter. Everything assigned to self becomes that object's own data.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

Attributes: Every Object Packs Its Own Bag

Attributes are the data inside one object. p1 and p2 come from the same class but share nothing. p1.ticker is CODE and p2.ticker is TEA, and they do not mix. You reach an attribute with the dot: object.name.

p1 = Position("CODE", 2, 10000)
p2 = Position("TEA", 10, 5000)
print(p1.ticker, p2.shares)    # CODE 10

Methods: Teach the Object a Trick

A method is a function inside a class. self goes first in the def but is not written in the call. profit(self, close) uses self.shares and self.buy, and when you call p.profit(4800), Python passes p as self. Trap: leaving self out of the def gives the error "takes 1 positional argument but 2 were given". You can reproduce this error in the last step of the position_report page.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

    def profit(self, close):
        return (close - self.buy) * self.shares

print(Position("TEA", 40, 5000).profit(4800))   # -8000

40 shares, bought at 5000 won, now 4800. Ouch.

One Loop, Five Objects, Two Destinations

A portfolio is a list of Position objects. Each object carries its own numbers in its own bag, and one loop asks every position the same question. The answers go to two places at once: the screen and a file.

portfolio = [Position("CODE", 10, 10000),
             Position("TEA", 40, 5000),
             Position("ROBO", 5, 40000)]

with open("report.txt", "w") as f:
    for p in portfolio:
        line = p.ticker + " " + str(p.shares)
        f.write(line + "\n")
        print(line)

The screen shows CODE 10, TEA 40 and ROBO 5, and the same three lines are saved in report.txt. Check the saved file in the terminal with cat report.txt.

Act 3 · Charts: Numbers That Persuade

Files remember, objects structure, and charts persuade. A table makes the reader do the math, but a line shows the trend at once. matplotlib is Python's standard plotting library. NumPy computes, pandas labels, and matplotlib draws.

One Install, One Alias: plt

On your own PC, run pip install matplotlib in the terminal; Colab already has it. The convention is import matplotlib.pyplot as plt. np, pd and plt are three-letter aliases the whole world uses the same way.

The web lab's virtual machine has matplotlib installed but no screen. So you cannot open a window with plt.show(); always save the figure to a file with plt.savefig("file.png"). Copy the saved PNG with cp week.png /mnt/host/, then enter the file name in the page's Download box to save it to your computer and open it. Loading matplotlib can take several tens of seconds.

Your First Line Plot

plt.plot(x, y) draws one line from point to point. x comes first (the weekdays), y next (the closes). The figure is the canvas and the axes are the chart on it. savefig writes the chart to a file; on your own PC in class you can open a window with show().

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
closes = [10000, 10200, 9800, 10500, 10800]

plt.plot(days, closes)
plt.title("CODE closing prices")
plt.savefig("week.png")
# plt.show() opens the chart in class

Titles, Labels, Grid, Markers

title names the chart, and xlabel and ylabel name the axes. grid(True) adds grid lines, and marker="o" puts a dot on each day. A labeled chart needs no explanation; an unlabeled chart needs an apology.

plt.plot(days, closes, marker="o")
plt.title("CODE closing prices")
plt.xlabel("Day")
plt.ylabel("Won")
plt.grid(True)
plt.savefig("labeled.png")

Two Lines and a Legend

Calling plot once per line makes them share one chart. label= names each line and legend() shows those names. You can see TEA sliding while CODE climbs without printing anything. If needed, change the look with linestyle="--" and color=.

code = [10000, 10200, 9800, 10500, 10800]
tea = [5000, 4950, 4900, 4850, 4800]

plt.plot(days, code, label="CODE", marker="o")
plt.plot(days, tea, label="TEA", marker="o")
plt.legend()
plt.savefig("two.png")

The pandas Shortcut

A Series can draw itself: closes.plot(). The index automatically becomes the x axis, and here title= is an argument of plot. Saving is still done with pyplot's plt.savefig.

import pandas as pd
import matplotlib.pyplot as plt

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
closes.plot(title="CODE", marker="o")
plt.savefig("series.png")

Bar Charts: Who Is Biggest?

plt.bar(x, y) draws one bar per category. Lines show change; bars compare size. Drawing the values of your five Positions as bars shows that ROBO is ahead before you print a single number.

tickers = ["CODE", "TEA", "ROBO", "MLBK", "FIT"]
values = [108000, 192000, 225000, 75000, 84000]

plt.bar(tickers, values)
plt.title("Portfolio value")
plt.ylabel("won")
plt.savefig("values.png")

Sort, Then Bar

Bars sorted from largest are read at a glance. Pair and rank them with sorted(zip(values, tickers)), tilt long names with xticks(rotation=45), and set the canvas size with figsize=(w, h).

pairs = sorted(zip(values, tickers), reverse=True)
plt.bar([t for v, t in pairs],
        [v for v, t in pairs])
plt.xticks(rotation=45)
plt.savefig("ranked.png")

Choosing the Chart

The question picks the chart, not your taste.

  • How did it move over time? A line: plt.plot.
  • Who is biggest? Bars: plt.bar.
  • How spread out are the values? A histogram: plt.hist.

Wrong chart, wrong answer, even when the data is right.

The Year from Disk

This morning you parsed trades.csv by hand. read_csv reads the one-year file the same way. Plot one column and 260 trading days appear. One file, one line of code, one year.

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("prices_2026.csv")
df["CODE"].plot(title="CODE in 2026")
plt.savefig("code.png")
print(len(df))   # 260

Histograms: How Spread?

diff() gives each day's difference from the day before. The first day has no previous day, so dropna() drops it. plt.hist counts the changes per interval (bin). The shape of the distribution is the risk story: narrow is calm, wide is rough.

df = pd.read_csv("prices_2026.csv")
changes = df["CODE"].diff().dropna()

plt.hist(changes)
plt.title("CODE daily change")
plt.savefig("changes.png")
print(len(changes))   # 259

Saving and Fresh Charts

savefig writes the current figure to a file. A png file can be pasted into reports and slides. figure() starts a new, empty chart, so to make two charts in one script you need a figure() between them. Trap: without figure(), the bars are drawn on top of the line and one file becomes a mess. On the my_charts page you can save two similar charts and download them.

import matplotlib.pyplot as plt

closes = [10000, 10200, 9800, 10500, 10800]

plt.plot(closes, marker="o")
plt.savefig("week.png")     # file for reports

plt.figure()                # a fresh chart
plt.bar(["win", "loss"], [3, 2])
plt.savefig("record.png")

Five Ways to Ruin a Friday Evening

  • open() without with: the file stays open, maybe even empty.
  • "w" on a journal: a week of trades disappears. Use "a" to append.
  • No self in a method's def: takes 1 argument but 2 were given.
  • Two charts without figure(): one overlapping mess.
  • Comparing unstripped lines: "sell\n" is not "sell".

strip() every line you read. Behind every comparison you forgot, a newline is hiding.
