3주차 1차시는 반복문을 배우는 시간입니다. 같은 일을 여러 번 하는 방법으로 for와 range(), while을 익히고, 누적 변수(accumulator)가 반복마다 어떻게 변하는지, 반복문이 언제 멈추는지 추적합니다. break와 continue를 의도에 맞게 쓰는 법을 배운 뒤, 반복문 안에 반복문을 넣는 중첩 반복문으로 구구단과 별 무늬를 만듭니다. 수업은 복습 10분, for 25분, while 20분, 휴식 10분, 중첩 반복문 15분, 안내 실습 30분, 정리 10분으로 진행합니다.

예제는 네 개입니다. 연습 1의 짝수 합(even_sum), 연습 2의 0까지 입력 합(input_sum), 실습 3의 구구단(multiplication), 실습 4의 별 삼각형(stars)입니다. 각 예제 페이지에는 그 앞에서 배우는 슬라이드 예제도 실행 단계로 들어 있습니다.

복습: 학생 한 명의 결과

if 문은 실행할 블록을 고릅니다. 60점 이상이면 합격입니다.

score = 75
if score >= 60:
    print("Pass")
else:
    print("Fail")
# Output: Pass

그런데 학생이 30명이라면 어떻게 해야 할까요? 같은 코드를 30번 복사하는 대신, 반복문으로 같은 처리를 되풀이합니다.

for: 값을 하나씩

for 다음의 in 뒤에 시퀀스를 둡니다. 반복할 때마다 다음 값이 변수에 들어갑니다. 콜론과 네 칸 들여쓰기가 반복문의 본문을 정합니다. 마지막 값까지 처리하면 반복이 끝나고, 들여쓰기 밖의 코드가 실행됩니다.

for letter in "ABC":
    print(letter)
print("Done")

# Output
# A
# B
# C
# Done

range()로 정수 범위 만들기

range(stop)은 0부터 시작합니다. range(start, stop)은 start를 포함합니다. 어느 경우든 stop 값은 항상 빠집니다. range는 정수의 순서를 나타내는 것이지 리스트가 아닙니다.

for i in range(3):
    print(i)
# 0, 1, 2 on separate lines

for i in range(1, 4):
    print(i)
# 1, 2, 3 on separate lines

간격과 거꾸로 세기

세 번째 인자는 간격(step)입니다. 음수 간격을 주면 거꾸로 셉니다. 방향이 맞지 않으면 빈 범위가 되어 본문이 한 번도 실행되지 않고, 간격이 0이면 ValueError가 납니다.

for i in range(2, 7, 2):
    print(i)
# 2, 4, 6

for i in range(3, 0, -1):
    print(i)
# 3, 2, 1

for i in range(3, 0):
    print(i)
# No output

even_sum의 앞쪽 단계에서 다섯 가지 범위를 한 줄씩 출력하고, range(1, 5, 0)의 ValueError도 확인할 수 있습니다.

누적 합 구하기

합계를 담을 변수 total은 반복문 앞에서 초기화합니다. total += n은 total = total + n과 같습니다. 최종 결과는 반복문이 끝난 뒤에 출력합니다.

total = 0
for n in range(1, 6):
    total += n
print(total)
# 15

슬라이드의 질문은 "total = 0을 반복문 안에 넣으면 어떻게 될까?"입니다. 그러면 반복할 때마다 0으로 되돌아가므로, 마지막 반복에서 더한 5만 남습니다. even_sum에서 두 경우를 모두 실행해 봅니다.

코드를 실행하기 전에 반복마다 변수의 값을 예측해 표로 적어 봅니다. 각 반복은 이전 반복의 total을 이어받습니다.

예제 페이지에서는 반복마다 n, 더하기 전, 더한 뒤 값을 출력하는 코드로 이 표를 그대로 만들어 봅니다.

연습 1: 짝수의 합

1부터 10까지의 정수를 차례로 보면서 if와 %로 짝수를 골라 total에 더합니다. 기대 결과는 30입니다. 5분 동안 풀어 봅니다.

total = 0
for n in range(1, 11):
    # Add your condition and update here.
    pass
print(total)

pass는 아무 일도 하지 않는 자리 표시용 문장입니다. 문법상 본문이 필요한 자리를 임시로 채워 둡니다. 그래서 시작 코드를 그대로 실행하면 아무것도 더하지 않고 0이 출력됩니다. n % 2 == 0일 때만 더하면 2 + 4 + 6 + 8 + 10 = 30이 됩니다(even_sum).

while: 조건이 참인 동안 반복

while은 본문을 실행하기 전에 조건을 검사합니다. 처음부터 조건이 거짓이면 본문은 한 번도 실행되지 않습니다. 반복을 끝내려면 조건에 쓰인 값을 본문에서 바꿔야 합니다.

count = 1
while count <= 3:
    print(count)
    count += 1
print("Done", count)
# 1
# 2
# 3
# Done 4

실행 순서와 무한 반복

초기화하고, 조건을 검사하고, 본문을 실행하고, 다시 조건을 검사하는 순서로 진행됩니다.

countcount <= 3동작
1True1 출력
2True2 출력
3True3 출력
4False반복 종료

count += 1이 없으면 조건이 계속 참이라 반복이 끝나지 않습니다. 터미널에서는 Ctrl+C로, Colab에서는 Stop 버튼으로 실행 중인 반복을 멈춥니다. 이 실습실의 터미널에서도 Ctrl+C가 동작합니다.

break: 반복문 빠져나가기

사용자가 끝내자고 할 때까지 입력을 반복하는 경우를 생각해 봅니다. break는 자신을 감싸는 가장 가까운 반복문을 빠져나갑니다. 입력이 q이면 되돌려 주는 출력을 건너뛰고 반복을 떠납니다.

while True:
    text = input("Message (q: quit): ")
    if text == "q":
        break
    print("Input:", text)
print("Done")

input_sum에서는 이 코드를 파일로 저장해 hello, hi, q를 차례로 입력한 결과를 볼 수 있습니다.

continue: 이번 반복만 건너뛰기

continue는 현재 반복의 나머지 문장을 건너뛰고 다음 반복으로 넘어갑니다. while 반복문에서 쓸 때는 반복을 멈추게 하는 갱신문까지 실수로 건너뛰지 않도록 주의합니다.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

# Output
# 1
# 2
# 4
# 5

for와 while 고르기

  • 문자열의 문자를 하나씩 처리할 때: for
  • 정해진 횟수만큼 반복할 때: range()와 함께 쓰는 for
  • 조건이 유지되는 동안 반복할 때: while
  • 두 반복문 모두 안에 if 문을 넣을 수 있습니다.

다음 세 경우에 어떤 반복문을 쓸지 고르고 이유를 설명해 봅니다. (1) 단어의 각 문자 출력하기, (2) 사용자가 q를 입력할 때까지 메시지 읽기, (3) 7단을 1부터 9까지 출력하기. 차례로 문자열에 대한 for, 끝나는 시점을 미리 모르는 while, 횟수가 정해진 range()의 for가 자연스럽습니다.

연습 2: 0이 나올 때까지 더하기

반복마다 정수를 하나씩 읽어, 0이 나오면 멈추고 합계를 출력합니다. 더하기 전에 멈춤 값인지 먼저 검사합니다. 입력은 정수 형식이라고 가정합니다. 힌트는 total = 0, while True, int(input()), break입니다.

입력 순서기대 합계

시작 코드에는 break까지 들어 있고 더하는 한 줄만 비어 있으므로, 실행하면 0에서 멈추긴 하지만 합계는 항상 Total: 0입니다. input_sum에서 세 테스트를 한 번에 실행해 답안과 비교합니다. 직접 python3 input_sum.py로 실행해 숫자를 하나씩 입력해 봐도 됩니다.

휴식과 중간 점검

10분 휴식 뒤 다음 질문으로 앞부분을 확인합니다.

  1. range(1, 5)의 마지막 값은? 4입니다. stop은 포함되지 않습니다.
  2. while은 언제 조건을 검사하는가? 본문을 실행하기 전, 매 반복의 시작에서 검사합니다.
  3. break와 continue의 차이는? break는 반복문 전체를 끝내고, continue는 이번 반복만 건너뜁니다.

다음은 반복문 안에서 또 반복하는 방법입니다.

중첩 반복문

바깥 반복문이 묶음을 하나 고르면, 안쪽 반복문은 그 바깥 값마다 자기 값을 처음부터 끝까지 모두 돕니다. 아래 예는 여섯 쌍을 출력합니다. 들여쓰기가 어느 문장이 어느 반복문에 속하는지 결정합니다.

for row in range(1, 3):
    for col in range(1, 4):
        print(row, col)
# 1 1
# 1 2
# 1 3
# 2 1
# 2 2
# 2 3

중첩 반복문 추적

바깥 반복을 한 단계 진행하기 전에 안쪽 반복을 끝까지 마칩니다. 새 row마다 col은 다시 1부터 시작합니다. 2행 3열이므로 본문은 여섯 번 실행됩니다.

바깥 row안쪽 col 값
11, 2, 3
21, 2, 3

두 반복문이 모두 끝난 뒤 row는 2, col은 3입니다. 반복 변수는 마지막으로 받은 값을 유지합니다.

실습 3: 구구단

3A: 한 단 출력하기

multiplication.py는 2부터 9까지의 정수를 하나 입력받습니다. 유효하면 1부터 9까지 곱하는 식 9개를 f-string으로 출력하고, 그렇지 않으면 Invalid table을 출력하고 한 단 출력 부분을 건너뜁니다. 입력은 정수 형식이라고 가정합니다.

Input: 7
First line: 7 x 1 = 7
Last line:  7 x 9 = 63
Number of equations: 9

Input: 1
Invalid table

3B: 2단부터 9단까지

한 단을 출력한 다음, 이어서 모든 단을 출력하도록 확장합니다. 바깥 반복문이 단을, 안쪽 반복문이 곱하는 수를 고릅니다. 각 단이 끝나면 빈 줄을 하나 출력합니다. 이 부분은 입력 검증 블록 뒤에 두어 항상 실행되게 합니다.

for table in range(2, 10):
    for factor in range(1, 10):
        # Print one equation here.
        pass
    print()

시작 코드에는 이 뼈대가 이미 있어서, 그대로 실행하면 All tables: 뒤에 단마다 출력되는 빈 줄 8개만 보입니다.

실습 3 확인

  • 유효한 경계값 2와 9, 잘못된 입력 1과 10을 테스트합니다.
  • 모든 단 부분은 8단 × 9개 = 72개의 식이어야 합니다. 첫 식은 2 x 1 = 2, 마지막 식은 9 x 9 = 81입니다.
  • 유효한 입력은 이 부분 앞에 식 9개를 더하고, 잘못된 입력은 아무것도 더하지 않습니다.

식의 개수는 직접 세기 어려우므로 multiplication에서는 grep -c ' = '로 셉니다. 7을 넣으면 81개, 1을 넣으면 72개가 나와야 합니다.

별 무늬: 행과 열

한 행마다 바깥 반복을 한 번 합니다. 1행에는 별 1개, 2행에는 2개, 이런 식으로 늘어납니다. print("*", end="")는 줄을 바꾸지 않고 같은 줄에 이어서 출력하고, 안쪽 반복문이 끝난 뒤의 print()가 현재 행을 끝냅니다.

for row in range(1, 4):
    for col in range(row):
        print("*", end="")
    print()
# *
# **
# ***

기본 과제는 반드시 중첩 반복문으로 만듭니다. 문자열 반복("*" * row)도 방법이지만 이것은 나중에 따로 이야기합니다.

실습 4 확인과 흔한 실수

  • 높이 1은 별 하나짜리 한 행입니다.
  • 높이 4는 네 행, 모두 합쳐 별 10개입니다.
  • 높이 10은 열 행입니다.
  • 높이 0과 11은 Invalid height 메시지만 출력합니다.

흔한 실수는 세 가지입니다. 바깥을 range(1, height)로 쓰면 마지막 행이 빠집니다. print()를 안쪽 반복문 안에 두면 별이 한 줄에 하나씩 찍힙니다. 안쪽을 range(height)로 쓰면 삼각형이 아니라 사각형이 됩니다. stars에서 별 개수 세기와 함께 두 가지 실수를 직접 재현해 볼 수 있습니다.

반복문에서 자주 하는 실수

  • range(1, 10)은 1부터 9까지이며 10은 포함되지 않습니다.
  • 누적 변수는 반복문 앞에서 초기화합니다.
  • 최종 요약 출력은 반복문 밖에 둡니다.
  • while 반복문에는 조건을 바꾸는 문장이나 빠져나갈 방법이 있어야 합니다.
  • 행을 끝내는 print()는 안쪽 반복문 뒤에 둡니다.

실행하기 전에는 첫 번째 반복, 마지막 반복, 최종 출력을 예측합니다. 디버깅할 때는 반복 변수와 누적 변수를 임시로 출력해 봅니다.
