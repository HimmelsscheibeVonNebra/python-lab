Steps실행 순서

  1. web start app.py

    Start app.py as a background server (about 10 seconds). When it is ready, the app preview panel opens under the terminal with the first page. The preview panel plays the browser's role in this lab.app.py를 백그라운드 서버로 띄운다(10초 정도). 준비되면 터미널 아래에 앱 미리보기 창이 열리고 첫 화면이 보인다. 미리보기 창이 이 실습의 브라우저 역할을 한다.

  2. web get /

    Send a request to the address /. The HTML returned by home(), the function marked @app.get("/"), is shown as text. HTTP 200 means success.주소 /로 요청을 보낸다. @app.get("/")가 붙은 home()이 돌려준 HTML이 글자로 보인다. HTTP 200은 성공이라는 뜻이다.

  3. web show '/hello?name=Mina'

    web show puts an address in the preview panel; web get shows the same page as text in the terminal.web show는 주소를 미리보기 창에 띄운다. web get은 같은 화면을 터미널에 글자로 보여 준다.

  4. web get '/hello?name=Mina'

    name=Mina after the ? is the query string. hello() reads it with request.args.get("name") and builds Hello, Mina!. Typing /hello?name=Mina in the preview panel's address box and pressing Open does the same.? 뒤의 name=Mina가 쿼리 문자열이다. hello()가 request.args.get("name")으로 읽어 Hello, Mina!를 만든다. 미리보기 창의 주소 칸에 /hello?name=Mina를 넣고 열기를 눌러도 같다.

  5. web get /hello

    Without name, get() uses its default "world": Hello, world!name이 없으면 get()의 기본값 "world"를 쓴다: Hello, world!

  6. web html '/hello?name=<b>Mina</b>'

    web html shows the raw HTML. Thanks to escape(), <b> became &lt;b&gt;, so the tag you typed is shown as text instead of being run.web html은 HTML 원문을 보여 준다. escape() 덕분에 <b>가 &lt;b&gt;로 바뀌어, 입력한 태그가 실행되지 않고 글자로 표시된다.

  7. web get /nothing

    For an address that does not exist, Flask answers HTTP 404 (Not Found).없는 주소는 Flask가 HTTP 404(Not Found)로 답한다.

  8. web log

    The server log has one line per request with its address and status code (200, 404).서버 로그: 요청마다 주소와 상태 코드(200, 404)가 한 줄씩 남는다.

  9. web stop

    Stop the server. After editing app.py, run web stop and then web start again so the new code is used.서버를 끈다. app.py를 고친 뒤에는 web stop → web start로 다시 띄워야 바뀐 코드가 적용된다.

pandas, matplotlib and Flask are downloaded the first time they are used, and loading them inside the emulator takes 10–30 seconds. Wait until the prompt comes back.pandas·matplotlib·Flask는 처음 쓸 때 필요한 파일을 내려받고, 에뮬레이터 안에서 불러오는 데 10~30초가 걸립니다. 프롬프트가 다시 나올 때까지 기다리세요.

app.py 21 lines21줄 
"""The smallest Flask app: two routes.  Run: web start app.py"""
from flask import Flask, request
from markupsafe import escape
 
app = Flask(__name__)
 
 
@app.get("/")
def home():
    return "<h1>Hello, Flask!</h1><p>Try /hello?name=Mina</p>"
 
 
@app.get("/hello")
def hello():
    name = request.args.get("name", "world")
    # escape(): a name like <b>hi</b> is shown as text, not run as HTML
    return f"<p>Hello, {escape(name)}!</p>"
 
 
if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)
