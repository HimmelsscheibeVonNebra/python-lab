Steps실행 순서

  1. python3 --version

    This lab's Python is 3.14.10. Only the number differs from the 3.12.4 on the slides; what you learn is the same. On a Windows PC the command is usually python or py.이 실습실의 Python은 3.14.10이다. 슬라이드의 3.12.4와 숫자만 다를 뿐 배우는 내용은 같다. Windows PC에서는 명령이 보통 python 또는 py다.

  2. printf '%s\n' '2 + 3' 'print("hi")' 'type(3.14)' 'exit()' | python3 -i

    This feeds input into the REPL. After each >>> you see, in order, the value of the expression 5, the print output hi, and <class 'float'>. If you type just python3 yourself, the same >>> prompt appears, and exit() leaves it.REPL에 입력을 흘려 넣은 모습이다. >>> 뒤에 식의 값 5, print 결과 hi, <class 'float'>가 차례로 나온다. 직접 python3만 입력하면 같은 >>> 프롬프트가 뜨고 exit()로 나온다.

  3. python3 -c 'print(type(42), type(3.14), type("hi"), type(True), type(None))'

    The five basic data types int, float, str, bool and NoneType are printed.다섯 가지 기본 자료형 int, float, str, bool, NoneType이 출력된다.

  4. python3 -c 'print(int("42"), int(3.9), float("3.5"), float(7), str(42) + "!", bool(0), bool(""), bool(None), bool(5))'

    int(3.9) truncates rather than rounds, giving 3, and float(7) gives 7.0. Only 0, the empty string and None are False; 5 is True.int(3.9)는 반올림이 아니라 버려서 3이 되고, float(7)은 7.0이 된다. 0·빈 문자열·None만 False이고 5는 True다.

  5. python3 -u -c 'print("3" + "3"); print(int("3") + 3); print("3" + 3)' 2>&1 | grep -v -e '^Traceback' -e '^ '

    "3" + "3" is the concatenation 33; converted with int it is 6. Adding a string and an integer raises a TypeError, as in the last line (the start of the Traceback is hidden with grep)."3" + "3"은 이어 붙인 33, int로 바꾸면 6이다. 문자열과 정수를 더하면 마지막 줄처럼 TypeError가 난다(Traceback 앞부분은 grep으로 숨겼다).

  6. python3 -u -c 'print(int(float("3.5"))); print(int("3.5"))' 2>&1 | grep -v -e '^Traceback' -e '^ '

    "3.5" has to go through float to become the integer 3. Calling int("3.5") directly raises ValueError: invalid literal for int()."3.5"는 float을 거쳐야 정수 3이 된다. int("3.5")를 바로 하면 ValueError: invalid literal for int()가 난다.

  7. mkdir -p ~/python-week1 && python3 -m venv --without-pip ~/python-week1/.venv && ls ~/python-week1/.venv/bin

    The virtual environment folder .venv is created, and activate and python appear inside bin. This lab has no pip, so --without-pip is added. On a real PC, python3 -m venv .venv is enough.가상 환경 폴더 .venv가 생기고 bin 안에 activate와 python이 보인다. 이 실습실에는 pip이 없어 --without-pip을 붙였다. 실제 PC에서는 python3 -m venv .venv면 된다.

  8. . ~/python-week1/.venv/bin/activate; which python; python --version; deactivate; which python

    After activation, python points to ~/python-week1/.venv/bin/python; after deactivate it is /usr/bin/python again. If you activate it yourself without deactivate, (.venv) appears in front of the prompt.활성화하면 python이 ~/python-week1/.venv/bin/python을 가리키고, deactivate 뒤에는 다시 /usr/bin/python이 된다. deactivate 없이 직접 활성화해 보면 프롬프트 앞에 (.venv)가 붙는다.
