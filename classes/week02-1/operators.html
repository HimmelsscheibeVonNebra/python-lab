Steps실행 순서

  1. python3 -c 'print(8 + 2, type(8 + 2)); print(8 / 2, type(8 / 2)); print("8" + "2", type("8" + "2"))'

    8 / 2 is the float 4.0 even though both operands are integers, and "8" + "2" is the str 82. Predict the value and type before running it.8 / 2는 정수끼리 나눠도 float 4.0이고, "8" + "2"는 str 82다. 실행 전에 값과 자료형을 먼저 예측해 본다.

  2. python3 -c 'raw = " 12 "; clean = raw.strip(); number = int(clean); print(repr(raw), repr(clean)); print(number + 3, clean + "3")'

    Seen with repr, raw still has its leading and trailing spaces. The numeric addition gives 15, and the string concatenation gives 123.repr로 보면 raw의 앞뒤 공백이 그대로 남아 있다. 숫자 덧셈은 15, 문자열 연결은 123이다.

  3. python3 -c 'a, b = 7, 3; print(a + b, a - b, a * b, a / b); print(a // b, a % b, a ** b, -7 // 3)'

    7 // 3 is 2, 7 % 3 is 1 and 7 ** 3 is 343. -7 // 3 rounds down, so it is -3, not -2.7 // 3은 2, 7 % 3은 1, 7 ** 3은 343이다. -7 // 3은 내림이라 -2가 아니라 -3이다.

  4. python3 -c 'minutes = 185; print(minutes // 60, minutes % 60); students = 29; print(students // 4, students % 4); print(3 * 60 + 5, 7 * 4 + 1)'

    Answers to the exercise: 3 hours 5 minutes, and 7 groups of 4 with 1 student left. Check that quotient × divisor + remainder gives back the original values 185 and 29.연습 문제의 답: 3시간 5분, 4명씩 7모둠에 1명 남음. 몫 × 나누는 수 + 나머지가 원래 값 185, 29로 돌아오는지 확인한다.

  5. python3 -c 'score = 85; print(score == 85, score != 85, score >= 60, 0 <= score <= 100, "85" == 85)'

    Comparisons return True/False. The string "85" and the integer 85 are not equal, so input must be converted before comparing.비교 결과는 True/False다. 문자열 "85"와 정수 85는 같지 않으므로 입력은 비교 전에 변환해야 한다.

  6. python3 -c 'for score in (0, 100, 101): print(score, 0 <= score <= 100, 0 < score < 100)'

    <= includes the endpoint and < excludes it. The two results differ at 0 and 100, and for 101 both are False.<=는 끝값을 포함하고 <는 제외한다. 0과 100에서 두 결과가 갈리고, 101은 둘 다 False다.

  7. python3 -c 'age = 20; has_id = True; print(age >= 18 and has_id, age < 18 or has_id, not has_id)'

    and is True when both are true, or is True when at least one is true, and not reverses the value.and는 둘 다 참일 때, or는 하나만 참이어도 True, not은 뒤집는다.

  8. python3 -c 'n = 0; print(n != 0 and 10 / n > 2); text = ""; print(text != "" and text[0] == "A")'

    Both print False and there is no error. The first condition is False, so 10 / n and text[0] are never evaluated (short-circuiting).둘 다 False가 나오고 오류가 없다. 앞쪽 조건이 False라 10 / n과 text[0]은 평가되지 않는다(단락 평가).

  9. python3 -c 'print(2 + 3 * 4, (2 + 3) * 4, -2 ** 2, (-2) ** 2); print(True or False and False, (True or False) and False)'

    14, 20, -4, 4. ** binds more tightly than unary -, so -2 ** 2 is -4. and comes before or, so the first expression is True; with parentheses it is False.14, 20, -4, 4. **가 단항 -보다 먼저라 -2 ** 2는 -4다. and가 or보다 먼저라 첫 식은 True, 괄호를 치면 False다.

  10. python3 -c 'score = 80; score += 5; print(score); x = 5; x += 3; x *= 2; print(x)'

    Compound assignments run in written order: 85, and then (5 + 3) × 2 = 16.복합 대입은 적힌 순서대로 실행된다: 85, 그리고 (5 + 3) × 2 = 16.

  11. for y in 2000 1900 2024; do echo $y | python3 leap_year.py; done

    A leap-year test that combines %, ==, and, or and not in one expression. After the Year: prompt you get 2000: Leap year, 1900: Not a leap year. It is worked through in detail in Session 2, Lab 4.%, ==, and, or, not을 한 식에 묶은 윤년 판정이다. 프롬프트 Year: 뒤에 2000: Leap year, 1900: Not a leap year가 나온다. 자세한 풀이는 2차시 실습 4에서 한다.

"""Lab 4 reference solution: the Gregorian leap-year rule."""
 
# Assume integer-formatted input. Range validation follows conversion.
year = int(input("Year: "))
 
if year <= 0:
    print("Enter a positive year")
else:
    is_leap = year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
    if is_leap:
        print(f"{year}: Leap year")
    else:
        print(f"{year}: Not a leap year")
 
# Tests:
# 2024, 2000 -> <year>: Leap year
# 2023, 1900 -> <year>: Not a leap year
# 0, -4 -> Enter a positive year
