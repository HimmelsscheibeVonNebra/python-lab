Steps실행 순서

  1. python3 -c 'text = "Python"; print(len(text), text[0], text[2], text[-1], text[-2])'

    Length 6, first character P (index 0), text[2] is t, and the negative indices -1 and -2 count from the end: n, o.길이 6, 첫 글자 P(인덱스 0), text[2]는 t, 음수 인덱스 -1과 -2는 끝에서부터 n, o다.

  2. python3 -u -c 'text = "Python"; print(text[5]); print(text[6])' 2>&1 | grep -v -e '^Traceback' -e '^ '

    With length 6, the valid indices are 0 to 5. text[5] is n, and text[6] is IndexError: string index out of range.길이 6이면 유효한 인덱스는 0~5다. text[5]는 n이고, text[6]은 IndexError: string index out of range다.

  3. python3 -u -c 'print("A"[0] == "A"[-1]); print(""[0])' 2>&1 | grep -v -e '^Traceback' -e '^ '

    In a one-character string the first and last characters are the same (True). An empty string has no valid index, so it is an IndexError.한 글자 문자열은 첫 글자와 마지막 글자가 같다(True). 빈 문자열에는 유효한 인덱스가 없어 IndexError다.

  4. python3 -c 'text = "Python"; print(text[0:2], text[2:], text[:4], text[::2], text[::-1], text[:99])'

    Py, thon, Pyth, Pto, nohtyP, Python. The stop index is not included, and a slice past the end, [:99], is cut at the end without an error.Py, thon, Pyth, Pto, nohtyP, Python. stop 인덱스는 포함되지 않고, 범위를 넘는 슬라이스 [:99]는 오류 없이 끝까지 잘린다.

  5. python3 -c 'text = "PYTHON"; print(text[1:4], text[:3], text[-3:], text[1::2], text[::-1], repr(text[2:2]))'

    Answers to the exercise: YTH, PYT, HON, YHN, NOHTYP. When start and stop are equal the result is an empty string, shown by repr as ''.연습 문제의 답: YTH, PYT, HON, YHN, NOHTYP. start와 stop이 같으면 빈 문자열이고 repr로 ''가 보인다.

  6. python3 -u -c 'text = "Python"; text = "J" + text[1:]; print(text); text[0] = "J"' 2>&1 | grep -v -e '^Traceback' -e '^ '

    Building a new string gives Jython. Strings are immutable, so assigning to text[0] gives TypeError: 'str' object does not support item assignment.새 문자열을 만들면 Jython이 된다. 문자열은 불변이라 text[0]에 대입하면 TypeError: 'str' object does not support item assignment다.

  7. python3 -c 'raw = " Hello Python "; clean = raw.strip(); print(clean.lower(), "|", clean.upper(), "|", clean.replace("Python", "AI")); print(clean.split(), "Python" in clean, "python" in clean)'

    Methods return a new string. split() makes the list ['Hello', 'Python'], and in is case-sensitive: True, False.메서드는 새 문자열을 돌려준다. split()은 ['Hello', 'Python'] 리스트를 만들고, in은 대소문자를 구별해 True, False다.

  8. python3 -c 'raw = " Hello Python "; clean = raw.strip(); lowered = clean.lower(); slug = lowered.replace(" ", "-"); print(repr(raw), clean, lowered, slug, sep=" / ")'

    A text-cleaning pipeline: strip affects only the ends, while replace also changes the space in the middle, giving hello-python. The original raw is unchanged.문자열 정리 과정: strip은 양끝만, replace는 가운데 공백까지 바꿔 hello-python이 된다. 원래 raw는 그대로 남아 있다.

  9. python3 -c 'name = "Mina"; score = 87.5; print("Hi, " + name); print("-" * 5); print("Score: " + str(score)); print(f"{name}: {score:.2f}"); print(" YES ".strip().lower() == "yes")'

    + joins and * repeats. To join a number with +, you need str(). After normalizing the input, " YES " equals "yes" (True).+는 연결, *는 반복이다. 숫자를 +로 붙이려면 str()이 필요하다. 입력을 정규화하면 " YES "도 "yes"와 같다(True).

  10. python3 -c 'item = "Notebook"; price = 2.5; quantity = 3; total = price * quantity; print(f"Item: {item}"); print(f"Quantity: {quantity}"); print(f"Total: {total:.2f}"); print(total)'

    The receipt example: the display is Total: 7.50, but the total variable still holds the number 7.5.영수증 예제: 표시는 Total: 7.50이지만 total 변수에는 여전히 숫자 7.5가 들어 있다.

  11. printf ' Python \n' | python3 strings.py

    A program that combines strip, len, upper, [::-1] and an empty-string check. Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P.strip, len, upper, [::-1], 빈 문자열 검사를 조합한 프로그램이다. Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P.
