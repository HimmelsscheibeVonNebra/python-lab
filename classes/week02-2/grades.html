    The starter code prints only the Score: prompt and no grade.시작 코드는 Score: 프롬프트만 출력하고 등급은 없다.

  2. for s in -1 0 59 60 69 70 79 80 89 90 100 101; do printf '%4s -> ' $s; echo $s | python3 ../solutions/grades.py | sed 's/^Score: //'; done

    A boundary test table. It uses the value just below each threshold and the threshold itself, the two endpoints 0 and 100, and the out-of-range values -1 and 101. 59 must be F, 60 D, 89 B, 90 A, and 101 Invalid score.경계값 테스트 표다. 각 기준의 바로 아래 값과 기준 값, 두 끝값 0과 100, 범위 밖 -1과 101을 넣었다. 59는 F, 60은 D, 89는 B, 90은 A, 101은 Invalid score여야 한다.

  3. printf '%s\n' 'score = 95' 'if score >= 60:' ' print("D")' 'elif score >= 90:' ' print("A")' | python3 -

    A wrong chain that checks the low threshold first. 95 comes out as D. This is why thresholds must be checked from the highest.낮은 기준을 먼저 검사한 잘못된 사슬이다. 95가 D로 나온다. 높은 기준부터 검사해야 하는 이유다.

  4. for s in 59 60 101; do printf '%s\n' 'score = '$s'' 'if not 0 <= score <= 100:' ' print(score, "Invalid score")' 'else:' ' if score >= 60:' ' print(score, "Pass")' ' else:' ' print(score, "Fail")' | python3 -; done

    Optional Pass/Fail task: the decision is placed inside the valid-score branch, so 101 gets no Pass/Fail.선택 과제 Pass/Fail: 판정을 유효 점수 분기 안에 넣었기 때문에 101에는 Pass/Fail이 붙지 않는다.

"""Lab 2 reference solution: integer scores and grade thresholds."""
 
# Assume integer-formatted input. Range validation follows conversion.
score = int(input("Score: "))
 
if not 0 <= score <= 100:
    print("Invalid score")
elif score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
 
# Tests:
# -1, 101 -> Invalid score
# 0, 59 -> F; 60, 69 -> D; 70, 79 -> C
# 80, 89 -> B; 90, 100 -> A
