Keyboard Input with input()

input() displays a prompt and waits for keyboard input. When you type a value and press Enter, the program continues. The returned value is always a string, even when you type a number, so labs that need an integer use int(input(...)). To try a different input, run the program again.

name = input("Name: ")
print(f"Hello, {name}!")
# Type Mina, then press Enter.
# Output: Hello, Mina!

score = int(input("Score: "))
print(score + 1)
# Type 85, then press Enter.
# Output: 86
# Enter integer-formatted text for score.

The example steps in this lab supply the input in advance and run automatically. For example, echo 85 | python3 grades.py is the same as typing 85 and pressing Enter. Because the input is not shown on screen, the output appears right after the prompt, as in Score: B. To type the input yourself, just run python3 grades.py.

f-Strings: Values Inside Text

print() is a function that displays a value, and the f is not syntax that print() requires. Without the f, the braces and variable name are printed literally. With an f in front of the quotation mark, the current value of name is put in place of {name}. Python builds the string first, and then print() displays it. For simple output, you can also list the values separated by commas.

name = "Mina"
score = 85
print("Hello, Mina!")
# Hello, Mina!
print("Hello, {name}!")
# Hello, {name}!
print(f"Hello, {name}!")
# Hello, Mina!
print(f"Score: {score}")
# Score: 85
print("Score:", score)
# Score: 85

Lab 3: Rock-Paper-Scissors

Rules

rps.py plays one round against the computer. The input is cleaned with strip().lower(), and only rock, paper or scissors is accepted. If both are the same it is a tie; rock beats scissors, scissors beats paper, and paper beats rock. Invalid input is rejected, and for valid input both choices are printed. The computer's choice is picked from a list with random.choice().

import random

# choice() picks one item.
computer = random.choice(
    ["rock", "paper", "scissors"]
)

# First, test with fixed values:
player = "rock"
computer = "scissors"
# Expected outcome: You win

Branching Example

Validate the player's choice before deciding the outcome. Check for a tie before win or loss, and list all three winning pairs. Everything else is a loss.

import random
p = input("Your choice: ").strip().lower()
options = ["rock", "paper", "scissors"]
c = random.choice(options)
if p not in ["rock", "paper", "scissors"]:
    print("Invalid choice")
else:
    print(f"You: {p}, computer: {c}")
    if p == c:
        print("Tie")
    elif ((p == "rock" and c == "scissors")
          or (p == "scissors" and c == "paper")
          or (p == "paper" and c == "rock")):
        print("You win")
    else:
        print("You lose")

The output must be exactly one of Tie, You win and You lose.

Lab 4: Leap-Year Calculator

Leap-Year Rules

leap_year.py reads a positive integer year and decides whether it is a leap year by the Gregorian calendar rules. If it is divisible by 400, it is a leap year. Otherwise, if it is divisible by 100, it is not a leap year. Otherwise, if it is divisible by 4, it is a leap year. Everything else is not a leap year. Divisibility is tested with the remainder operator %.

# Divisibility uses remainder:
print(2024 % 4 == 0)      # True
print(1900 % 100 == 0)    # True
print(2000 % 400 == 0)    # True

# Expected classifications:
# 2024: Leap year
# 1900: Not a leap year
# 2000: Leap year
# 2023: Not a leap year

Tracing the Leap-Year Rule

First find the results of the three divisibility tests. A year that is a multiple of 100 is a leap year only if it is also divisible by 400, and an ordinary multiple of 4 is a leap year. Explain why 1900 and 2000 give different results.

year = 1900
by4 = year % 4 == 0
by100 = year % 100 == 0
by400 = year % 400 == 0
print(by4, by100, by400)
# True True False
print(by400 or (by4 and not by100))
# False

# Repeat with 2000, 2024 and 2023.
# Expected: True, True, False.

Leap-Year Calculator

Reject 0 and negative years. Combine the rules with and and or, and use parentheses to separate the two cases that make a leap year. Print a clear result for the year entered.

year = int(input("Year: "))
if year <= 0:
    print("Enter a positive year")
else:
    is_leap = (year % 400 == 0 or
               (year % 4 == 0 and
                year % 100 != 0))
    if is_leap:
        print(f"{year}: Leap year")
    else:
        print(f"{year}: Not a leap year")

An Equivalent Branch Chain

The challenge is to express the same rule with if/elif/else. Keep the positive-year check first, check multiples of 400 before multiples of 100, and multiples of 100 before multiples of 4. Compare the results with the Boolean-expression version.

year = 2000
if year <= 0:
    print("Enter a positive year")
elif year % 400 == 0:
    print(f"{year}: Leap year")
elif year % 100 == 0:
    print(f"{year}: Not a leap year")
elif year % 4 == 0:
    print(f"{year}: Leap year")
else:
    print(f"{year}: Not a leap year")

f-string: 텍스트 안에 값 넣기

print()는 값을 보여 주는 함수이고, f는 print()에 꼭 필요한 문법이 아닙니다. f를 붙이지 않으면 중괄호와 변수 이름이 글자 그대로 출력됩니다. 따옴표 앞에 f를 붙이면 {name} 자리에 name의 현재 값이 들어갑니다. Python이 먼저 문자열을 완성하고, 그다음 print()가 그것을 보여 줍니다. 간단한 출력은 쉼표로 값을 나열해도 됩니다.

score = 85

# Hello, {name}!
print(f"Hello, {name}!")
# Hello, Mina!
print(f"Score: {score}")

# Score: 85

실습 4: 윤년 계산

윤년 규칙

leap_year.py는 양의 정수 연도를 입력받아 그레고리력 규칙으로 윤년인지 판단합니다. 400으로 나누어떨어지면 윤년입니다. 그렇지 않고 100으로 나누어떨어지면 윤년이 아닙니다. 그렇지 않고 4로 나누어떨어지면 윤년입니다. 나머지는 모두 윤년이 아닙니다. 나누어떨어지는지는 나머지 연산 %로 검사합니다.

# Divisibility uses remainder:
print(2024 % 4 == 0)      # True
print(1900 % 100 == 0)    # True
print(2000 % 400 == 0)    # True

# Expected classifications:
# 2024: Leap year
# 1900: Not a leap year
# 2000: Leap year
# 2023: Not a leap year

규칙 추적하기

먼저 세 가지 나눗셈 검사의 결과를 구합니다. 100의 배수인 해는 400으로도 나누어떨어져야 윤년이고, 일반적인 4의 배수는 윤년입니다. 1900과 2000의 결과가 왜 다른지 설명해 봅니다.

year = 1900
by4 = year % 4 == 0
by100 = year % 100 == 0
by400 = year % 400 == 0
print(by4, by100, by400)
# True True False
print(by400 or (by4 and not by100))
# False

# Repeat with 2000, 2024 and 2023.
# Expected: True, True, False.

윤년 계산기

0과 음수 연도는 거부합니다. 규칙은 and와 or로 묶고, 괄호로 윤년이 되는 두 가지 경우를 구분합니다. 입력한 연도에 대해 분명한 결과를 출력합니다.

year = int(input("Year: "))
if year <= 0:
    print("Enter a positive year")
else:
    is_leap = (year % 400 == 0 or
               (year % 4 == 0 and
                year % 100 != 0))
    if is_leap:
        print(f"{year}: Leap year")
    else:
        print(f"{year}: Not a leap year")

같은 규칙의 if/elif 사슬

도전 과제는 같은 규칙을 if/elif/else로 표현하는 것입니다. 양수 검사를 맨 앞에 두고, 400의 배수 검사를 100의 배수 검사보다, 100의 배수 검사를 4의 배수 검사보다 먼저 합니다. 결과를 불리언 식 버전과 비교해 봅니다.

year = 2000
if year <= 0:
    print("Enter a positive year")
elif year % 400 == 0:
    print(f"{year}: Leap year")
elif year % 100 == 0:
    print(f"{year}: Not a leap year")
elif year % 4 == 0:
    print(f"{year}: Leap year")
else:
    print(f"{year}: Not a leap year")

leap_year 예제에서 네 해의 추적, 답안의 여섯 가지 입력(2024, 2000, 2023, 1900, 0, -4), 그리고 if/elif 버전을 실행할 수 있습니다.
