Steps실행 순서

  1. echo 2024 | python3 leap_year.py; echo

    The starter code prints only the Year: prompt.시작 코드는 Year: 프롬프트만 출력한다.

  2. for y in 1900 2000 2024 2023; do printf '%s\n' 'year = '$y'' 'by4 = year % 4 == 0' 'by100 = year % 100 == 0' 'by400 = year % 400 == 0' 'print(year, by4, by100, by400, by400 or (by4 and not by100))' | python3 -; done

    Work out the three divisibility tests first. 1900 gives True True False, so it is not a leap year (False); 2000 is a multiple of 400, so it is a leap year. 2024 is True, 2023 is False.나눗셈 검사 세 개를 먼저 계산해 본다. 1900은 True True False라 윤년이 아니고(False), 2000은 400의 배수라 윤년이다. 2024는 True, 2023은 False.

  3. for y in 2024 2000 2023 1900 0 -4; do echo $y | python3 ../solutions/leap_year.py; done

    Running the solution: 2024 and 2000 are Leap year, 2023 and 1900 are Not a leap year, and 0 and -4 give Enter a positive year.답안 실행: 2024와 2000은 Leap year, 2023과 1900은 Not a leap year, 0과 -4는 Enter a positive year다.

  4. for y in 1900 2000; do printf '%s\n' 'year = '$y'' 'if year <= 0:' ' print("Enter a positive year")' 'elif year % 400 == 0:' ' print(f"{year}: Leap year")' 'elif year % 100 == 0:' ' print(f"{year}: Not a leap year")' 'elif year % 4 == 0:' ' print(f"{year}: Leap year")' 'else:' ' print(f"{year}: Not a leap year")' | python3 -; done

    The if/elif solution to the challenge. Checking in the order 400 → 100 → 4 gives the same results as the Boolean-expression solution.도전 과제의 if/elif 풀이다. 400 → 100 → 4 순서로 검사하면 불리언 식 풀이와 같은 결과가 나온다.

  5. python3 -c 'year = 1900; print(year % 4 == 0)'

    A common defect, checking only for multiples of 4: 1900 comes out True and is wrongly judged a leap year. 1900 is the test that exposes this defect.4의 배수만 검사하는 흔한 결함: 1900이 True로 나와 윤년으로 잘못 판정된다. 1900이 이 결함을 드러내는 테스트다.

"""Lab 4 reference solution: the Gregorian leap-year rule."""
 
# Assume integer-formatted input. Range validation follows conversion.
year = int(input("Year: "))
 
if year <= 0:
    print("Enter a positive year")
else:
    is_leap = year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
    if is_leap:
        print(f"{year}: Leap year")
    else:
        print(f"{year}: Not a leap year")
 
# Tests:
# 2024, 2000 -> <year>: Leap year
# 2023, 1900 -> <year>: Not a leap year
# 0, -4 -> Enter a positive year
