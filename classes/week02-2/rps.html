Steps실행 순서

  1. echo rock | python3 rps.py; echo

    The starter code prints only the prompt. The computer's choice is already made, but there is no comparison code.시작 코드는 프롬프트만 출력한다. 컴퓨터 선택은 이미 만들어지지만 비교 코드가 없다.

  2. for i in 1 2 3; do echo rock | python3 ../solutions/rps.py; done

    Even with the same rock entered three times, the computer's choice and the result can differ each time because of random.choice. So as it is, the test cannot be repeated.같은 rock을 세 번 넣어도 random.choice 때문에 컴퓨터 선택과 결과가 매번 달라질 수 있다. 그래서 이대로는 테스트를 반복할 수 없다.

  3. sed 's/random.choice(options)/"scissors"/' ../solutions/rps.py > /tmp/rps_fixed.py; grep -n 'computer =' /tmp/rps_fixed.py

    The reproducible test from the slides: a copy with the computer's choice fixed to "scissors" is made in /tmp. The original file is not changed.슬라이드의 재현 가능한 테스트: 컴퓨터 선택을 "scissors"로 고정한 사본을 /tmp에 만들었다. 원본 파일은 바꾸지 않는다.

  4. for p in ' ROCK ' paper scissors lizard ''; do printf '[%s] ' "$p"; echo "$p" | python3 /tmp/rps_fixed.py; done

    With the computer on scissors: ROCK with spaces and capitals is cleaned up and gives You win, paper gives You lose, scissors gives Tie, and lizard and the empty input give Invalid choice.컴퓨터가 scissors일 때: 공백과 대문자가 섞인 ROCK은 정리돼 You win, paper는 You lose, scissors는 Tie, lizard와 빈 입력은 Invalid choice다.

  5. for c in rock paper scissors; do sed "s/random.choice(options)/\"$c\"/" ../solutions/rps.py > /tmp/rps_$c.py; done; for p in rock paper scissors; do for c in rock paper scissors; do printf '%-9s %-9s ' $p $c; echo $p | python3 /tmp/rps_$c.py | tail -1; done; done

    Prints all 9 possible pairs as a table. As in the table on the slides, there must be 3 Ties, 3 You wins and 3 You loses.가능한 9가지 조합 전체를 표로 출력한다. 슬라이드의 표와 같이 Tie 3번, You win 3번, You lose 3번이어야 한다.

  6. python3 -c 'options = ["rock", "paper", "scissors"]; print("ROCK" in options, "ROCK".strip().lower() in options)'

    Without lower(), ROCK is treated as invalid input (False). After normalizing, it is True.lower()를 빠뜨리면 ROCK이 잘못된 입력(False)으로 처리된다. 정규화한 뒤에는 True다.

When testing your own rps.py, temporarily fix computer = "scissors" as on the slides, and change it back to random.choice(options) before submitting. If you replace ../solutions/rps.py with rps.py in the sed command above, you can run the same test without editing your file.자기 rps.py를 테스트할 때는 슬라이드처럼 computer = "scissors"로 잠시 고정해 보고, 제출 전에 random.choice(options)로 되돌린다. 위의 sed 명령에서 ../solutions/rps.py를 rps.py로 바꾸면 파일을 고치지 않고 같은 시험을 할 수 있다.

"""Lab 3 reference solution: one round of rock-paper-scissors."""
 
import random
 
options = ["rock", "paper", "scissors"]
player = input("Your choice: ").strip().lower()
computer = random.choice(options)
 
if player not in options:
    print("Invalid choice")
else:
    print(f"You: {player}, computer: {computer}")
    if player == computer:
        print("Tie")
    elif (
        (player == "rock" and computer == "scissors")
        or (player == "scissors" and computer == "paper")
        or (player == "paper" and computer == "rock")
    ):
        print("You win")
    else:
        print("You lose")
 
# Tests with computer temporarily fixed to "scissors":
# " ROCK " -> You win
# "paper" -> You lose
# "scissors" -> Tie
# "lizard" or "" -> Invalid choice
# Restore random.choice(options) after testing.
