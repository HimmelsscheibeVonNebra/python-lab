Steps실행 순서

  1. printf ' Python \n' | python3 strings.py; echo

    The starter code prints only the Text: prompt. The input is piped in; you can also run python3 strings.py and type it yourself.시작 코드는 Text: 프롬프트만 출력한다. 입력을 파이프로 넣었으며, python3 strings.py로 실행해 직접 입력해도 된다.

  2. printf ' Python \n' | python3 ../solutions/strings.py

    The spaces are removed, giving Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P.공백이 제거돼 Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P가 나온다.

  3. printf ' \n' | python3 ../solutions/strings.py

    Input of spaces only becomes an empty string after strip. Length: 0, Upper: and Reverse: are empty, and No text entered is printed. Even for an empty string, the first three lines must be printed.공백만 입력하면 strip 뒤 빈 문자열이 된다. Length: 0, Upper:와 Reverse:는 비어 있고 No text entered가 나온다. 빈 문자열에서도 앞의 세 줄은 출력돼야 한다.

  4. printf ' A \n' | python3 ../solutions/strings.py

    One character gives Length: 1, and Upper, Reverse and First are all A.한 글자는 Length: 1이고 Upper, Reverse, First가 모두 A다.

  5. python3 -u -c 'text = " ".strip(); print(text[0])' 2>&1 | grep -v -e '^Traceback' -e '^ '

    The defect you get by indexing without a check. An empty string raises IndexError, so it must be guarded with if text:.검사 없이 인덱싱하면 생기는 결함이다. 빈 문자열에서 IndexError가 나므로 if text:로 막아야 한다.

  6. python3 -c 'word = "Level".lower(); print(word == word[::-1])'

    Optional extension: after converting to lowercase and comparing with the reverse, the palindrome Level gives True.선택 확장 과제: 소문자로 바꾼 뒤 역순과 비교하면 회문 Level은 True다.

"""Lab 1 reference solution: string manipulation."""
 
text = input("Text: ").strip()
 
print(f"Length: {len(text)}")
print(f"Upper: {text.upper()}")
print(f"Reverse: {text[::-1]}")
 
if text:
    print(f"First: {text[0]}")
else:
    print("No text entered")

# "   " -> Length: 0, empty Upper/Reverse, No text entered
