Steps실행 순서

  1. printf '%s\n' 'def greet():' ' print("Hello!")' 'print("Before")' 'greet()' 'greet()' 'print("After")' | python3 -

    def on its own prints nothing. The body runs each time the function is called, giving the order Before, Hello!, Hello!, After.def만으로는 아무것도 출력되지 않는다. 호출할 때마다 본문이 실행돼 Before, Hello!, Hello!, After 순서가 된다.

  2. printf '%s\n' 'def cafe():' ' print("Americano")' 'drink = cafe()' 'print(drink)' | python3 -

    The cafe challenge: Americano is what the print inside the function displayed on screen, and drink holds None.카페 문제: Americano는 함수 안의 print가 화면에 보여 준 것이고, drink에는 None이 들어 있다.

  3. printf '%s\n' 'def cafe():' ' return "Americano"' 'drink = cafe()' 'print(drink)' | python3 -

    Replacing print with return sends the value back to the caller, so drink holds Americano, and it is printed only once.print를 return으로 바꾸면 값이 호출한 쪽으로 돌아와 drink에 Americano가 담기고, 출력은 한 번만 된다.

  4. printf '%s\n' 'def show_double(number):' ' print(number * 2)' 'def double(number):' ' return number * 2' 'shown = show_double(4)' 'saved = double(4)' 'print(shown)' 'print(saved + 1)' | python3 -

    show_double(4) displays 8 but returns None. double(4) prints nothing but returns 8, so saved + 1 is 9.show_double(4)는 8을 보여 주지만 None을 돌려준다. double(4)는 아무것도 출력하지 않지만 8을 돌려줘 saved + 1이 9가 된다.

  5. python3 is_even.py

    The function in the starter code is only pass, so None is printed all four times.시작 코드의 함수는 pass뿐이라 네 번 모두 None이 출력된다.

  6. python3 ../../solutions/session2/is_even.py

    Returning number % 2 == 0 gives True, False, True, True for 4, 7, 0, -2. The even test is correct for negative numbers and 0 too.number % 2 == 0을 return하면 4, 7, 0, -2에 대해 True, False, True, True다. 음수와 0도 짝수 판정이 맞다.
