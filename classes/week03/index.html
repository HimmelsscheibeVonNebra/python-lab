even_sum ~/week03/starter/session1

Practice 1: add only the even integers from 1 to 10 to total and print 30. Before that, check how for, range() and an accumulator variable behave using the examples from the slides.연습 1: 1부터 10까지의 정수 중 짝수만 total에 더해 30을 출력한다. 그 전에 for, range(), 누적 변수의 동작을 슬라이드 예제로 확인한다.

Steps실행 순서

  1. python3 - <<'EOF' for letter in "ABC": print(letter) print("Done") EOF

    On each iteration the next character goes into letter. After A, B, C the loop ends and Done is printed once.반복마다 다음 글자가 letter에 들어간다. A, B, C 다음 반복이 끝나고 Done이 한 번 출력된다.

  2. python3 - <<'EOF' for i in range(3): print(i, end=" ") print("| range(3)") for i in range(1, 4): print(i, end=" ") print("| range(1, 4)") for i in range(2, 7, 2): print(i, end=" ") print("| range(2, 7, 2)") for i in range(3, 0, -1): print(i, end=" ") print("| range(3, 0, -1)") for i in range(3, 0): print(i, end=" ") print("| range(3, 0)") EOF

    The stop value is always left out: 0 1 2, 1 2 3, 2 4 6, 3 2 1. range(3, 0), whose direction is wrong, is empty and gives no values.stop 값은 언제나 빠진다: 0 1 2, 1 2 3, 2 4 6, 3 2 1. 방향이 맞지 않는 range(3, 0)은 비어 있어 아무 값도 없다.

  3. python3 -u -c 'range(1, 5, 0)' 2>&1 | grep -v -e '^Traceback' -e '^ '

    A step of 0 gives ValueError: range() arg 3 must not be zero.step이 0이면 ValueError: range() arg 3 must not be zero다.

  4. python3 - <<'EOF' total = 0 for n in range(1, 6): before = total total += n print(n, before, total) print("final:", total) EOF

    An accumulator trace table: each line is n, total before adding and total after adding. Each iteration carries on from the previous total, giving 1, 3, 6, 10, 15.누적 추적표: 각 줄은 n, 더하기 전 total, 더한 뒤 total이다. 이전 total을 이어받아 1, 3, 6, 10, 15가 된다.

  5. python3 - <<'EOF' for n in range(1, 6): total = 0 total += n print("final:", total) EOF

    The question from the slides: if total = 0 is put inside the loop, it is reset every time and only the last value, 5, remains.슬라이드의 질문: total = 0을 반복문 안에 두면 매번 초기화돼 마지막 값 5만 남는다.

  6. python3 even_sum.py

    The starter code has only pass, so it adds nothing and prints 0.시작 코드는 pass만 있어 아무것도 더하지 않고 0을 출력한다.

  7. python3 ../../solutions/session1/even_sum.py

    Adding only when n % 2 == 0 gives 2 + 4 + 6 + 8 + 10 = 30.if n % 2 == 0일 때만 더하면 2 + 4 + 6 + 8 + 10 = 30이다.

input_sum ~/week03/starter/session1

Practice 2: read integers one at a time with while True, break when 0 is entered, and print the total. First check the execution order of while, break and continue.연습 2: while True로 정수를 하나씩 입력받아 0이 나오면 break하고 합계를 출력한다. while의 실행 순서, break, continue를 먼저 확인한다.

Steps실행 순서

  1. python3 - <<'EOF' count = 1 while count <= 3: print(count) count += 1 print("Done", count) EOF

    The condition is tested first and then the body runs. The loop exits when count becomes 4 and the condition is False, so you get Done 4. Without count += 1 it is an infinite loop.조건을 먼저 검사하고 본문을 실행한다. count가 4가 되어 조건이 False일 때 빠져나오므로 Done 4다. count += 1이 없으면 무한 반복이다.

  2. cat > /tmp/echo_q.py <<'EOF' while True: text = input("Message (q: quit): ") if text == "q": break print("Input:", text) print("Done") EOF printf 'hello\nhi\nq\n' | python3 /tmp/echo_q.py

    The break example is saved as /tmp/echo_q.py and given hello, hi and q. hello and hi are echoed back with Input:, and q ends the loop with no output, so Done is printed.break 예제를 /tmp/echo_q.py로 저장하고 hello, hi, q를 넣었다. hello와 hi는 Input:으로 되돌려 주고, q에서는 출력 없이 반복을 끝내 Done이 나온다.

  3. python3 - <<'EOF' for n in range(1, 6): if n == 3: continue print(n) EOF

    continue skips only the rest of the current iteration. Only 3 is left out, and 1, 2, 4, 5 are printed.continue는 이번 반복의 나머지만 건너뛴다. 3만 빠지고 1, 2, 4, 5가 출력된다.

  4. printf '3\n5\n0\n' | python3 input_sum.py

    The starter code does stop at 0, but there is no code that adds, so it prints Total: 0.시작 코드는 0에서 멈추긴 하지만 더하는 코드가 없어 Total: 0이다.

  5. printf '3\n5\n0\n' | python3 ../../solutions/session1/input_sum.py printf '0\n' | python3 ../../solutions/session1/input_sum.py printf -- '-2\n5\n0\n' | python3 ../../solutions/session1/input_sum.py

    Three tests: 3, 5, 0 gives Total: 8; 0 right away gives Total: 0; -2, 5, 0 gives Total: 3. Check for 0 first, then add.세 테스트: 3, 5, 0은 Total: 8, 바로 0이면 Total: 0, -2, 5, 0은 Total: 3. 0인지 먼저 검사한 뒤 더한다.

You can also run python3 input_sum.py yourself, enter numbers one at a time and finish with 0. If you get stuck in an infinite loop by mistake, stop it with Ctrl+C (the Stop button in Colab).직접 python3 input_sum.py로 실행해 숫자를 하나씩 입력하고 0으로 끝내 봐도 된다. 실수로 무한 반복에 빠지면 Ctrl+C로 멈춘다(Colab에서는 Stop 버튼).

sum_to ~/week03/starter/session2

Lab 3: complete sum_to(n), which adds 1 through n with a loop and returns the result. For a negative number it returns None. First check local variables, and the problem of a return inside a loop ending the function early.실습 3: 반복문으로 1부터 n까지 더해 돌려주는 sum_to(n)을 완성한다. 음수면 None을 돌려준다. 지역 변수와, 반복문 안의 return이 함수를 일찍 끝내는 문제를 먼저 확인한다.

Steps실행 순서

  1. python3 -u - <<'EOF' 2>&1 | grep -v -e '^Traceback' -e '^ ' number = 10 def add_one(number): result = number + 1 return result print(add_one(3)) print(number) print(result) EOF

    Local variables: add_one(3) is 4, and the outer number stays 10. result inside the function cannot be used outside, giving NameError: name 'result' is not defined.지역 변수: add_one(3)은 4, 바깥 number는 그대로 10이다. 함수 안의 result는 밖에서 쓸 수 없어 NameError: name 'result' is not defined다.

  2. python3 - <<'EOF' def serve(): for number in range(1, 4): return f"Coffee for {number}" print(serve()) EOF

    The barista who leaves early: there are three customers, but the return in the first iteration ends the function, so only Coffee for 1 appears.일찍 퇴근하는 바리스타: 손님은 셋이지만 첫 반복의 return이 함수를 끝내 Coffee for 1 하나만 나온다.

  3. python3 - <<'EOF' def too_early(n): total = 0 for value in range(1, n + 1): total += value return total print(too_early(5)) print(too_early(0)) EOF

    If return is indented inside the loop, too_early(5) is 1, not 15. With n = 0 the loop never runs and never reaches the return, so the result is None.return을 반복문 안에 들여 쓰면 too_early(5)가 15가 아니라 1이다. n = 0이면 반복이 한 번도 돌지 않아 return에 닿지 못하고 None이다.

  4. python3 sum_to.py

    sum_to in the starter code returns None, so the caller prints Invalid input.시작 코드의 sum_to는 None을 돌려주므로 호출한 쪽이 Invalid input을 출력한다.

Integer Ranges with range()

range(stop) starts at 0. range(start, stop) includes start. In either case, the stop value is always left out. A range represents a sequence of integers; it is not a list.

for i in range(1, 4):

# 1, 2, 3 on separate lines

What Is a Function?

Repeated Code, Different Inputs

The two calculations below follow the same rule; only the input values differ. A function gives such a calculation a reusable name, and the caller can pass different inputs each time it calls it.

price = 20
quantity = 3
print(price * quantity)   # 60

price = 12
quantity = 5
print(price * quantity)   # 60

Functions: A Name for a Task

A function is a named block of code that runs when it is called. The slides use a cafe analogy. Defining is writing down the recipe once, calling is placing an order so that it is made by that recipe, and reusing is ordering again with different input. The answer to the question "If you only write down the recipe, does coffee get made?" is "No." In the same way, a function does not run just because it is defined.

Function Inputs and Results

Arguments supply the input values, the function does the task, and return hands the result to the caller. For example, total_price(20, 3) returns 60. Some functions take no arguments. A function that does not explicitly return a value returns None.

Defining and Calling Functions

Defining a Function

def starts a function definition. Write the name of the task, and put the parameters inside the parentheses. The colon and indentation define the body. Defining a function does not run its body.

def greet():
    print("Hello!")
# No output until the function is called.

greet()
# Hello!

Calling a Function

Parentheses make a function call. Execution goes into the function body and, when the body finishes, comes back to where it was called. In this session's scripts, functions are defined before they are called. Each call runs the body again.

def greet():
    print("Hello!")

print("Before")
greet()
greet()
print("After")
# Before
# Hello!
# Hello!
# After

Parameters & Arguments

Parameters are the names written in the function definition, and arguments are the values the caller passes. On each call, the arguments are bound to the parameters. Inside the function, parameters behave like local variables.

def show_total(price, quantity):
    print(price * quantity)

show_total(20, 3)    # 60
show_total(12, 5)    # 60
# Parameters: price, quantity
# Arguments in the first call: 20, 3

Returning a Result

return sends a value back to the caller. The returned result can be stored in a variable or used directly in an expression. return ends the current function call right there.

def total_price(price, quantity):
    return price * quantity

amount = total_price(20, 3)
print(amount)        # 60
print(amount + 5)    # 65

Ways to Pass Arguments

Positional & Keyword Arguments

Positional arguments bind in parameter order. Keyword arguments name the parameter directly, which makes the meaning of the call clear. In this session's functions, positional arguments come before keyword arguments.

Default Parameter Values

A default supplies a value when the caller omits the argument. If the caller explicitly gives another value, it overrides the default. Put parameters without defaults before parameters with defaults. Today's examples use only simple numeric defaults.

def power(base, exponent=2):
    return base ** exponent

print(power(2, 3))            # 8
print(power(5, exponent=0))   # 1

A Loop Inside a Function

A function body can contain a loop. Initialize the accumulator afresh on each call, and put the return after the loop so that it returns the completed sum. This version assumes n is an integer of 0 or more.

    return total

return Ends the Whole Function

return exits the function, ending any loop inside it as well. This differs from break, which exits only the nearest loop. Returning inside a loop can stop the accumulation too early.

def too_early(n):
    total = 0
    for value in range(1, n + 1):
        total += value
        return total    # Wrong indentation

print(too_early(0))     # None

too_early(0) is None because the loop never runs, so the return is never reached. You can check both results in sum_to.

실습 4: 계산기 함수

요구 사항

calculate(a, b, operator)를 정의합니다. "+", "-", "*", "/"를 지원하고, a와 b는 숫자, operator는 문자열이라고 가정합니다. 지원하지 않는 연산자이거나 0으로 나누는 경우에는 None을 돌려줍니다. 올바른 연산에는 결과가 0이어도 숫자 결과를 돌려줍니다.

호출반환값

선택 과제는 호출하는 쪽에서 a, b, 연산자를 입력받아 calculate()를 호출하는 것입니다.

실습 4 확인

지원하는 네 연산을 모두 확인하고, 0으로 나누기와 지원하지 않는 연산자를 테스트합니다. 음수와 결과가 0인 경우도 시험합니다. 함수는 출력하지 않고 값만 돌려줘야 합니다.

결과를 검사할 때 if not result는 쓰지 않습니다. 올바른 결과 0을 거짓으로 취급하기 때문입니다. 대신 if result is None을 씁니다. calculator에서 두 표의 아홉 호출을 한 번에 실행하고, not result와 result is None이 0에 대해 다르게 판단하는 것을 확인할 수 있습니다.

함수에서 자주 하는 실수

  • 함수 이름만 쓰고 괄호를 붙이지 않으면 호출되지 않습니다.
  • 필수 인자를 너무 적게 넘기면 TypeError가 납니다.
  • 값을 출력한다고 그 값이 호출한 쪽에 돌아가지는 않습니다.
  • 반복문 안의 return은 작업을 너무 일찍 끝낼 수 있습니다.
  • 지역 변수는 함수 밖에서 바로 쓸 수 없습니다.

버그마다 함수 정의, 호출, 반환값을 각각 찾아 봅니다. 앞의 두 실수는 power의 마지막 단계에서 재현됩니다. 괄호 없이 쓰면 <function total_price at ...>만 보이고, 인자를 하나 빠뜨리면 missing 1 required positional argument 오류가 납니다.

확인 퀴즈

  1. def power(base, exponent=2)에서 매개변수는? base와 exponent입니다.
  2. power(3)은 무엇을 돌려주는가? 기본값 2를 써서 9입니다.
  3. return이 없는 함수는 무엇을 만드는가? None입니다.

마지막으로, 호출한 쪽이 함수로부터 어떻게 값을 받는지 자기 말로 설명해 봅니다.
