  1. python3 number_tools.py

    When run directly, __name__ is "__main__", so the demo runs. The starter's average is just pass and returns None, so it prints Demo average: None.직접 실행하면 __name__이 "__main__"이므로 데모가 돈다. 스타터의 average는 pass뿐이라 None을 돌려주어 Demo average: None이 나온다.

  2. python3 stats_report.py

    The starter report prints only Scores: [88, 92, 79, 93]. import number_tools passes silently: the demo does not run when the module is imported.스타터 보고서는 Scores: [88, 92, 79, 93]만 출력한다. import number_tools는 조용히 지나간다. 가져올 때는 데모가 실행되지 않는다.

  3. python3 ../../solutions/session1/number_tools.py

    Running the finished module directly: Demo average: 5.0 (2+4+6+8 divided by 4).완성본 모듈의 직접 실행 결과: Demo average: 5.0 (2+4+6+8을 4로 나눈 값).

  4. python3 ../../solutions/session1/stats_report.py

    Finished report: Average: 88.0 (352 / 4), Above 85: 3 (88, 92, 93). The script's own folder comes first in the module search path, so the number_tools in the solutions folder is the one imported.완성본 보고서: Average: 88.0 (352 / 4), Above 85: 3 (88, 92, 93). 스크립트가 있는 폴더가 모듈 검색 경로의 첫 자리라서 solutions 폴더의 number_tools가 import된다.

  5. python3 -c 'import number_tools; print(number_tools.__name__)'

    Inside an imported module, __name__ is the file name minus .py: number_tools. That is why the demo line is not printed.import된 모듈 안에서 __name__은 파일 이름에서 .py를 뺀 number_tools다. 그래서 데모 줄은 출력되지 않는다.

  6. (cd ../../solutions/session1 && python3 -c 'import number_tools; print(number_tools.average([]))')

    The average of an empty list divides by zero and raises ZeroDivisionError: division by zero (Lab 1 Checks). How to handle this error is next session's topic. Because the cd happens inside the parentheses, the current folder does not change.빈 리스트의 평균은 0으로 나누게 되어 ZeroDivisionError: division by zero가 난다(Lab 1 Checks). 이 오류를 처리하는 방법은 다음 시간 주제다. 괄호 안에서 cd했으므로 현재 폴더는 바뀌지 않는다.

The ZeroDivisionError in the last step is shown on purpose. After filling in the two TODO functions, rerun the first two steps: you should get Demo average: 5.0, Average: 88.0, Above 85: 3, the same as the finished version.마지막 단계의 ZeroDivisionError는 일부러 보여 주는 오류다. 두 TODO 함수를 채운 뒤 첫 두 단계를 다시 실행하면 완성본과 같은 Demo average: 5.0, Average: 88.0, Above 85: 3이 나와야 한다.

"""Lab 1 solution module: small statistics tools for lists of numbers."""
 
 
def average(numbers):
    return sum(numbers) / len(numbers)
 
 
def count_above(numbers, limit):
    count = 0
    for value in numbers:
        if value > limit:
            count += 1
    return count
 
 
if __name__ == "__main__":
    demo = [2, 4, 6, 8]
    print("Demo average:", average(demo))
