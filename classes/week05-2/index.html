Yesterday's arrays hold numbers of a single kind. A portfolio mixes ticker codes (strings), share counts and prices, and every column needs a name and every row a label. pandas is the standard tool for data like this.

Series: A Labeled Column

Making a Series

A Series is a single column of values. You make one from a list with pd.Series([...]). Here it holds the closing prices (in won) of the CODE stock. tolist() turns it back into a list.

import pandas as pd

closes = pd.Series([10000, 10200, 9800])
print(closes)
print(closes.tolist())   # [10000, ...]

Vector Math, Zero Loops

Suppose you bought CODE on Monday at 10,000 won. closes - 10000 computes each day's profit or loss in one go. mean, max, min and sum also aggregate the whole column at once. The sum of a mask (True/False) is the number of Trues, so it gives the number of up days.

closes = pd.Series([10000, 10200, 9800, 10500, 10800])
print((closes - 10000).tolist())   # [0, 200, ...]
print(closes.mean())               # 10260.0
print(closes.max())                # 10800
print((closes > 10000).sum())      # 3

The Index: Names or Rows

The index is the label of each row. The default is the positions 0, 1, 2, 3, and you can give weekday names with index=. Square brackets and .loc read by label.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes["Tue"])       # 10200
print(closes.loc["Mon"])   # 10000

Masks: Keep What You Want

A comparison returns True/False for each day and works exactly as in NumPy. closes[mask] keeps only the winning days. Combining conditions needs parentheses and &.

mask = closes > 10000
print(closes[mask].tolist())   # [10200, ...]
print(closes[mask].mean())     # 10500.0
print(mask.tolist())           # False, True, ...

DataFrame: A Table of Columns

Making a DataFrame

A DataFrame is a table of rows and columns. Here it is the portfolio on Friday evening. You make it from a dict of lists of equal length, and each column is a Series sharing a single index. CODE is yesterday's store, CodeShop.

import pandas as pd

portfolio = pd.DataFrame({
    "ticker": ["CODE", "TEA", "ROBO"],
    "shares": [10, 40, 5],
    "buy": [10000, 5000, 40000],
    "close": [10800, 4800, 45000],
})
print(portfolio)

Two Ways to Build a Frame

A dict of lists (one key per column) and a list of dicts (one dict per trade) both build the same table. The row dicts must have the same keys.

trades = [
    {"ticker": "CODE", "shares": 10},
    {"ticker": "TEA", "shares": 40},
]
log = pd.DataFrame(trades)
print(log.shape)   # (2, 2)

First Look: shape, head, columns

df.shape is (rows, columns); the portfolio above is (3, 4). df.head(n) previews the first rows and df.tail(n) the last rows, and df.columns lists the column names.

print(portfolio.shape)            # (3, 4)
print(portfolio.head(2))
print(portfolio.columns.tolist())

Selecting Columns

A single column, portfolio["close"], is a Series. For several columns, put a list of names inside the brackets (double brackets); the order of the list becomes the column order. When the name is simple, the df.col form also works.

tickers = portfolio["ticker"]
print(tickers.tolist())   # ['CODE', ...]

friday = portfolio[["ticker", "close"]]
print(friday.shape)       # (3, 2)

Rows by Position: iloc

iloc picks rows by position. portfolio.iloc[0] is the first trade, iloc[0:2] gives several rows, and negative numbers count from the end.

print(portfolio.iloc[0])
print(portfolio.iloc[0:2])
print(portfolio.iloc[-1]["ticker"])   # ROBO

In the last step of the my_portfolio page you can see this three-stock table and the output of head, columns, iloc and describe for yourself.

Midpoint Check

  • Series and DataFrame: which is one column, and which is a table?
  • What exactly does a mask keep? The rows (values) at the positions that are True.
  • Why must all the column lists have the same length? Because every column shares a single index.

Sorting and Statistics

Sorting: sort_values

sort_values("close") sorts by one column, and ascending=False puts the largest first. Whole rows move along with the sort key. Sorting returns a new table, so the original stays as it is.

ranked = portfolio.sort_values("close", ascending=False)
print(ranked["ticker"].tolist())
# ['ROBO', 'CODE', 'TEA']

One-Column Statistics

The column operations of a Series work as they are. describe() shows count, mean, std, min, max and the quartiles all at once. Use round(x, 2) to keep reports tidy.

closes = portfolio["close"]
print(closes.max())              # 45000
print(round(closes.mean(), 1))   # 20200.0
print(closes.describe())

Where Is the Best Row? idxmax

idxmax() returns the label of the largest value. Where NumPy's argsort ranked by position, idxmax tells you the name. You can read that whole row with .loc[label], and it works the same on a Series and on a column of a table.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes.idxmax())           # Fri
print(closes[closes.idxmax()])   # 10800

Adding Columns and Counting

New Columns from Old

Assigning adds a column to the table. invested is the amount paid (shares × buy price), and profit is (close − buy) × shares. The vector operation fills every row at once, and the table itself changes.

shares = portfolio["shares"]
buy = portfolio["buy"]
close = portfolio["close"]

portfolio["invested"] = shares * buy
portfolio["profit"] = (close - buy) * shares
print(portfolio["profit"].tolist())
# [8000, -8000, 25000]

Counting Categories: value_counts

value_counts() counts how many times each value appears and returns them from most to least frequent. We use it to count buys and sells in a trade journal, and it works on any column, strings or labels.

actions = pd.Series(["buy", "sell", "buy", "buy", "sell", "buy"])
print(actions.value_counts())
# buy: 4, sell: 2

Filtering Whole Rows

A mask on a column filters whole rows. Keeping only the rows whose close is above the buy price leaves CODE and ROBO. Masks are combined with (a) & (b) and (a) | (b). If you store the result in a new variable, the original table stays safe.

win = portfolio["close"] > portfolio["buy"]
winners = portfolio[win]
print(winners["ticker"].tolist())   # ['CODE', 'ROBO']
print(winners.shape)                # (2, 4)

  • When combining masks, wrap each side in its own parentheses.

Series: 라벨이 붙은 열

Series 만들기

Series는 값 한 열입니다. pd.Series([...])로 리스트에서 만듭니다. 여기서는 CODE 종목의 종가(원)입니다. tolist()로 다시 리스트로 바꿀 수 있습니다.

import pandas as pd

closes = pd.Series([10000, 10200, 9800])
print(closes)
print(closes.tolist())   # [10000, ...]

반복문 없는 벡터 연산

월요일에 CODE를 10,000원에 샀다고 합시다. closes - 10000은 날마다의 손익을 한 번에 계산합니다. mean, max, min, sum도 열 전체를 한 번에 집계합니다. 마스크(True/False)의 합은 True의 개수이므로 오른 날의 수가 됩니다.

closes = pd.Series([10000, 10200, 9800, 10500, 10800])
print((closes - 10000).tolist())   # [0, 200, ...]
print(closes.mean())               # 10260.0
print(closes.max())                # 10800
print((closes > 10000).sum())      # 3

index: 행의 이름

index는 각 행의 라벨입니다. 기본값은 위치 0, 1, 2, 3이고, index=로 요일 이름을 줄 수 있습니다. 대괄호와 .loc은 라벨로 읽습니다.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes["Tue"])       # 10200
print(closes.loc["Mon"])   # 10000

마스크: 원하는 것만 남기기

비교는 날마다 True/False를 돌려주고, NumPy와 똑같이 동작합니다. closes[mask]는 이긴 날만 남깁니다. 조건을 결합할 때는 괄호와 &가 필요합니다.

mask = closes > 10000
print(closes[mask].tolist())   # [10200, ...]
print(closes[mask].mean())     # 10500.0
print(mask.tolist())           # False, True, ...

DataFrame: 열로 이루어진 표

DataFrame 만들기

DataFrame은 행과 열로 된 표입니다. 여기서는 금요일 저녁의 포트폴리오입니다. 길이가 같은 리스트들의 dict로 만들며, 각 열은 하나의 index를 공유하는 Series입니다. CODE는 어제의 상점 CodeShop입니다.

import pandas as pd

portfolio = pd.DataFrame({
    "ticker": ["CODE", "TEA", "ROBO"],
    "shares": [10, 40, 5],
    "buy": [10000, 5000, 40000],
    "close": [10800, 4800, 45000],
})
print(portfolio)

표를 만드는 두 가지 방법

리스트의 dict(열마다 키 하나)와 dict의 리스트(거래마다 dict 하나) 모두 같은 표를 만듭니다. 행 dict들은 같은 키를 가져야 합니다.

trades = [
    {"ticker": "CODE", "shares": 10},
    {"ticker": "TEA", "shares": 40},
]
log = pd.DataFrame(trades)
print(log.shape)   # (2, 2)

첫 확인: shape, head, columns

df.shape는 (행, 열)이며 위 포트폴리오는 (3, 4)입니다. df.head(n)은 앞쪽 행을, df.tail(n)은 뒤쪽 행을 미리 보여 주고, df.columns는 열 이름을 나열합니다.

print(portfolio.shape)            # (3, 4)
print(portfolio.head(2))
print(portfolio.columns.tolist())

열 선택

열 하나 portfolio["close"]는 Series입니다. 여러 열은 대괄호 안에 이름의 리스트를 넣으며(대괄호 두 겹), 리스트의 순서가 열 순서가 됩니다. 이름이 단순하면 df.col 형태도 됩니다.

tickers = portfolio["ticker"]
print(tickers.tolist())   # ['CODE', ...]

friday = portfolio[["ticker", "close"]]
print(friday.shape)       # (3, 2)

위치로 행 선택: iloc

iloc은 위치로 행을 고릅니다. portfolio.iloc[0]은 첫 거래, iloc[0:2]는 여러 행, 음수는 끝에서부터 셉니다.

print(portfolio.iloc[0])
print(portfolio.iloc[0:2])
print(portfolio.iloc[-1]["ticker"])   # ROBO

중간 점검

  • Series와 DataFrame: 열 하나인가, 표인가?
  • 마스크는 정확히 무엇을 남기는가? True인 위치의 행(값)입니다.
  • 왜 모든 열 리스트의 길이가 같아야 하는가? 모든 열이 하나의 index를 공유하기 때문입니다.

정렬과 통계

정렬: sort_values

sort_values("close")는 한 열을 기준으로 정렬하고, ascending=False는 큰 것부터 놓습니다. 정렬 키와 함께 행 전체가 이동합니다. 정렬은 새 표를 돌려주므로 원래 표는 그대로입니다.

ranked = portfolio.sort_values("close", ascending=False)
print(ranked["ticker"].tolist())
# ['ROBO', 'CODE', 'TEA']

열 하나의 통계

Series의 열 연산이 그대로 통합니다. describe()는 count, mean, std, min, max, 사분위수를 한꺼번에 보여 줍니다. round(x, 2)로 보고서를 깔끔하게 만듭니다.

closes = portfolio["close"]
print(closes.max())              # 45000
print(round(closes.mean(), 1))   # 20200.0
print(closes.describe())

가장 큰 행은 어디에: idxmax

idxmax()는 가장 큰 값의 라벨을 돌려줍니다. NumPy의 argsort가 위치로 순위를 매겼다면 idxmax는 이름을 알려 줍니다. .loc[label]로 그 행 전체를 읽을 수 있으며, Series에도 표의 열에도 똑같이 쓸 수 있습니다.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes.idxmax())           # Fri
print(closes[closes.idxmax()])   # 10800

열 추가와 세기

기존 열로 새 열 만들기

대입하면 표에 열이 추가됩니다. invested는 산 금액(주식 수 × 매수가), profit은 (종가 − 매수가) × 주식 수입니다. 벡터 연산이 모든 행을 한 번에 채우고, 표 자체가 바뀝니다.

shares = portfolio["shares"]
buy = portfolio["buy"]
close = portfolio["close"]

portfolio["invested"] = shares * buy
portfolio["profit"] = (close - buy) * shares
print(portfolio["profit"].tolist())
# [8000, -8000, 25000]

범주 세기: value_counts

value_counts()는 값마다 몇 번 나왔는지 세고, 많은 것부터 돌려줍니다. 매매 일지에서 buy와 sell을 세는 데 쓰며, 문자열이든 라벨이든 어떤 열에도 쓸 수 있습니다.

actions = pd.Series(["buy", "sell", "buy", "buy", "sell", "buy"])
print(actions.value_counts())
# buy: 4, sell: 2

행 전체 거르기

열에 대한 마스크는 행 전체를 거릅니다. 종가가 매수가보다 높은 행만 남기면 CODE와 ROBO가 남습니다. 마스크는 (a) & (b), (a) | (b)로 결합합니다. 결과를 새 변수에 담으면 원래 표는 안전합니다.

win = portfolio["close"] > portfolio["buy"]
winners = portfolio[win]
print(winners["ticker"].tolist())   # ['CODE', 'ROBO']
print(winners.shape)                # (2, 4)

먼저 읽고, 변환한 다음 Series를 만듭니다. days와 값 리스트는 같은 순서를 공유하고, mean, max, idxmax, 마스크가 네 가지 답을 줍니다. index가 가격 목록을 보고서로 바꿔 줍니다. 슬라이드의 예는 입력 대신 문자열 리스트를 쓰지만, 과제 프로그램은 input()으로 읽습니다. 웹 실습에서는 printf '4200\n4350\n4100\n4400\n4300\n' | python3 price_report.py로 입력을 한꺼번에 넣어 볼 수 있습니다.

import pandas as pd

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
typed = ["4200", "4350", "4100", "4400", "4300"]

values = []
for text in typed:
    values.append(int(text))
closes = pd.Series(values, index=days)

print(closes.mean())     # 4270.0
print(closes.idxmax())   # Thu
