Modules and import

What Is a Module?

A module is a file containing Python definitions (functions, variables and so on). The file name minus .py is the module name. For example, greetings.py is the greetings module. Importing a module runs its top-level code once. In fact, every program you have written so far was already a module.

# File: greetings.py
def hello(name):
    return "Hello, " + name + "!"

import and the Dot

import math loads the math module. The dot reaches a name inside the module: math.sqrt(2) means "the sqrt inside the math module". Keeping the prefix makes it clear from the code alone where each name came from. Python remembers (caches) a module after its first import, so importing the same module again does not run it again.

import math

print(math.pi)           # 3.141592653589793
print(math.sqrt(2))      # 1.4142135623730951
print(math.floor(2.9))   # 2

from module import name

If you import only the names you need, you can use them without a prefix. You can list several names separated by commas, and you can also rename a name while importing it. Only the imported names become visible: writing math.pi after from math import sqrt fails because there is no name math.

from math import sqrt, pi

print(sqrt(16))   # 4.0
print(pi)         # 3.141592653589793

Reusable code lives in its own .py file. average returns the mean of a list of numbers, and spread returns the difference between the largest and smallest values.     return total / len(numbers)

def spread(numbers):
    return max(numbers) - min(numbers)

datetime: Dates and Moments

date and datetime

A date holds a year, month and day, and a datetime also holds hours, minutes and seconds. today() and now() report the current moment, and each part is read as an attribute such as .year, .month, .day or .hour. The web lab's virtual machine takes today's date from your computer's clock; you can check it with the date command in the terminal.

now = datetime.now()
print(now.hour, now.minute)

Formatting Dates: strftime

strftime turns a date into a string in the layout you want. %Y, %m and %d are the year, month and day, and %A is the full weekday name. You can build exactly the string a report needs.

from datetime import date

today = date.today()
print(today.strftime("%Y-%m-%d"))       # 2026-09-27
print(today.strftime("%A, %d %B %Y"))   # Sunday, 27 September 2026 (example)

Date Arithmetic: timedelta

Subtracting two dates gives a timedelta in days, and .days extracts the whole number of days. Adding a timedelta to a date gives a future date. A negative number of days means the date has already passed.

from datetime import date, timedelta

today = date(2026, 9, 27)   # example
exam = date(2026, 11, 13)
print((exam - today).days)          # 47
print(today + timedelta(days=100))  # 2027-01-05

random: Random Numbers

Floats and Integers

random() returns a float from 0.0 up to, but not including, 1.0, and uniform(a, b) returns a float over a wider range. randint(a, b) picks an integer with both ends included. The results differ on every run.

import random

print(random.random())        # 0.639... (varies)
print(random.uniform(1, 10))  # 8.11... (varies)
print(random.randint(1, 6))   # one die, 1..6
print(random.randint(1, 6))   # a second roll

Pick, Shuffle, Sample

choice(seq) picks one element. shuffle(list) mixes the list in place and returns None, so writing names = random.shuffle(names) loses the list. sample(seq, k) picks k different elements. All of these work on the lists from Week 4.

import random

names = ["Ara", "Ben", "Cho", "Dan"]
print(random.choice(names))            # one name
random.shuffle(names)
print(names)                           # new order
print(random.sample(range(1, 46), 6))

Repeatability: seed

The same seed produces the same sequence, and different seeds give different results. Seeds are used for testing and for reproducing a run; games and lotteries rely on unseeded randomness that differs every time.

import random

random.seed(42)
print(random.randint(1, 100))   # 82
print(random.randint(1, 100))   # 15

random.seed(42)
print(random.randint(1, 100))   # 82 again

np.array: Lists Become Arrays

np.array turns a list into an ndarray. A nested list becomes a 2D array. In the example below, rows are stores and columns are products. The ingredients are lists you already know.

import numpy as np

r1 = [270000, 150000, 420000, 234000]
r2 = [189000, 100000, 315000, 180000]
r3 = [108000, 75000, 180000, 126000]
sales = np.array([r1, r2, r3])
print(sales)

Arrays by Recipe

arange(1, 10, 2) makes a range that excludes the end; zeros((2, 3)) and ones((2, 2)) make arrays of a given shape filled with 0 or 1; full((4,), 0.03) makes an array repeating one value; and linspace(0, 1, 5) makes evenly spaced values including both ends.

import numpy as np

print(np.arange(1, 10, 2))    # [1 3 5 7 9]
print(np.full((4,), 0.03))    # [0.03 0.03 0.03 0.03]
print(np.linspace(0, 1, 5))   # [0.   0.25 0.5  0.75 1.  ]

Random Arrays, Seeded

np.random is similar to the random module. randint(50, 151, size=5) draws five integers, and as with range the end 151 is excluded. With seed(42) everyone gets the same result.

import numpy as np

np.random.seed(42)
print(np.random.randint(50, 151, size=5))   # [101 142 64 121 110]
print(np.random.randint(1, 7, size=3))      # [5 2 3]

Reading an Array: shape and dtype

shape is (rows, columns); the sales above is (3, 4). ndim is the number of dimensions, size the number of elements, and dtype the single data type all elements share. When you receive new data, ask for its shape and dtype first.

print(sales.shape, sales.ndim, sales.size)   # (3, 4) 2 12
print(sales.dtype)                           # int64

The default dtype of an integer array depends on the environment. On a 64-bit PC it is usually int64, but on this 32-bit virtual machine it comes out as int32.

One dtype per Array

An array stores only one data type. Mixing integers and floats gives float64, and mixing numbers and strings turns everything into strings. astype(np.float64) converts to floats.

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
print(prices.mean())                 # 14000.0
print(prices.astype(np.float64))     # [ 9000. 25000.  4000. 18000.]
print(np.array([9000, "event"]))     # ['9000' 'event']

Indexing and Slicing

Indexes and slices work just like with lists. prices[1:3] starts at 1 and stops before 3. The difference is that a slice is a view onto the same memory: changing the view changes the original too. When you need a real copy, use prices[1:3].copy().

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
view = prices[1:3]
view[0] = 9900
print(prices)   # [ 9000  9900  4000 18000]

2D Indexing: [row, column]

Write the row and column inside one pair of brackets, separated by a comma. sales[1, 2] is a single cell, and sales[:, 1] is one whole column. Both directions can be sliced: sales[:2, 1:3].

sales = np.array([r1, r2])
print(sales[1, 2])   # 315000
print(sales[:, 1])   # [150000 100000]

Choosing by Condition: Masks

A comparison returns a Boolean array, and using it as an index keeps only the elements that are True. To combine masks, use & and |, not and/or, and put parentheses around each comparison.

revenue = prices * counts
print(revenue[revenue >= 100000])   # [108000 180000 126000]
mask = (revenue >= 100000) & (revenue < 150000)
print(revenue[mask])                # [108000 126000]

Fancy Indexing

Passing a list of positions picks elements in the order you want, and the same position may be repeated. The result is a new array, not a view. We use this later to pair names with rankings.

print(prices[[3, 0]])      # [18000  9000]
print(prices[[0, 0, 1]])   # [ 9000  9000 25000]

Vectorized Math and Broadcasting

Operators are applied element by element. prices * 2 doubles every value, whereas * 2 on a list repeats the whole list. np.sqrt and np.round also apply to the whole array. NumPy computes by stretching a smaller shape to fit a larger one (broadcasting). A single number spreads over the whole array, so prices * 0.9 discounts every product. The trailing dimensions must be equal or 1.

print(prices * 2)                     # [18000 50000  8000 36000]
print(prices + 1000)                  # [10000 26000  5000 19000]
print(np.sqrt(np.array([1, 4, 9])))   # [1. 2. 3.]
print(prices * 0.9)                   # [ 8100. 22500.  3600. 16200.]
promo = np.array([1000, 2000, 500, 3000])
print(prices + promo)                 # [10000 27000  4500 21000]

Aggregation with axis

sum, mean, max and min fold an array into a single value. axis=0 computes each column from top to bottom, and axis=1 computes each row across. Check with the length of the result: 4 products, 3 stores.

sales = np.array([r1, r2, r3])
print(sales.sum(axis=0))   # [567000 325000 915000 540000]
print(sales.sum(axis=1))   # [1074000  784000  489000]
print(sales.sum())         # 2347000

reshape, Stacking, Sorting

reshape(4, 3) groups the same data into a new shape, for example splitting 12 months into four quarters. -1 means "whatever is left", and .T swaps rows and columns. The number of elements (size) cannot change. vstack joins arrays as new rows and hstack as new columns (a new store is vstack, a new period is hstack). sort returns the sorted values and argsort the sorted positions, so together with fancy indexing you can line up names in order. argsort(-x) ranks from largest to smallest.

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))            # [470 533 592 666]
print(monthly.reshape(2, -1).shape)   # (2, 6)

wonju = np.array([90000, 60000, 120000, 70000])
sales = np.array([r1, r2])
print(np.vstack([sales, wonju]).shape)   # (3, 4)
print(np.hstack([sales, sales]).shape)   # (2, 8)

revenue = np.array([108000, 75000, 180000, 126000])
names = np.array(["mug", "shirt", "stickers", "tumbler"])
print(names[np.argsort(revenue)])
# ['shirt' 'mug' 'tumbler' 'stickers']

3주차에 만든 sum_to(n)은 1 + 2 + … + n을 돌려줍니다. 이 함수가 필요한 두 번째 프로그램이 생겼다고 해 봅시다. 코드를 복사해 붙이면 당장은 되지만, 버그를 발견하면 두 곳을 모두 고쳐야 합니다. 이번 시간의 목표는 다시 쓸 코드에 자기만의 집을 마련해 주는 것입니다.

def sum_to(n):
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(10))   # 55

모듈은 Python 정의(함수, 변수 등)가 들어 있는 파일입니다. 파일 이름에서 .py를 뺀 것이 모듈 이름이 됩니다. 예를 들어 greetings.py는 greetings 모듈입니다. 모듈을 import하면 그 모듈의 맨 위 수준 코드가 한 번 실행됩니다. 사실 지금까지 작성한 모든 프로그램도 이미 모듈이었습니다.

datetime: 날짜와 시각

date와 datetime

date는 연·월·일을, datetime은 거기에 시·분·초까지 담습니다. today()와 now()는 현재 시점을 알려 주고, 각 부분은 .year, .month, .day, .hour 같은 속성으로 읽습니다. 웹 실습의 가상 머신은 내 컴퓨터의 시계를 따라 오늘 날짜를 정하며, 터미널에서 date 명령으로 확인할 수 있습니다.

from datetime import date, datetime

today = date.today()
print(today)    # 2026-09-27 (example)
print(today.year, today.month, today.day)

now = datetime.now()
print(now.hour, now.minute)

날짜 서식: strftime

strftime은 날짜를 원하는 모양의 문자열로 바꿉니다. %Y, %m, %d는 연·월·일, %A는 요일의 전체 이름입니다. 보고서에 필요한 문자열을 정확히 만들 수 있습니다.

from datetime import date

today = date.today()
print(today.strftime("%Y-%m-%d"))       # 2026-09-27
print(today.strftime("%A, %d %B %Y"))   # Sunday, 27 September 2026 (example)

날짜 계산: timedelta

두 날짜를 빼면 일 단위의 timedelta가 나오고, .days로 정수 일수를 꺼냅니다. 날짜에 timedelta를 더하면 미래의 날짜가 됩니다. 일수가 음수이면 그 날짜가 이미 지났다는 뜻입니다.

from datetime import date, timedelta

today = date(2026, 9, 27)   # example
exam = date(2026, 11, 13)
print((exam - today).days)          # 47
print(today + timedelta(days=100))  # 2027-01-05

random: 난수

실수와 정수

random()은 0.0 이상 1.0 미만의 실수를, uniform(a, b)는 더 넓은 범위의 실수를 돌려줍니다. randint(a, b)는 양 끝을 모두 포함하는 정수를 고릅니다. 결과는 실행할 때마다 다릅니다.

import random

print(random.random())        # 0.639... (varies)
print(random.uniform(1, 10))  # 8.11... (varies)
print(random.randint(1, 6))   # one die, 1..6
print(random.randint(1, 6))   # a second roll

고르기, 섞기, 뽑기

choice(seq)는 원소 하나를 고릅니다. shuffle(list)는 리스트를 그 자리에서 섞고 None을 돌려줍니다. 그래서 names = random.shuffle(names)처럼 쓰면 리스트를 잃어버립니다. sample(seq, k)는 서로 다른 원소 k개를 뽑습니다. 모두 4주차의 리스트 위에서 동작합니다.

import random

names = ["Ara", "Ben", "Cho", "Dan"]
print(random.choice(names))            # one name
random.shuffle(names)
print(names)                           # new order
print(random.sample(range(1, 46), 6))

재현성: seed

같은 seed를 주면 같은 수열이 나오고, seed가 다르면 결과도 다릅니다. 테스트하거나 실행 결과를 재현할 때 쓰며, 게임이나 복권은 seed 없이 매번 다른 난수에 의존합니다.

import random

random.seed(42)
print(random.randint(1, 100))   # 82
print(random.randint(1, 100))   # 15

random.seed(42)
print(random.randint(1, 100))   # 82 again

게임 반복의 구조는 이렇습니다. randint(1, 100)은 반복 전에 비밀 수를 한 번만 고릅니다. 반복은 추측이 맞을 때까지 계속되고, if/elif/else로 비교하며 시도 횟수를 셉니다. 맞히면 반복을 멈춥니다. 슬라이드의 예는 추측을 리스트로 고정해 흐름만 보여 주고, 실제 프로그램은 input()으로 추측을 읽으며 break로 멈춥니다.

import random

    elif guess > secret:

    else:

NumPy: 표준 라이브러리 너머

표준 라이브러리는 Python과 함께 오지만, NumPy는 배열 계산을 위한 외부 패키지입니다. 배열은 숫자 묶음 전체를 한 번에 계산합니다. 다음 시간의 pandas와 이후의 matplotlib이 NumPy 위에 만들어져 있습니다. 슬라이드는 Colab(NumPy가 미리 설치됨)이나 내 PC(pip install numpy)에서 따라 치도록 되어 있습니다. 이 웹 실습의 가상 머신에는 NumPy가 이미 들어 있으므로 아무 페이지의 터미널에서 python3을 실행해 아래 코드를 그대로 입력해 볼 수 있습니다. 다만 import numpy는 가상 머신에서 몇 초에서 수십 초가 걸립니다.

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
counts = np.array([12, 3, 45, 7])
print(prices * counts)
# [108000 75000 180000 126000]

np.array: 리스트가 배열로

np.array는 리스트를 ndarray로 바꿉니다. 중첩 리스트는 2차원 배열이 됩니다. 아래 예에서 행은 매장, 열은 상품입니다. 재료는 이미 알고 있는 리스트입니다.

import numpy as np

r1 = [270000, 150000, 420000, 234000]
r2 = [189000, 100000, 315000, 180000]
r3 = [108000, 75000, 180000, 126000]
sales = np.array([r1, r2, r3])
print(sales)

규칙으로 배열 만들기

arange(1, 10, 2)는 끝을 제외한 범위를, zeros((2, 3))와 ones((2, 2))는 모양을 0이나 1로 채운 배열을, full((4,), 0.03)은 한 값을 반복한 배열을, linspace(0, 1, 5)는 양 끝을 포함해 고르게 나눈 값을 만듭니다.

import numpy as np

print(np.arange(1, 10, 2))    # [1 3 5 7 9]
print(np.full((4,), 0.03))    # [0.03 0.03 0.03 0.03]
print(np.linspace(0, 1, 5))   # [0.   0.25 0.5  0.75 1.  ]

seed를 준 난수 배열

np.random은 random 모듈과 비슷합니다. randint(50, 151, size=5)는 정수 다섯 개를 뽑는데, range처럼 끝 151은 제외됩니다. seed(42)로 모두가 같은 결과를 얻습니다.

import numpy as np

np.random.seed(42)
print(np.random.randint(50, 151, size=5))   # [101 142 64 121 110]
print(np.random.randint(1, 7, size=3))      # [5 2 3]

배열 읽기: shape와 dtype

shape는 (행, 열)이고 위 sales는 (3, 4)입니다. ndim은 차원 수, size는 원소 개수, dtype은 모든 원소가 공유하는 하나의 자료형입니다. 새 데이터를 받으면 먼저 shape와 dtype을 물어봅니다.

print(sales.shape, sales.ndim, sales.size)   # (3, 4) 2 12
print(sales.dtype)                           # int64

정수 배열의 기본 dtype은 환경에 따라 다릅니다. 64비트 PC에서는 보통 int64이지만, 32비트인 이 가상 머신에서는 int32로 나옵니다.

배열 하나에 dtype 하나

배열은 한 가지 자료형만 저장합니다. 정수와 실수를 섞으면 float64가 되고, 숫자와 문자열을 섞으면 모두 문자열이 됩니다. astype(np.float64)로 실수로 바꿀 수 있습니다.

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
print(prices.mean())                 # 14000.0
print(prices.astype(np.float64))     # [ 9000. 25000.  4000. 18000.]
print(np.array([9000, "event"]))     # ['9000' 'event']

인덱싱과 슬라이싱

리스트와 똑같이 인덱스와 슬라이스를 씁니다. prices[1:3]은 1에서 시작해 3 앞에서 멈춥니다. 다른 점은 슬라이스가 같은 메모리를 보는 뷰(view)라는 것입니다. 뷰를 고치면 원본도 바뀝니다. 진짜 복사본이 필요하면 prices[1:3].copy()를 씁니다.

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
view = prices[1:3]
view[0] = 9900
print(prices)   # [ 9000  9900  4000 18000]

2차원 인덱싱: [행, 열]

대괄호 한 쌍 안에 쉼표로 행과 열을 씁니다. sales[1, 2]는 칸 하나, sales[:, 1]은 열 하나 전체입니다. 두 방향 모두 슬라이스할 수 있습니다: sales[:2, 1:3].

sales = np.array([r1, r2])
print(sales[1, 2])   # 315000
print(sales[:, 1])   # [150000 100000]

조건으로 고르기: 마스크

비교 연산은 불리언 배열을 돌려주고, 그것을 인덱스로 쓰면 True인 원소만 남습니다. 마스크를 결합할 때는 and/or가 아니라 &와 |를 쓰고, 비교마다 괄호를 씌워야 합니다.

revenue = prices * counts
print(revenue[revenue >= 100000])   # [108000 180000 126000]
mask = (revenue >= 100000) & (revenue < 150000)
print(revenue[mask])                # [108000 126000]

팬시 인덱싱

위치의 리스트를 넘기면 원하는 순서로 고를 수 있고, 같은 위치를 반복해도 됩니다. 결과는 뷰가 아닌 새 배열입니다. 뒤에서 이름과 순위를 짝지을 때 씁니다.

print(prices[[3, 0]])      # [18000  9000]
print(prices[[0, 0, 1]])   # [ 9000  9000 25000]

벡터화 연산과 브로드캐스팅

연산자는 원소별로 적용됩니다. prices * 2는 모든 값을 두 배로 만들지만, 리스트에 * 2를 하면 리스트 전체가 반복됩니다. np.sqrt, np.round도 배열 전체에 적용됩니다. NumPy는 작은 모양을 큰 모양에 맞게 늘려(브로드캐스팅) 계산합니다. 숫자 하나는 배열 전체에 퍼지므로 prices * 0.9는 모든 상품을 할인합니다. 끝쪽 차원이 같거나 1이어야 합니다.

print(prices * 2)                     # [18000 50000  8000 36000]
print(prices + 1000)                  # [10000 26000  5000 19000]
print(np.sqrt(np.array([1, 4, 9])))   # [1. 2. 3.]
print(prices * 0.9)                   # [ 8100. 22500.  3600. 16200.]
promo = np.array([1000, 2000, 500, 3000])
print(prices + promo)                 # [10000 27000  4500 21000]

axis로 집계하기

sum, mean, max, min은 배열을 하나의 값으로 접습니다. axis=0은 각 열을 위에서 아래로, axis=1은 각 행을 가로로 계산합니다. 결과 길이로 확인합니다: 상품 4개, 매장 3개.

sales = np.array([r1, r2, r3])
print(sales.sum(axis=0))   # [567000 325000 915000 540000]
print(sales.sum(axis=1))   # [1074000  784000  489000]
print(sales.sum())         # 2347000

reshape, 쌓기, 정렬

reshape(4, 3)은 같은 데이터를 새 모양으로 묶습니다. 12개월을 네 분기로 나누는 식입니다. -1은 "남는 만큼"이라는 뜻이고, .T는 행과 열을 바꿉니다. 원소 개수(size)는 바뀔 수 없습니다. vstack은 배열을 새 행으로, hstack은 새 열로 이어 붙입니다(새 매장은 vstack, 새 기간은 hstack). sort는 정렬된 값을, argsort는 정렬된 위치를 돌려주므로 팬시 인덱싱과 함께 이름을 순서대로 늘어놓을 수 있습니다. argsort(-x)는 큰 것부터 순위를 매깁니다.

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))            # [470 533 592 666]
print(monthly.reshape(2, -1).shape)   # (2, 6)

wonju = np.array([90000, 60000, 120000, 70000])
sales = np.array([r1, r2])
print(np.vstack([sales, wonju]).shape)   # (3, 4)
print(np.hstack([sales, sales]).shape)   # (2, 8)

revenue = np.array([108000, 75000, 180000, 126000])
names = np.array(["mug", "shirt", "stickers", "tumbler"])
print(names[np.argsort(revenue)])
# ['shirt' 'mug' 'tumbler' 'stickers']

따라 하기: 연간 보고서

12개월 매출(단위: 만 원)을 네 분기로 reshape하고, axis=1로 분기별 합계를 구하고, argmax로 최고 매출 달의 인덱스를, argsort(-monthly)[:3]로 상위 세 달을 찾습니다.

import numpy as np

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))               # [470 533 592 666]
print(monthly.sum(), monthly.argmax())   # 2261 11
print(np.argsort(-monthly)[:3])          # [11 10  9]

Series: A Labeled Column

Making a Series

A Series is a single column of values. You make one from a list with pd.Series([...]). Here it holds the closing prices (in won) of the CODE stock. tolist() turns it back into a list.

import pandas as pd

closes = pd.Series([10000, 10200, 9800])
print(closes)
print(closes.tolist())   # [10000, ...]

Vector Math, Zero Loops

Suppose you bought CODE on Monday at 10,000 won. closes - 10000 computes each day's profit or loss in one go. mean, max, min and sum also aggregate the whole column at once. The sum of a mask (True/False) is the number of Trues, so it gives the number of up days.

closes = pd.Series([10000, 10200, 9800, 10500, 10800])
print((closes - 10000).tolist())   # [0, 200, ...]
print(closes.mean())               # 10260.0
print(closes.max())                # 10800
print((closes > 10000).sum())      # 3

The Index: Names or Rows

The index is the label of each row. The default is the positions 0, 1, 2, 3, and you can give weekday names with index=. Square brackets and .loc read by label.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes["Tue"])       # 10200
print(closes.loc["Mon"])   # 10000

Masks: Keep What You Want

A comparison returns True/False for each day and works exactly as in NumPy. closes[mask] keeps only the winning days. Combining conditions needs parentheses and &.

mask = closes > 10000
print(closes[mask].tolist())   # [10200, ...]
print(closes[mask].mean())     # 10500.0
print(mask.tolist())           # False, True, ...

DataFrame: A Table of Columns

Making a DataFrame

A DataFrame is a table of rows and columns. Here it is the portfolio on Friday evening. You make it from a dict of lists of equal length, and each column is a Series sharing a single index. CODE is yesterday's store, CodeShop.

import pandas as pd

portfolio = pd.DataFrame({
    "ticker": ["CODE", "TEA", "ROBO"],
    "shares": [10, 40, 5],
    "buy": [10000, 5000, 40000],
    "close": [10800, 4800, 45000],
})
print(portfolio)

Two Ways to Build a Frame

A dict of lists (one key per column) and a list of dicts (one dict per trade) both build the same table. The row dicts must have the same keys.

trades = [
    {"ticker": "CODE", "shares": 10},
    {"ticker": "TEA", "shares": 40},
]
log = pd.DataFrame(trades)
print(log.shape)   # (2, 2)

First Look: shape, head, columns

df.shape is (rows, columns); the portfolio above is (3, 4). df.head(n) previews the first rows and df.tail(n) the last rows, and df.columns lists the column names.

print(portfolio.shape)            # (3, 4)
print(portfolio.head(2))
print(portfolio.columns.tolist())

Selecting Columns

A single column, portfolio["close"], is a Series. For several columns, put a list of names inside the brackets (double brackets); the order of the list becomes the column order. When the name is simple, the df.col form also works.

tickers = portfolio["ticker"]
print(tickers.tolist())   # ['CODE', ...]

friday = portfolio[["ticker", "close"]]
print(friday.shape)       # (3, 2)

Rows by Position: iloc

iloc picks rows by position. portfolio.iloc[0] is the first trade, iloc[0:2] gives several rows, and negative numbers count from the end.

print(portfolio.iloc[0])
print(portfolio.iloc[0:2])
print(portfolio.iloc[-1]["ticker"])   # ROBO

  • What exactly does a mask keep? The rows (values) at the positions that are True.
  • Why must all the column lists have the same length? Because every column shares a single index.

Sorting and Statistics

Sorting: sort_values

sort_values("close") sorts by one column, and ascending=False puts the largest first. Whole rows move along with the sort key. Sorting returns a new table, so the original stays as it is.

ranked = portfolio.sort_values("close", ascending=False)
print(ranked["ticker"].tolist())
# ['ROBO', 'CODE', 'TEA']

One-Column Statistics

The column operations of a Series work as they are. describe() shows count, mean, std, min, max and the quartiles all at once. Use round(x, 2) to keep reports tidy.

closes = portfolio["close"]
print(closes.max())              # 45000
print(round(closes.mean(), 1))   # 20200.0
print(closes.describe())

Where Is the Best Row? idxmax

idxmax() returns the label of the largest value. Where NumPy's argsort ranked by position, idxmax tells you the name. You can read that whole row with .loc[label], and it works the same on a Series and on a column of a table.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes.idxmax())           # Fri
print(closes[closes.idxmax()])   # 10800

Adding Columns and Counting

New Columns from Old

Assigning adds a column to the table. invested is the amount paid (shares × buy price), and profit is (close − buy) × shares. The vector operation fills every row at once, and the table itself changes.

shares = portfolio["shares"]
buy = portfolio["buy"]
close = portfolio["close"]

portfolio["invested"] = shares * buy
portfolio["profit"] = (close - buy) * shares
print(portfolio["profit"].tolist())
# [8000, -8000, 25000]

Counting Categories: value_counts

value_counts() counts how many times each value appears and returns them from most to least frequent. We use it to count buys and sells in a trade journal, and it works on any column, strings or labels.

actions = pd.Series(["buy", "sell", "buy", "buy", "sell", "buy"])
print(actions.value_counts())
# buy: 4, sell: 2

Filtering Whole Rows

A mask on a column filters whole rows. Keeping only the rows whose close is above the buy price leaves CODE and ROBO. Masks are combined with (a) & (b) and (a) | (b). If you store the result in a new variable, the original table stays safe.

win = portfolio["close"] > portfolio["buy"]
winners = portfolio[win]
print(winners["ticker"].tolist())   # ['CODE', 'ROBO']
print(winners.shape)                # (2, 4)

가장 큰 행은 어디에: idxmax

idxmax()는 가장 큰 값의 라벨을 돌려줍니다. NumPy의 argsort가 위치로 순위를 매겼다면 idxmax는 이름을 알려 줍니다. .loc[label]로 그 행 전체를 읽을 수 있으며, Series에도 표의 열에도 똑같이 쓸 수 있습니다.

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
print(closes.idxmax())           # Fri
print(closes[closes.idxmax()])   # 10800

열 추가와 세기

기존 열로 새 열 만들기

대입하면 표에 열이 추가됩니다. invested는 산 금액(주식 수 × 매수가), profit은 (종가 − 매수가) × 주식 수입니다. 벡터 연산이 모든 행을 한 번에 채우고, 표 자체가 바뀝니다.

shares = portfolio["shares"]
buy = portfolio["buy"]
close = portfolio["close"]

portfolio["invested"] = shares * buy
portfolio["profit"] = (close - buy) * shares
print(portfolio["profit"].tolist())
# [8000, -8000, 25000]

범주 세기: value_counts

value_counts()는 값마다 몇 번 나왔는지 세고, 많은 것부터 돌려줍니다. 매매 일지에서 buy와 sell을 세는 데 쓰며, 문자열이든 라벨이든 어떤 열에도 쓸 수 있습니다.

actions = pd.Series(["buy", "sell", "buy", "buy", "sell", "buy"])
print(actions.value_counts())
# buy: 4, sell: 2

행 전체 거르기

열에 대한 마스크는 행 전체를 거릅니다. 종가가 매수가보다 높은 행만 남기면 CODE와 ROBO가 남습니다. 마스크는 (a) & (b), (a) | (b)로 결합합니다. 결과를 새 변수에 담으면 원래 표는 안전합니다.

win = portfolio["close"] > portfolio["buy"]
winners = portfolio[win]
print(winners["ticker"].tolist())   # ['CODE', 'ROBO']
print(winners.shape)                # (2, 4)

import pandas as pd

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
typed = ["4200", "4350", "4100", "4400", "4300"]

values = []
for text in typed:

closes = pd.Series(values, index=days)

print(closes.mean())     # 4270.0
print(closes.idxmax())   # Thu
