Steps실행 순서

  1. head -3 trades.csv; wc -l trades.csv

    The first line holds the column names date,ticker,action,shares,price, and below it comes one trade per line. 11 lines in total = 1 header line + 10 trades.첫 줄은 열 이름 date,ticker,action,shares,price이고, 그 아래가 거래 한 건씩이다. 전체 11줄 = 헤더 1줄 + 거래 10건.

  2. python3 journal_by_hand.py; echo "exit=$?"

    The starter opens the file, reads only the header and closes it. There is no output and exit=0. When the with block ends, the file is closed automatically.스타터는 파일을 열고 헤더만 읽은 뒤 닫는다. 출력이 없고 exit=0이다. with 블록이 끝나면 파일은 자동으로 닫힌다.

  3. python3 -c 'f = open("trades.csv"); print(repr(f.readline())); line = f.readline(); fields = line.strip().split(","); print(fields); print(fields[1], fields[2], int(fields[3]) * int(fields[4])); f.close()'

    repr shows that the header returned by readline() ends with \n. Removing it with strip() and cutting with split(",") gives a list of five strings. Even the numbers are strings like '10', so they must be converted with int() before they can be multiplied: TEA buy 50000.readline()이 돌려준 헤더 끝에 \n이 붙어 있는 것을 repr로 확인한다. strip()으로 떼고 split(",")으로 자르면 문자열 다섯 개의 리스트가 된다. 숫자도 '10'처럼 문자열이라 int()로 바꿔야 곱할 수 있다: TEA buy 50000.

  4. python3 -c 'f = open("trades.csv"); f.readline(); last = f.readline().split(",")[4]; print(repr(last), last == "5000"); f.close()'

    Splitting without strip() leaves the last field as '5000\n', which is not equal to "5000" (False). This is the trap where the newline at the end of the line ruins a comparison.strip() 없이 자르면 마지막 필드가 '5000\n'이라 "5000"과 같지 않다(False). 줄 끝 개행이 비교를 망치는 함정이다.

  5. cut -d, -f3 trades.csv | sort | uniq -c

    Count the third column (action) with shell tools to see the answer ahead of time: buy 6, sell 4 (the 1 action is the header). The finished program should print two lines, buy 6 and sell 4.셸 도구로 세 번째 열(action)을 세어 정답을 미리 본다: buy 6, sell 4(action 1은 헤더). 완성한 프로그램은 buy 6과 sell 4 두 줄을 출력해야 한다.
