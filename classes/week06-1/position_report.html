  4. printf 'class P:\n def profit(close):\n return close\nprint(P().profit(4800))\n' > no_self.py; python3 no_self.py; rm no_self.py

    Calling a method whose def leaves out self gives TypeError: P.profit() takes 1 positional argument but 2 were given.
