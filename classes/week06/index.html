journal_by_hand ~/week06/starter

Practice 1. Open the trades.csv next to the program with open(), skip the one header line, split each remaining line into fields with strip() and split(","), and count whether the action (fields[2]) is buy or sell. It is an exercise in doing by hand what pd.read_csv does.Practice 1. 옆에 있는 trades.csv를 open()으로 열어 헤더 한 줄을 건너뛰고, 나머지 줄마다 strip()과 split(",")으로 필드를 나눠 action(fields[2])이 buy인지 sell인지 센다. pd.read_csv가 하는 일을 손으로 해 보는 연습이다.

Steps실행 순서

  1. head -3 trades.csv; wc -l trades.csv

    The first line holds the column names date,ticker,action,shares,price, and below it comes one trade per line. 11 lines in total = 1 header line + 10 trades.첫 줄은 열 이름 date,ticker,action,shares,price이고, 그 아래가 거래 한 건씩이다. 전체 11줄 = 헤더 1줄 + 거래 10건.

  2. python3 journal_by_hand.py; echo "exit=$?"

    The starter opens the file, reads only the header and closes it. There is no output and exit=0. When the with block ends, the file is closed automatically.스타터는 파일을 열고 헤더만 읽은 뒤 닫는다. 출력이 없고 exit=0이다. with 블록이 끝나면 파일은 자동으로 닫힌다.

  3. python3 - <<'EOF' f = open("trades.csv") print(repr(f.readline())) line = f.readline() fields = line.strip().split(",") print(fields) print(fields[1], fields[2], int(fields[3]) * int(fields[4])) f.close() EOF

    repr shows that the header returned by readline() ends with \n. Removing it with strip() and cutting with split(",") gives a list of five strings. Even the numbers are strings like '10', so they must be converted with int() before they can be multiplied: TEA buy 50000.readline()이 돌려준 헤더 끝에 \n이 붙어 있는 것을 repr로 확인한다. strip()으로 떼고 split(",")으로 자르면 문자열 다섯 개의 리스트가 된다. 숫자도 '10'처럼 문자열이라 int()로 바꿔야 곱할 수 있다: TEA buy 50000.

  4. python3 - <<'EOF' f = open("trades.csv") f.readline() last = f.readline().split(",")[4] print(repr(last), last == "5000") f.close() EOF

    Splitting without strip() leaves the last field as '5000\n', which is not equal to "5000" (False). This is the trap where the newline at the end of the line ruins a comparison.strip() 없이 자르면 마지막 필드가 '5000\n'이라 "5000"과 같지 않다(False). 줄 끝 개행이 비교를 망치는 함정이다.

  5. cut -d, -f3 trades.csv | sort | uniq -c

    Count the third column (action) with shell tools to see the answer ahead of time: buy 6, sell 4 (the 1 action is the header). The finished program should print two lines, buy 6 and sell 4.셸 도구로 세 번째 열(action)을 세어 정답을 미리 본다: buy 6, sell 4(action 1은 헤더). 완성한 프로그램은 buy 6과 sell 4 두 줄을 출력해야 한다.

With nano journal_by_hand.py, write a for line in f: loop where the TODO is, increase the two counters, and at the end print print("buy", buys) and print("sell", sells). Run it again and compare with the shell result above.nano journal_by_hand.py로 TODO 자리에 for line in f: 반복을 쓰고 두 카운터를 늘린 뒤, 마지막에 print("buy", buys)와 print("sell", sells)를 출력한다. 다시 실행해 위 셸 결과와 같은지 비교한다.

"""Generate prices_2026.csv - one trading year of the five story stocks.
 
Deterministic: random.seed(2026) makes every run produce the same
bytes, so the committed CSV can always be regenerated and checked.
 
Story anchor: the week of 2026-03-02..03-06 is pinned to the exact
closes used across the Week 5 materials (portfolio buys match the
Monday closes; Friday closes match portfolio.csv), so exercises can
cross-check files against each other.
 
Run from this data folder:  python3 make_prices_2026.py
"""
import random
from datetime import date, timedelta
 
random.seed(2026)
 
# ticker: Mon..Fri closes of the story week (2026-03-02..03-06)
ANCHORS = {
    "CODE": [10000, 10200, 9800, 10500, 10800],
    "TEA": [5000, 4950, 4900, 4850, 4800],
    "ROBO": [40000, 39800, 41200, 43500, 45000],
    "MLBK": [2000, 2100, 1900, 2300, 2500],
    "FIT": [3000, 2900, 3100, 3700, 4200],
}
YEAR_START = date(2026, 1, 2)
YEAR_END = date(2026, 12, 31)
WEEK_START = date(2026, 3, 2)
MAX_MOVE = 0.02  # daily change is uniform in -2%..+2%
 
 
def walk(first, days, last=None):
    """Return `days` closes as a random walk starting after `first`.
 
    With `last`, the walk is linearly drifted so its final close lands
    exactly on `last`; the anchor week then joins without a jump.
    """
    prices = [first]
    for _ in range(days):
        prices.append(prices[-1] * (1 + random.uniform(-MAX_MOVE, MAX_MOVE)))
    if last is not None and days:
        drift = (last - prices[-1]) / days
        prices = [p + drift * i for i, p in enumerate(prices)]
    return [max(100, round(p)) for p in prices[1:]]
 
 
def trading_days():
    days, day = [], YEAR_START
    while day <= YEAR_END:
        if day.weekday() < 5:
            days.append(day)
        day += timedelta(days=1)
    return days
 
 
days = trading_days()
pre = [d for d in days if d < WEEK_START]
post = [d for d in days if d > WEEK_START + timedelta(days=4)]
 
columns = {}
for ticker, closes in ANCHORS.items():
    week = dict(zip((WEEK_START + timedelta(days=i) for i in range(5)), closes))
    columns[ticker] = {**dict(zip(pre, walk(closes[0], len(pre), closes[0]))),

                       **dict(zip(post, walk(closes[-1], len(post))))}
 
with open("prices_2026.csv", "w") as f:
    f.write("date," + ",".join(ANCHORS) + "\n")
    for day in days:
        f.write(day.isoformat() + ","
                + ",".join(str(columns[t][day]) for t in ANCHORS) + "\n")
 
print(f"prices_2026.csv: {len(days)} trading days, {len(ANCHORS)} tickers")

Act 1 · Files: Teach Your Program to Remember

print() talks; a file remembers. The screen is not storage; the disk is. A file is your program's memory: what you write today is still there tomorrow. In fact, you have already been using files: prices_2026.csv is a file too.

open(): Three Moves and One Trap

open(path, "w") creates a file and returns a file object. f.write(text) puts a string into the file and does nothing more. f.close() hands the file back to the system. If you forget close(), the file may be left empty or locked. Trap: write() adds no newline, so you have to write "\n" at the end of each line yourself.

report = open("summary.txt", "w")
report.write("CODE week high: 10800")
report.write("\n")
report.close()
print("Saved summary.txt")

with: The Door That Closes Itself

with open(...) as f: closes the file when the block ends. Even if an error occurs inside the block, the file is closed on the way out. No forgotten close(), no locked file, no half-written report. From this slide on, every open() is written with with.

lines = ["CODE 10800", "TEA 4800"]
with open("summary.txt", "w") as f:
    for line in lines:
        f.write(line + "\n")
print("Saved summary.txt")

Predict: if you run this script twice, how many lines will summary.txt have? The answer is in the "Modes" section below.

Reading: Three Ways to Drink from a File

read() gives the whole file as one string (the whole glass at once). readlines() gives a list of lines (poured into cups). for line in f: reads one line at a time and saves memory (one sip at a time). If you leave out the mode, the default is "r", that is, reading. Trap: every line ends with "\n", so you have to remove it with strip(). Otherwise "buy\n" is not equal to "buy".

with open("trades.csv") as f:
    header = f.readline()
    print(header.strip())         # date,ticker,...

with open("trades.csv") as f:
    print(len(f.readlines()))     # 11 with header

11 is 10 trades plus 1 header line. On the journal_by_hand page you can confirm the same number with wc -l trades.csv.

Anatomy of a CSV Line

strip() removes the hidden "\n" at the end, and split(",") cuts the line into a list of fields. Every field is a string, even "3", so turn it into a number with int(). This is exactly what read_csv does.

with open("trades.csv") as f:
    f.readline()
    line = f.readline()

fields = line.strip().split(",")
print(fields[1], fields[2],
      int(fields[3]) * int(fields[4]))
# TEA buy 50000

The output is the first trade of the week: 10 shares × 5000 won.

Modes: r Reads, w Wipes, a Adds

  • "r" reads. If the file does not exist, you get a clear FileNotFoundError.
  • "w" writes from scratch. It wipes the file before writing. Every time.
  • "a" appends. The old lines stay and new lines are added at the end.
  • A report that replaces itself uses "w"; a journal that grows uses "a".
with open("journal.txt", "a") as f:
    f.write("2026-03-09,CODE,buy,2,10900\n")

The answer to the earlier prediction: even after two runs, there are still 2 lines, because "w" wiped the first run's contents before the second run wrote.

Act 2 · Classes: You Already Talk to Objects

The dot is a sentence: "this thing, do what you know." In "CODE".upper() the string knows how to shout in capitals, in closes.mean() the Series knows how to average, and in f.write(...) the file knows how to save. An object combines data with the behavior that fits that data. Today we design such objects ourselves.

Blueprint and Buildings: class Position

class Position: draws a blueprint for a new kind of object. __init__ runs every time a Position is created, and self, the object being built right now, is always the first parameter. Everything assigned to self becomes that object's own data.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

Attributes: Every Object Packs Its Own Bag

Attributes are the data inside one object. p1 and p2 come from the same class but share nothing. p1.ticker is CODE and p2.ticker is TEA, and they do not mix. You reach an attribute with the dot: object.name.

p1 = Position("CODE", 2, 10000)
p2 = Position("TEA", 10, 5000)
print(p1.ticker, p2.shares)    # CODE 10

Methods: Teach the Object a Trick

A method is a function inside a class. self goes first in the def but is not written in the call. profit(self, close) uses self.shares and self.buy, and when you call p.profit(4800), Python passes p as self. Trap: leaving self out of the def gives the error "takes 1 positional argument but 2 were given". You can reproduce this error in the last step of the position_report page.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

    def profit(self, close):
        return (close - self.buy) * self.shares

print(Position("TEA", 40, 5000).profit(4800))   # -8000

40 shares, bought at 5000 won, now 4800. Ouch.

One Loop, Five Objects, Two Destinations

A portfolio is a list of Position objects. Each object carries its own numbers in its own bag, and one loop asks every position the same question. The answers go to two places at once: the screen and a file.

portfolio = [Position("CODE", 10, 10000),
             Position("TEA", 40, 5000),
             Position("ROBO", 5, 40000)]

with open("report.txt", "w") as f:
    for p in portfolio:
        line = p.ticker + " " + str(p.shares)
        f.write(line + "\n")
        print(line)

The screen shows CODE 10, TEA 40 and ROBO 5, and the same three lines are saved in report.txt. Check the saved file in the terminal with cat report.txt.

1막 · 파일: 프로그램에게 기억을

print()는 말하고, 파일은 기억합니다. 화면은 저장소가 아니고 디스크가 저장소입니다. 파일은 프로그램의 기억이어서 오늘 쓴 것이 내일도 남아 있습니다. 사실 여러분은 이미 파일을 써 왔습니다. prices_2026.csv도 파일입니다.

open(): 세 동작과 함정 하나

open(path, "w")는 파일을 만들고 파일 객체를 돌려줍니다. f.write(text)는 문자열을 파일에 넣을 뿐 그 이상은 하지 않습니다. f.close()는 파일을 시스템에 돌려줍니다. close()를 빼먹으면 파일이 비어 있거나 잠긴 채로 남을 수 있습니다. 함정: write()는 줄바꿈을 붙이지 않으므로 줄 끝에 "\n"을 직접 써야 합니다.

report = open("summary.txt", "w")
report.write("CODE week high: 10800")
report.write("\n")
report.close()
print("Saved summary.txt")

with: 스스로 닫히는 문

with open(...) as f:는 블록이 끝날 때 파일을 닫습니다. 블록 안에서 오류가 나도 나가는 길에 닫힙니다. 잊어버린 close()도, 잠긴 파일도, 반쯤 쓰인 보고서도 없습니다. 이 슬라이드부터 모든 open()은 with와 함께 씁니다.

lines = ["CODE 10800", "TEA 4800"]
with open("summary.txt", "w") as f:
    for line in lines:
        f.write(line + "\n")
print("Saved summary.txt")

예측해 보세요: 이 스크립트를 두 번 실행하면 summary.txt에는 몇 줄이 있을까요? 답은 아래 "모드" 절에 있습니다.

읽기: 파일을 마시는 세 가지 방법

read()는 파일 전체를 문자열 하나로 줍니다(한 잔을 통째로). readlines()는 줄의 리스트를 줍니다(여러 컵에 나눠 붓기). for line in f:는 한 번에 한 줄씩 읽어 메모리를 아낍니다(한 모금씩). 모드를 생략하면 "r", 즉 읽기가 기본입니다. 함정: 모든 줄은 "\n"으로 끝나므로 strip()으로 떼어야 합니다. 떼지 않으면 "buy\n"은 "buy"와 같지 않습니다.

with open("trades.csv") as f:
    header = f.readline()
    print(header.strip())         # date,ticker,...

with open("trades.csv") as f:
    print(len(f.readlines()))     # 11 with header

11은 거래 10건과 헤더 1줄입니다. journal_by_hand 페이지에서 wc -l trades.csv로 같은 수를 확인할 수 있습니다.

CSV 한 줄의 해부

strip()은 끝에 숨은 "\n"을 없애고, split(",")은 줄을 필드의 리스트로 자릅니다. 필드는 "3"이라도 모두 문자열이므로 int()로 숫자로 만듭니다. 이것이 바로 read_csv가 하는 일입니다.

with open("trades.csv") as f:
    f.readline()
    line = f.readline()

fields = line.strip().split(",")
print(fields[1], fields[2],
      int(fields[3]) * int(fields[4]))
# TEA buy 50000

출력은 그 주의 첫 거래, 10주 × 5000원입니다.

모드: r은 읽고, w는 지우고, a는 덧붙인다

  • "r"은 읽기입니다. 파일이 없으면 FileNotFoundError가 분명하게 납니다.
  • "w"는 처음부터 씁니다. 쓰기 전에 파일을 먼저 지웁니다. 매번.
  • "a"는 덧붙입니다. 옛 줄은 남고 새 줄이 끝에 붙습니다.
  • 스스로를 갈아치우는 보고서는 "w", 자라나는 일지는 "a".
with open("journal.txt", "a") as f:
    f.write("2026-03-09,CODE,buy,2,10900\n")

앞의 예측 문제의 답: 두 번 실행해도 여전히 2줄입니다. 두 번째 실행이 쓰기 전에 "w"가 첫 실행의 내용을 지웠기 때문입니다.

점은 하나의 문장입니다. "이것아, 네가 아는 일을 해라." "CODE".upper()에서 문자열은 대문자로 외치는 법을 알고, closes.mean()에서 Series는 평균 내는 법을, f.write(...)에서 파일은 저장하는 법을 압니다. 객체는 데이터와 그 데이터에 맞는 동작을 합친 것입니다. 오늘은 그런 객체를 직접 설계합니다.

설계도와 건물: class Position

class Position:은 새로운 종류의 객체를 위한 설계도를 그립니다. __init__은 Position이 만들어질 때마다 실행되고, self는 지금 만들어지고 있는 그 객체로서 항상 첫 번째 매개변수입니다. self에 대입한 것은 모두 그 객체 자신의 데이터가 됩니다.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

속성: 객체마다 자기 가방

속성은 한 객체 안의 데이터입니다. p1과 p2는 같은 클래스에서 나왔지만 아무것도 공유하지 않습니다. p1.ticker는 CODE, p2.ticker는 TEA이며 섞이지 않습니다. 속성은 점으로 꺼냅니다: object.name.

p1 = Position("CODE", 2, 10000)
p2 = Position("TEA", 10, 5000)
print(p1.ticker, p2.shares)    # CODE 10

메서드: 객체에게 재주 가르치기

메서드는 클래스 안의 함수입니다. self는 def에서는 첫 자리에 쓰지만 호출할 때는 쓰지 않습니다. profit(self, close)는 self.shares와 self.buy를 사용하고, p.profit(4800)을 부르면 Python이 p를 self로 넘깁니다. 함정: def에서 self를 빼먹으면 "takes 1 positional argument but 2 were given"이라는 오류가 납니다. position_report 페이지의 마지막 단계에서 이 오류를 재현해 볼 수 있습니다.

class Position:
    def __init__(self, ticker, shares, buy):
        self.ticker = ticker
        self.shares = shares
        self.buy = buy

    def profit(self, close):
        return (close - self.buy) * self.shares

print(Position("TEA", 40, 5000).profit(4800))   # -8000

40주를 5000원에 샀는데 지금은 4800원입니다. 아야.

반복 하나, 객체 다섯, 목적지 둘

포트폴리오는 Position 객체의 리스트입니다. 객체마다 자기 숫자를 자기 가방에 들고 있고, 반복문 하나가 모든 포지션에게 같은 질문을 합니다. 답은 한 번에 화면과 파일 두 곳으로 갑니다.

portfolio = [Position("CODE", 10, 10000),
             Position("TEA", 40, 5000),
             Position("ROBO", 5, 40000)]

with open("report.txt", "w") as f:
    for p in portfolio:
        line = p.ticker + " " + str(p.shares)
        f.write(line + "\n")
        print(line)

화면에는 CODE 10, TEA 40, ROBO 5가 나오고 report.txt에도 같은 세 줄이 저장됩니다. 저장된 파일은 터미널에서 cat report.txt로 확인합니다.

3막 · 차트: 설득하는 숫자

파일은 기억하고, 객체는 구조를 잡고, 차트는 설득합니다. 표는 읽는 사람이 계산하게 만들지만 선은 추세를 바로 보여 줍니다. matplotlib은 Python의 표준 그래프 라이브러리입니다. NumPy가 계산하고, pandas가 라벨을 붙이고, matplotlib이 그립니다.

설치와 별칭: plt

내 PC에서는 터미널에서 pip install matplotlib을 실행하고, Colab에는 이미 있습니다. 관례는 import matplotlib.pyplot as plt입니다. np, pd, plt는 전 세계가 똑같이 쓰는 세 글자 별칭입니다.

이 웹 실습의 가상 머신에는 matplotlib이 설치되어 있지만 화면이 없습니다. 그래서 plt.show()로 창을 띄울 수는 없고, 항상 plt.savefig("파일.png")로 그림을 파일에 저장합니다. 저장한 PNG는 cp week.png /mnt/host/로 복사한 뒤 페이지의 받기 상자에 파일 이름을 넣어 내 컴퓨터로 내려받아 엽니다. matplotlib을 불러오는 데는 수십 초가 걸릴 수 있습니다.

첫 선 그래프

plt.plot(x, y)는 점과 점을 잇는 선 하나를 그립니다. x가 먼저(요일), y가 다음(종가)입니다. figure는 캔버스이고 axes는 그 위의 차트입니다. savefig는 차트를 파일에 쓰고, 수업 중 내 PC에서는 show()로 창을 열 수 있습니다.

import matplotlib.pyplot as plt

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
closes = [10000, 10200, 9800, 10500, 10800]

plt.plot(days, closes)
plt.title("CODE closing prices")
plt.savefig("week.png")
# plt.show() opens the chart in class

제목, 축 이름, 격자, 마커

title은 차트의 이름을, xlabel과 ylabel은 축의 이름을 붙입니다. grid(True)는 눈금선을, marker="o"는 날마다 점을 찍습니다. 이름이 붙은 차트는 설명이 필요 없고, 이름 없는 차트는 사과가 필요합니다.

plt.plot(days, closes, marker="o")
plt.title("CODE closing prices")
plt.xlabel("Day")
plt.ylabel("Won")
plt.grid(True)
plt.savefig("labeled.png")

선 두 개와 범례

선마다 plot을 한 번씩 부르면 한 차트를 공유합니다. label=로 선마다 이름을 붙이고 legend()로 그 이름을 보여 줍니다. CODE가 오르는 동안 TEA가 미끄러지는 것이 출력하지 않아도 보입니다. 필요하면 linestyle="--"와 color=로 모양을 바꿉니다.

code = [10000, 10200, 9800, 10500, 10800]
tea = [5000, 4950, 4900, 4850, 4800]

plt.plot(days, code, label="CODE", marker="o")
plt.plot(days, tea, label="TEA", marker="o")
plt.legend()
plt.savefig("two.png")

pandas 지름길

Series는 스스로 그릴 수 있습니다: closes.plot(). index가 자동으로 x축이 되고, 여기서는 title=이 plot의 인자입니다. 저장은 여전히 pyplot의 plt.savefig로 합니다.

import pandas as pd
import matplotlib.pyplot as plt

closes = pd.Series([10000, 10200, 9800, 10500, 10800],
                   index=["Mon", "Tue", "Wed", "Thu", "Fri"])
closes.plot(title="CODE", marker="o")
plt.savefig("series.png")

막대 그래프: 누가 제일 큰가

plt.bar(x, y)는 범주마다 막대 하나를 그립니다. 선은 변화를, 막대는 크기를 비교합니다. 다섯 Position의 평가액을 막대로 그리면 숫자를 출력하기도 전에 ROBO가 앞서 있다는 것이 보입니다.

tickers = ["CODE", "TEA", "ROBO", "MLBK", "FIT"]

plt.title("Portfolio value")
plt.ylabel("won")
plt.savefig("values.png")

정렬한 다음 막대

큰 것부터 정렬한 막대는 한눈에 읽힙니다. sorted(zip(values, tickers))로 짝을 지어 순위를 매기고, xticks(rotation=45)로 긴 이름을 기울이며, figsize=(w, h)로 캔버스 크기를 정합니다.

pairs = sorted(zip(values, tickers), reverse=True)
plt.bar([t for v, t in pairs],
        [v for v, t in pairs])
plt.xticks(rotation=45)
plt.savefig("ranked.png")

차트 고르기

차트는 취향이 아니라 질문이 고릅니다.

  • 시간에 따라 어떻게 움직였나? 선: plt.plot.
  • 누가 제일 큰가? 막대: plt.bar.
  • 값이 얼마나 퍼져 있나? 히스토그램: plt.hist.

히스토그램: 얼마나 퍼져 있나

diff()는 날마다 전날과의 차이를 줍니다. 첫날은 전날이 없으므로 dropna()로 버립니다. plt.hist는 변화량을 구간(bin)별로 셉니다. 분포의 모양이 위험의 이야기입니다. 좁으면 잔잔하고 넓으면 거칩니다.

print(len(changes))   # 259

저장과 새 차트

savefig는 현재 figure를 파일에 씁니다. png 파일은 보고서와 슬라이드에 붙일 수 있습니다. figure()는 새로운 빈 차트를 시작하므로, 한 스크립트에서 차트 두 개를 만들려면 그 사이에 figure()가 하나 필요합니다. 함정: figure()가 없으면 막대가 선 위에 그려져 한 파일이 엉망이 됩니다. my_charts 페이지에서 비슷한 두 차트를 저장하고 내려받아 볼 수 있습니다.
