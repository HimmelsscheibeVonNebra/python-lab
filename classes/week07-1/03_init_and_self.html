03_init_and_self

__init__(self, owner, balance) is called for every new instance and stores the initial values in self.owner and self.balance. Arguments are passed at creation, as in BankAccount("Minsu", 10000).__init__(self, owner, balance)가 새 인스턴스마다 호출되어 self.owner와 self.balance에 초기값을 저장한다. BankAccount("Minsu", 10000)처럼 생성할 때 인자를 넘긴다.

"""Step 3: initialize instance attributes with __init__ and self."""
 
 
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance
 
 
minsu = BankAccount("Minsu", 10000)
jisu = BankAccount("Jisu", 5000)
print(minsu.owner, minsu.balance)
print(jisu.owner, jisu.balance)
 
minsu.balance = minsu.balance + 3000
print("After changing Minsu:", minsu.balance, jisu.balance)
