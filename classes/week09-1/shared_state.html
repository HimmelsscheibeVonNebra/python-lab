shared_state

If a mutable list is a class attribute, every instance shares that one list. A list that each instance should have for itself is created on self in __init__.변경 가능한 리스트를 클래스 속성으로 두면 모든 인스턴스가 그 리스트 하나를 함께 쓴다. 인스턴스마다 따로 가져야 할 리스트는 __init__에서 self에 만든다.

"""Runnable lecture example / 강의용 실행 예제."""
class BadBook:
    accounts = []
 
 
class IndependentBook:
    def __init__(self):
        self.accounts = []
 
 
first, second = BadBook(), BadBook()
first.accounts.append("Minsu")
print("Shared class list:", second.accounts)
first, second = IndependentBook(), IndependentBook()
first.accounts.append("Minsu")
print("Independent instance list:", second.accounts)
