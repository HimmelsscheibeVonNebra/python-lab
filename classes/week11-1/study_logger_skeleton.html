  1. ls; cat data/study.csv

CSV에는 헤더 date,course,minutes와 python 90분, stats 45분 두 행이 들어 있다.

  2. python3 main.py

    This prints Loaded 0 records and TODO: totals. It says 0 even though the file has two rows because load_records() is still a placeholder that returns an empty list. It runs, but it does not yet satisfy the requirements (REQ-03, REQ-04).Loaded 0 records와 TODO: totals가 나온다. 파일에 두 행이 있는데도 0인 이유는 load_records()가 아직 빈 리스트를 돌려주는 자리 표시이기 때문이다. 실행은 되지만 요구사항(REQ-03, REQ-04)은 아직 만족하지 못한다.

  3. python3 -c 'import logic; print(logic.make_record.__doc__)'

    The contract written in the function document (DOC 3) is there as the docstring. Read the shape of the return value {"date", "course", "minutes": int}, the lower-casing, and the conditions that raise ValueError.함수 문서(DOC 3)에 쓴 계약이 docstring으로 들어 있다. 반환값의 모양 {"date", "course", "minutes": int}, 소문자 변환, ValueError를 내는 조건을 읽어 본다.

  4. grep -nE 'def |raise NotImplementedError|TODO' *.py

    All six functions from the function table (parse_minutes, make_record, weekly_totals, load_records, append_record, format_totals) and main() are present, and each body is marked with NotImplementedError or TODO. Every function name is a verb plus a noun.함수 표의 여섯 함수(parse_minutes, make_record, weekly_totals, load_records, append_record, format_totals)와 main()이 모두 있고, 각 본문이 NotImplementedError 또는 TODO로 표시되어 있다. 함수 이름은 모두 동사+명사다.

  5. python3 -c 'from logic import parse_minutes; parse_minutes("90")'

    Calling a function that has no body yet gives a NotImplementedError: parse_minutes traceback. At the skeleton stage this is normal. From the next session on, these lines are replaced one by one with real bodies.아직 본문이 없는 함수를 호출하면 NotImplementedError: parse_minutes 트레이스백이 난다. 뼈대 단계에서는 이것이 정상이다. 다음 차시부터 이 줄을 하나씩 실제 본문으로 바꾼다.
