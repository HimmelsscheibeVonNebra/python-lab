operators ~/conditionals/solutions

Run the operator examples from the slides as short programs. Check the value and type of expressions, // and %, comparisons and ranges, short-circuiting with and / or, precedence and compound assignment. At the end, run a leap-year program that uses all of these operators (the solution to Lab 4).슬라이드의 연산자 예제를 짧은 프로그램으로 실행한다. 식의 값과 자료형, //와 %, 비교와 범위, and·or의 단락 평가, 우선순위와 복합 대입을 확인한다. 마지막에 이 연산자들을 모두 쓰는 윤년 프로그램(실습 4의 답안)을 돌려 본다.

Steps실행 순서

  1. python3 - <<'EOF' print(8 + 2, type(8 + 2)) print(8 / 2, type(8 / 2)) print("8" + "2", type("8" + "2")) EOF

    8 / 2 is the float 4.0 even though both operands are integers, and "8" + "2" is the str 82. Predict the value and type before running it.8 / 2는 정수끼리 나눠도 float 4.0이고, "8" + "2"는 str 82다. 실행 전에 값과 자료형을 먼저 예측해 본다.

  2. python3 - <<'EOF' raw = " 12 " clean = raw.strip() number = int(clean) print(repr(raw), repr(clean)) print(number + 3, clean + "3") EOF

    Seen with repr, raw still has its leading and trailing spaces. The numeric addition gives 15, and the string concatenation gives 123.repr로 보면 raw의 앞뒤 공백이 그대로 남아 있다. 숫자 덧셈은 15, 문자열 연결은 123이다.

  3. python3 - <<'EOF' a, b = 7, 3 print(a + b, a - b, a * b, a / b) print(a // b, a % b, a ** b, -7 // 3) EOF

    7 // 3 is 2, 7 % 3 is 1 and 7 ** 3 is 343. -7 // 3 rounds down, so it is -3, not -2.7 // 3은 2, 7 % 3은 1, 7 ** 3은 343이다. -7 // 3은 내림이라 -2가 아니라 -3이다.

  4. python3 - <<'EOF' minutes = 185 print(minutes // 60, minutes % 60) students = 29 print(students // 4, students % 4) print(3 * 60 + 5, 7 * 4 + 1) EOF

    Answers to the exercise: 3 hours 5 minutes, and 7 groups of 4 with 1 student left. Check that quotient × divisor + remainder gives back the original values 185 and 29.연습 문제의 답: 3시간 5분, 4명씩 7모둠에 1명 남음. 몫 × 나누는 수 + 나머지가 원래 값 185, 29로 돌아오는지 확인한다.

  5. python3 - <<'EOF' score = 85 print(score == 85, score != 85, score >= 60, 0 <= score <= 100, "85" == 85) EOF

    Comparisons return True/False. The string "85" and the integer 85 are not equal, so input must be converted before comparing.비교 결과는 True/False다. 문자열 "85"와 정수 85는 같지 않으므로 입력은 비교 전에 변환해야 한다.

  6. python3 -c 'for score in (0, 100, 101): print(score, 0 <= score <= 100, 0 < score < 100)'

    <= includes the endpoint and < excludes it. The two results differ at 0 and 100, and for 101 both are False.<=는 끝값을 포함하고 <는 제외한다. 0과 100에서 두 결과가 갈리고, 101은 둘 다 False다.

  7. python3 - <<'EOF' age = 20 has_id = True print(age >= 18 and has_id, age < 18 or has_id, not has_id) EOF

    and is True when both are true, or is True when at least one is true, and not reverses the value.and는 둘 다 참일 때, or는 하나만 참이어도 True, not은 뒤집는다.

  8. python3 - <<'EOF' n = 0 print(n != 0 and 10 / n > 2) text = "" print(text != "" and text[0] == "A") EOF

    Both print False and there is no error. The first condition is False, so 10 / n and text[0] are never evaluated (short-circuiting).둘 다 False가 나오고 오류가 없다. 앞쪽 조건이 False라 10 / n과 text[0]은 평가되지 않는다(단락 평가).

  9. python3 - <<'EOF' print(2 + 3 * 4, (2 + 3) * 4, -2 ** 2, (-2) ** 2) print(True or False and False, (True or False) and False) EOF

    14, 20, -4, 4. ** binds more tightly than unary -, so -2 ** 2 is -4. and comes before or, so the first expression is True; with parentheses it is False.14, 20, -4, 4. **가 단항 -보다 먼저라 -2 ** 2는 -4다. and가 or보다 먼저라 첫 식은 True, 괄호를 치면 False다.

  10. python3 - <<'EOF' score = 80 score += 5 print(score) x = 5 x += 3 x *= 2 print(x) EOF

    Compound assignments run in written order: 85, and then (5 + 3) × 2 = 16.복합 대입은 적힌 순서대로 실행된다: 85, 그리고 (5 + 3) × 2 = 16.

  11. for y in 2000 1900 2024; do echo $y | python3 leap_year.py; done

    A leap-year test that combines %, ==, and, or and not in one expression. After the Year: prompt you get 2000: Leap year, 1900: Not a leap year. It is worked through in detail in Lab 4.%, ==, and, or, not을 한 식에 묶은 윤년 판정이다. 프롬프트 Year: 뒤에 2000: Leap year, 1900: Not a leap year가 나온다. 자세한 풀이는 실습 4에서 한다.

string_basics ~/conditionals/solutions

Run string indices and negative indices, IndexError, slicing and reversing, immutability, strip, lower, upper, replace, split and in, string joining and f-strings, and the receipt example. At the end, run a string processing program that combines them (the solution to Lab 1).문자열 인덱스와 음수 인덱스, IndexError, 슬라이싱과 역순, 불변성, strip·lower·upper·replace·split과 in, 문자열 연결과 f-string, 영수증 예제를 실행한다. 마지막에 이를 조합한 문자열 처리 프로그램(실습 1의 답안)을 돌린다.

Steps실행 순서

  1. python3 - <<'EOF' text = "Python" print(len(text), text[0], text[2], text[-1], text[-2]) EOF

    Length 6, first character P (index 0), text[2] is t, and the negative indices -1 and -2 count from the end: n, o.길이 6, 첫 글자 P(인덱스 0), text[2]는 t, 음수 인덱스 -1과 -2는 끝에서부터 n, o다.

  2. python3 -u -c 'text = "Python"; print(text[5]); print(text[6])' 2>&1 | grep -v -e '^Traceback' -e '^ '

    With length 6, the valid indices are 0 to 5. text[5] is n, and text[6] is IndexError: string index out of range.길이 6이면 유효한 인덱스는 0~5다. text[5]는 n이고, text[6]은 IndexError: string index out of range다.

  3. python3 -u -c 'print("A"[0] == "A"[-1]); print(""[0])' 2>&1 | grep -v -e '^Traceback' -e '^ '

    In a one-character string the first and last characters are the same (True). An empty string has no valid index, so it is an IndexError.한 글자 문자열은 첫 글자와 마지막 글자가 같다(True). 빈 문자열에는 유효한 인덱스가 없어 IndexError다.

  4. python3 - <<'EOF' text = "Python" print(text[0:2], text[2:], text[:4], text[::2], text[::-1], text[:99]) EOF

    Py, thon, Pyth, Pto, nohtyP, Python. The stop index is not included, and a slice past the end, [:99], is cut at the end without an error.Py, thon, Pyth, Pto, nohtyP, Python. stop 인덱스는 포함되지 않고, 범위를 넘는 슬라이스 [:99]는 오류 없이 끝까지 잘린다.

  5. python3 - <<'EOF' text = "PYTHON" print(text[1:4], text[:3], text[-3:], text[1::2], text[::-1], repr(text[2:2])) EOF

    Answers to the exercise: YTH, PYT, HON, YHN, NOHTYP. When start and stop are equal the result is an empty string, shown by repr as ''.연습 문제의 답: YTH, PYT, HON, YHN, NOHTYP. start와 stop이 같으면 빈 문자열이고 repr로 ''가 보인다.

  6. python3 -u - <<'EOF' 2>&1 | grep -v -e '^Traceback' -e '^ ' text = "Python" text = "J" + text[1:] print(text) text[0] = "J" EOF

    Building a new string gives Jython. Strings are immutable, so assigning to text[0] gives TypeError: 'str' object does not support item assignment.새 문자열을 만들면 Jython이 된다. 문자열은 불변이라 text[0]에 대입하면 TypeError: 'str' object does not support item assignment다.

  7. python3 - <<'EOF' raw = " Hello Python " clean = raw.strip() print(clean.lower(), "|", clean.upper(), "|", clean.replace("Python", "AI")) print(clean.split(), "Python" in clean, "python" in clean) EOF

    Methods return a new string. split() makes the list ['Hello', 'Python'], and in is case-sensitive: True, False.메서드는 새 문자열을 돌려준다. split()은 ['Hello', 'Python'] 리스트를 만들고, in은 대소문자를 구별해 True, False다.

  8. python3 - <<'EOF' raw = " Hello Python " clean = raw.strip() lowered = clean.lower() slug = lowered.replace(" ", "-") print(repr(raw), clean, lowered, slug, sep=" / ") EOF

    A text-cleaning pipeline: strip affects only the ends, while replace also changes the space in the middle, giving hello-python. The original raw is unchanged.문자열 정리 과정: strip은 양끝만, replace는 가운데 공백까지 바꿔 hello-python이 된다. 원래 raw는 그대로 남아 있다.

  9. python3 - <<'EOF' name = "Mina" score = 87.5 print("Hi, " + name) print("-" * 5) print("Score: " + str(score)) print(f"{name}: {score:.2f}") print(" YES ".strip().lower() == "yes") EOF

    + joins and * repeats. To join a number with +, you need str(). After normalizing the input, " YES " equals "yes" (True).+는 연결, *는 반복이다. 숫자를 +로 붙이려면 str()이 필요하다. 입력을 정규화하면 " YES "도 "yes"와 같다(True).

  10. python3 - <<'EOF' item = "Notebook" price = 2.5 quantity = 3 total = price * quantity print(f"Item: {item}") print(f"Quantity: {quantity}") print(f"Total: {total:.2f}") print(total) EOF

    The receipt example: the display is Total: 7.50, but the total variable still holds the number 7.5.영수증 예제: 표시는 Total: 7.50이지만 total 변수에는 여전히 숫자 7.5가 들어 있다.

  11. printf ' Python \n' | python3 strings.py

    A program that combines strip, len, upper, [::-1] and an empty-string check. Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P.strip, len, upper, [::-1], 빈 문자열 검사를 조합한 프로그램이다. Length: 6, Upper: PYTHON, Reverse: nohtyP, First: P.

conditionals ~/conditionals/solutions

Run and check the order of execution of if / else, the difference between an elif chain and separate if statements, a nested condition that prevents division by zero, input validation, and a discount condition bug caused by misusing or, together with its fix. At the end, run the grade classifier (the solution to Lab 2).if / else의 실행 순서, elif 사슬과 독립된 if의 차이, 0으로 나누기를 막는 중첩 조건, 입력 검증, or를 잘못 쓴 할인 조건 버그와 수정을 실행해 확인한다. 마지막에 성적 분류 프로그램(실습 2의 답안)을 돌린다.

Steps실행 순서

  1. for age in 17 18; do python3 - <<EOF age = $age print("Start") if age >= 18: print("Adult") else: print("Under 18") print("Done") EOF done

    Exactly one of if and else runs. With 17 you get Under 18, with 18 you get Adult, and Start and Done, outside the indentation, are always printed.if와 else 중 정확히 하나만 실행된다. 17이면 Under 18, 18이면 Adult이고 들여쓰기 밖의 Start와 Done은 항상 출력된다.

  2. python3 - <<'EOF' score = 95 if score >= 90: print("A") if score >= 80: print("B") print("--- if/elif ---") if score >= 90: print("A") elif score >= 80: print("B") EOF

    Two separate if statements each check their own condition, so both A and B are printed. The elif chain stops at A, the first match.독립된 if 두 개는 각자 검사해 A와 B가 모두 나온다. elif 사슬은 처음 맞은 A에서 멈춘다.

  3. cat > /tmp/divide.py <<'EOF' a = float(input("First number: ")) b = float(input("Second number: ")) if b == 0: print("Cannot divide by zero") else: result = a / b if result < 0: print("Negative result") print(f"Result: {result:.2f}") EOF printf '7\n0\n' | python3 /tmp/divide.py echo printf -- '-6\n4\n' | python3 /tmp/divide.py

    The nested condition from the slides is saved as /tmp/divide.py and run twice. 7, 0 gives Cannot divide by zero; -6, 4 gives Negative result followed by Result: -1.50.슬라이드의 중첩 조건을 /tmp/divide.py로 저장해 두 번 실행했다. 7, 0은 Cannot divide by zero, -6, 4는 Negative result 다음에 Result: -1.50이 나온다.

  4. for t in -1 0 2; do python3 - <<EOF tickets = $t if tickets < 0: print(tickets, "Invalid quantity") else: if tickets == 0: print(tickets, "No booking") else: print(tickets, f"Booked: {tickets}") EOF done

    Validate first and put the normal processing inside else. The three cases, negative, zero and positive, each give a different message.검증을 먼저 하고 정상 처리를 else 안에 둔다. 음수·0·양수 세 경우가 각각 다른 메시지를 낸다.

  5. for c in adult student senior; do python3 - <<EOF customer = "$c" price = 100 if customer == "student" or "senior": price *= 0.8 print(customer, price) EOF done

    The bug from the debugging exercise: even adult gets the discount, 80.0. The "senior" on the right of or is a non-empty string, so it is always true.디버깅 연습의 버그: adult까지 80.0으로 할인된다. or 오른쪽의 "senior"는 비어 있지 않은 문자열이라 항상 참이다.

  6. for c in adult student senior; do python3 - <<EOF customer = "$c" price = 100 if customer == "student" or customer == "senior": price *= 0.8 print(customer, price) EOF done

    Comparing both sides with customer == gives adult 100, student 80.0, senior 80.0.양쪽을 모두 customer == 로 비교하면 adult 100, student 80.0, senior 80.0이 된다.

  7. python3 -c 'print(bool("False"), bool(""), bool("senior"))'

    "False" is also a non-empty string, so it is True. Only the empty string is False."False"도 비어 있지 않은 문자열이므로 True다. 빈 문자열만 False다.

  8. for s in 85 95 59; do echo $s | python3 grades.py; done

    An elif chain that checks the highest threshold first. After Score: you get B, A, F.높은 기준부터 검사하는 elif 사슬이다. Score: 뒤에 B, A, F가 나온다.

Review: Expression, Value & Type

An Expression Produces a Value

An expression is evaluated to produce a value. The type of that value determines which operations are allowed. Before running the code, predict both the value and its type, then check with type().

print(8 + 2)              # 10

Review: Input, Types & Output

input() returns a string, even for numeric input. Numeric text must be converted with int() or float() before you can calculate with it. An expression combines values and operators.

a = "12"

price = 12.5

Tracing Input Conversion

Treat raw as text read from input(). strip() removes surrounding whitespace, and int() creates an integer from numeric text. Converting a value does not change the original raw. With repr(), the spaces are shown as they are inside the quotes.

print(clean + "3")    # 123

The last two lines give different results because number is an integer and so is added, while clean is a string and so is concatenated.

print(a - b)     # 4
print(a * b)     # 21
print(a / b)     # 2.333...
print(a // b)    # 2
print(a % b)     # 1
print(a ** b)    # 343

Comparison Operators

== tests equality and != tests inequality. <, <=, > and >= compare sizes. Comparisons return True or False. Be careful to distinguish =, which assigns, from ==, which compares. Chaining comparisons lets you check a range at once.

score = 85
print(score == 85)          # True
print(score != 85)          # False
print(score >= 60)          # True
print(score < 60)           # False
print(0 <= score <= 100)    # True

print("85" == 85)           # False
# Convert input before comparing.

The string "85" and the integer 85 are not equal. Values read from input must be converted before comparing.

Inclusive & Exclusive Boundaries

A boundary that accepts the endpoint, like <=, is called an inclusive boundary, and one that rejects the endpoint, like <, is called an exclusive boundary. Compare the two results at 0 and 100.

score = 100
print(0 <= score <= 100)    # True
print(0 < score < 100)      # False
score = 0
print(0 <= score <= 100)    # True
print(0 < score < 100)      # False
score = 101
print(0 <= score <= 100)    # False

When testing a score range, test just below, at and just above each endpoint. This principle carries over to the boundary tests of the grade classifier in the practice part.

Logical Operators

and is true only when both conditions are true, or is true when at least one condition is true, and not reverses the truth value.

age = 20
has_id = True
print(age >= 18 and has_id)   # True
print(age < 18 or has_id)     # True
print(not has_id)             # False

n = 0
print(n != 0 and 10 / n > 2)
# False: 10 / n is never evaluated.

Boolean Results & Short-Circuiting

Summing up the four combinations: and is true only when both inputs are true, and or is false only when both inputs are false.

print(True and True)      # True
print(True and False)     # False
print(False and True)     # False
print(False and False)    # False
print(False or True)      # True
print(False or False)     # False

Once the result is already decided, Python does not evaluate the remaining operand. This is called short-circuiting. In A and B, if A is false, B is skipped. Using this, the earlier condition acts as a "guard" that keeps the later expression safe. n != 0 and 10 / n > 2 above never divides by zero, and the code below never takes text[0] from an empty string, so neither raises an error.

text = ""
print(text != "" and text[0] == "A")
# False: text[0] is not evaluated.

Precedence & Assignment Updates

** has the highest precedence, followed by * / // %, then + -. Below those come the comparison operators, then not, and and or, in that order. Use parentheses to make the intended grouping clear. +=, -= and *= update an existing variable.

print(2 + 3 * 4)        # 14
print((2 + 3) * 4)      # 20
print(-2 ** 2)          # -4
print((-2) ** 2)        # 4

score = 80
score += 5
print(score)            # 85

# Which output do you expect?
print(True or False and False)
# True

-2 ** 2 is -4 because ** is evaluated before the sign -, giving -(2 ** 2). In the last expression and comes first, so it is True or (False and False), that is, True.

For a string of length n, the nonnegative valid indices are 0 through n − 1. In a non-empty string, -1 refers to the last character. In a one-character string, the first and last characters are the same. An empty string has no valid index at all.

print(text[0])      # C
print(text[3])      # e
print(text[-1])     # e

text = "A"
print(text[0] == text[-1])   # True

# "Code"[4] raises IndexError.
# ""[0] raises IndexError.

In string_basics you can see that text[6] and ""[0] really do raise IndexError: string index out of range. Preventing indexing into an empty string is the key point of the string processing lab.

String Slicing

text[start:stop] is the substring that includes start and excludes stop. If start is omitted it starts from 0, and if stop is omitted it goes to the end. The third value is the step, and [::-1] reverses the string. A slice that goes past the end does not raise an error; it simply cuts as far as the string goes.

Strings are immutable values. Changing a single character, as in text[0] = "J", is not allowed, so you build a new string with the change and assign it again.

text = "Python"
print(text[0:2])     # Py
print(text[2:])      # thon
print(text[:4])      # Pyth
print(text[::2])     # Pto
print(text[::-1])    # nohtyP
print(text[:99])     # Python

# text[0] = "J" is invalid.
text = "J" + text[1:]
print(text)          # Jython

String Methods & Membership

String methods do not change the original string; they return a new result.

  • strip() removes whitespace from both ends.
  • lower() and upper() change the case.
  • replace(old, new) returns the replaced string.
  • split() splits a string into a list of strings.
  • in checks whether a substring is contained. It is case-sensitive.
raw = "  Hello Python  "
clean = raw.strip()
print(clean)                          # Hello Python
print(clean.lower())                  # hello python
print(clean.upper())                  # HELLO PYTHON
print(clean.replace("Python", "AI"))  # Hello AI
print(clean.split())                  # ['Hello', 'Python']
print("Python" in clean)              # True
print("python" in clean)              # False

Common Mistakes

  • To test equality, use ==, not the assignment =.
  • A missing colon or wrong indentation breaks the block.
  • To compare as numbers, convert the string first.
  • "False" is a non-empty string, so bool("False") is True.
  • When you use or, compare both cases explicitly.
choice = "paper"

# Incorrect: "scissors" is truthy.

    print("This always runs")

# Correct:
if (choice == "rock"
        or choice == "scissors"):
    print("Rock or scissors")

The incorrect code is read as (choice == "rock") or "scissors". Even if the left side is false, the "scissors" on the right is a non-empty string and is treated as true, so the whole condition is always true.
