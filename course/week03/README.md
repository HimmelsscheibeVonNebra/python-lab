# Week 3: Loops and Functions

English Python 3 code for the two Week 3 sessions. No external packages are required.

## Session 1: Loops

In `starter/session1/` and `solutions/session1/`:

- `even_sum.py`: accumulate even integers from 1 through 10.
- `input_sum.py`: read integers until zero and print the total.
- `multiplication.py`: one multiplication table and all tables from 2 through 9.
- `stars.py`: a growing triangle using nested loops.

Assume integer-formatted numeric input.

## Session 2: Functions

In `starter/session2/` and `solutions/session2/`:

- `is_even.py`: return a Boolean result.
- `power.py`: use a default exponent and keyword arguments.
- `sum_to.py`: return a loop-based sum, or None for negative input.
- `calculator.py`: return an arithmetic result, or None for unsupported operations or division by zero.

## Running

From the repository root:

```sh
python3 Codes/week03/starter/session1/input_sum.py
python3 Codes/week03/starter/session2/calculator.py
python3 Codes/week03/solutions/session2/calculator.py
```

Starter files contain intentional TODOs and are not completed solutions. Share starters with students and reveal solutions after practice. The repository's existing .gitignore excludes instructor solutions and Markdown notes.
