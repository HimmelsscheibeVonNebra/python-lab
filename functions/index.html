is_even ~/functions/starter

Practice 1: complete is_even, which returns True/False depending on whether an integer is even. Before that, check definition and calling, and the difference between print and return, with the examples from the slides.연습 1: 정수가 짝수인지 True/False로 돌려주는 is_even을 완성한다. 그 전에 정의와 호출, print와 return의 차이를 슬라이드 예제로 확인한다.

Steps실행 순서

  1. python3 - <<'EOF' def greet(): print("Hello!") print("Before") greet() greet() print("After") EOF

    def on its own prints nothing. The body runs each time the function is called, giving the order Before, Hello!, Hello!, After.def만으로는 아무것도 출력되지 않는다. 호출할 때마다 본문이 실행돼 Before, Hello!, Hello!, After 순서가 된다.

  2. python3 - <<'EOF' def cafe(): print("Americano") drink = cafe() print(drink) EOF

    The cafe challenge: Americano is what the print inside the function displayed on screen, and drink holds None.카페 문제: Americano는 함수 안의 print가 화면에 보여 준 것이고, drink에는 None이 들어 있다.

  3. python3 - <<'EOF' def cafe(): return "Americano" drink = cafe() print(drink) EOF

    Replacing print with return sends the value back to the caller, so drink holds Americano, and it is printed only once.print를 return으로 바꾸면 값이 호출한 쪽으로 돌아와 drink에 Americano가 담기고, 출력은 한 번만 된다.

  4. python3 - <<'EOF' def show_double(number): print(number * 2) def double(number): return number * 2 shown = show_double(4) saved = double(4) print(shown) print(saved + 1) EOF

    show_double(4) displays 8 but returns None. double(4) prints nothing but returns 8, so saved + 1 is 9.show_double(4)는 8을 보여 주지만 None을 돌려준다. double(4)는 아무것도 출력하지 않지만 8을 돌려줘 saved + 1이 9가 된다.

  5. python3 is_even.py

    The function in the starter code is only pass, so None is printed all four times.시작 코드의 함수는 pass뿐이라 네 번 모두 None이 출력된다.

  6. python3 ../solutions/is_even.py

sum_to ~/functions/starter

Lab 3: complete sum_to(n), which adds 1 through n with a loop and returns the result. For a negative number it returns None. First check local variables, and the problem of a return inside a loop ending the function early.실습 3: 반복문으로 1부터 n까지 더해 돌려주는 sum_to(n)을 완성한다. 음수면 None을 돌려준다. 지역 변수와, 반복문 안의 return이 함수를 일찍 끝내는 문제를 먼저 확인한다.

Steps실행 순서

  1. python3 -u - <<'EOF' 2>&1 | grep -v -e '^Traceback' -e '^ ' number = 10 def add_one(number): result = number + 1 return result print(add_one(3)) print(number) print(result) EOF

    Local variables: add_one(3) is 4, and the outer number stays 10. result inside the function cannot be used outside, giving NameError: name 'result' is not defined.지역 변수: add_one(3)은 4, 바깥 number는 그대로 10이다. 함수 안의 result는 밖에서 쓸 수 없어 NameError: name 'result' is not defined다.

  2. python3 - <<'EOF' def serve(): for number in range(1, 4): return f"Coffee for {number}" print(serve()) EOF

    The barista who leaves early: there are three customers, but the return in the first iteration ends the function, so only Coffee for 1 appears.일찍 퇴근하는 바리스타: 손님은 셋이지만 첫 반복의 return이 함수를 끝내 Coffee for 1 하나만 나온다.

  3. python3 - <<'EOF' def too_early(n): total = 0 for value in range(1, n + 1): total += value return total print(too_early(5)) print(too_early(0)) EOF

    If return is indented inside the loop, too_early(5) is 1, not 15. With n = 0 the loop never runs and never reaches the return, so the result is None.return을 반복문 안에 들여 쓰면 too_early(5)가 15가 아니라 1이다. n = 0이면 반복이 한 번도 돌지 않아 return에 닿지 못하고 None이다.

    sum_to in the starter code returns None, so the caller prints Invalid input.시작 코드의 sum_to는 None을 돌려주므로 호출한 쪽이 Invalid input을 출력한다.

Tests: 1 -> 1; 5 -> 15; 0 -> 0; -1 -> None; 3 -> 6.

    if n < 0:
        return None

    return total

Functions함수

This chapter is about functions. We learn how to define and call a function, parameters and arguments, and return values, and we distinguish between printing a result and returning it. We explain local variables and try combining several small functions.

There are four examples: the even-number predicate of Practice 1 (is_even), the power function of Practice 2 (power), the sum from 1 to n of Lab 3 (sum_to), and the calculator function of Lab 4 (calculator). Each example page also includes, as run steps, the slide examples taught before it.

What Is a Function?

Repeated Code, Different Inputs

The two calculations below follow the same rule; only the input values differ. A function gives such a calculation a reusable name, and the caller can pass different inputs each time it calls it.

price = 20
quantity = 3
print(price * quantity)   # 60

price = 12
quantity = 5
print(price * quantity)   # 60

Functions: A Name for a Task

A function is a named block of code that runs when it is called. The slides use a cafe analogy. Defining is writing down the recipe once, calling is placing an order so that it is made by that recipe, and reusing is ordering again with different input. The answer to the question "If you only write down the recipe, does coffee get made?" is "No." In the same way, a function does not run just because it is defined.

Function Inputs and Results

Arguments supply the input values, the function does the task, and return hands the result to the caller. For example, total_price(20, 3) returns 60. Some functions take no arguments. A function that does not explicitly return a value returns None.

Defining and Calling Functions

Defining a Function

def starts a function definition. Write the name of the task, and put the parameters inside the parentheses. The colon and indentation define the body. Defining a function does not run its body.

def greet():
    print("Hello!")
# No output until the function is called.

greet()
# Hello!

Calling a Function

Parentheses make a function call. Execution goes into the function body and, when the body finishes, comes back to where it was called. In this chapter's scripts, functions are defined before they are called. Each call runs the body again.

def greet():
    print("Hello!")

print("Before")
greet()
greet()
print("After")
# Before
# Hello!
# Hello!
# After

Parameters & Arguments

Parameters are the names written in the function definition, and arguments are the values the caller passes. On each call, the arguments are bound to the parameters. Inside the function, parameters behave like local variables.

def show_total(price, quantity):
    print(price * quantity)

show_total(20, 3)    # 60
show_total(12, 5)    # 60
# Parameters: price, quantity
# Arguments in the first call: 20, 3

Returning a Result

return sends a value back to the caller. The returned result can be stored in a variable or used directly in an expression. return ends the current function call right there.

def total_price(price, quantity):
    return price * quantity

amount = total_price(20, 3)
print(amount)        # 60
print(amount + 5)    # 65

Cafe Challenge: Where Is My Coffee?

Before running it, vote on what drink will hold. Will it be "Americano" or None?

def cafe():

Displaying and Returning

print() displays information on screen, and return gives a value to the caller. A function can also return a value without printing anything. If another calculation needs the result, choose return.

def show_double(number):
    print(number * 2)

def double(number):
    return number * 2

shown = show_double(4)   # Displays 8
saved = double(4)        # No output
print(shown)             # None
print(saved + 1)         # 9

Missing Return Values

A function that runs to its end without reaching a return returns None. A bare return with no value also gives None. Check that every execution path that should return a result has a return. None is a special value, not the string "None".

def broken_double(number):
    result = number * 2
    # Missing: return result

answer = broken_double(4)
print(answer)    # None
# answer + 1 would raise TypeError.

Ways to Pass Arguments

Positional & Keyword Arguments

Positional arguments bind in parameter order. Keyword arguments name the parameter directly, which makes the meaning of the call clear. In this chapter's functions, positional arguments come before keyword arguments.

def total_price(price, quantity):
    return price * quantity

# Every call prints 60.

Default Parameter Values

A default supplies a value when the caller omits the argument. If the caller explicitly gives another value, it overrides the default. Put parameters without defaults before parameters with defaults. This chapter's examples use only simple numeric defaults.

def power(base, exponent=2):
    return base ** exponent

print(power(3))               # 9
print(power(2, 3))            # 8
print(power(5, exponent=0))   # 1

Local Variables & Scope

In this chapter's examples, a name assigned inside a function is a local variable. A local variable is separate from a variable of the same name outside. Pass results explicitly as return values; the functions we write here do not use global state.

A Loop Inside a Function

A function body can contain a loop. Initialize the accumulator afresh on each call, and put the return after the loop so that it returns the completed sum. This version assumes n is an integer of 0 or more.

def sum_to(n):
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(5))    # 15
print(sum_to(3))    # 6
print(sum_to(0))    # 0

return Ends the Whole Function

return exits the function, ending any loop inside it as well. This differs from break, which exits only the nearest loop. Returning inside a loop can stop the accumulation too early.

def too_early(n):
    total = 0
    for value in range(1, n + 1):
        total += value
        return total    # Wrong indentation

print(too_early(5))     # 1, not 15
print(too_early(0))     # None

too_early(0) is None because the loop never runs, so the return is never reached. You can check both results in sum_to.

def sum_to(n):

함수란

같은 계산, 다른 입력

아래 두 계산은 같은 규칙을 따르고 입력 값만 다릅니다. 함수는 이런 계산에 다시 쓸 수 있는 이름을 붙여 주며, 호출하는 쪽은 부를 때마다 다른 입력을 넘길 수 있습니다.

price = 20
quantity = 3
print(price * quantity)   # 60

price = 12
quantity = 5
print(price * quantity)   # 60

작업에 붙인 이름

함수는 호출할 때 실행되는, 이름이 붙은 코드 블록입니다. 슬라이드는 카페에 비유합니다. 정의는 조리법을 한 번 적어 두는 것이고, 호출은 주문해서 그 조리법대로 만들게 하는 것이며, 재사용은 다른 입력으로 다시 주문하는 것입니다. "조리법을 적기만 하면 커피가 만들어질까?"라는 질문의 답은 "아니다"입니다. 함수도 정의만 해서는 실행되지 않습니다.

함수의 입력과 결과

인자(argument)가 입력 값을 주고, 함수가 작업을 하고, return이 결과를 호출한 쪽에 건네줍니다. 예를 들어 total_price(20, 3)은 60을 돌려줍니다. 인자를 받지 않는 함수도 있습니다. 반환값을 명시하지 않은 함수는 None을 돌려줍니다.

함수 정의와 호출

함수 정의하기

def로 함수 정의를 시작합니다. 작업의 이름을 쓰고, 괄호 안에 매개변수를 둡니다. 콜론과 들여쓰기가 본문을 정합니다. 함수를 정의해도 본문은 실행되지 않습니다.

def greet():
    print("Hello!")
# No output until the function is called.

greet()
# Hello!

함수 호출하기

괄호를 붙여야 함수가 호출됩니다. 실행 흐름은 함수 본문으로 들어갔다가 본문이 끝나면 호출한 곳으로 돌아옵니다. 이 장의 스크립트에서는 함수를 호출하기 전에 정의해 둡니다. 호출할 때마다 본문이 다시 실행됩니다.

def greet():
    print("Hello!")

print("Before")
greet()
greet()
print("After")
# Before
# Hello!
# Hello!
# After

매개변수와 인자

매개변수(parameter)는 함수 정의에 적힌 이름이고, 인자(argument)는 호출하는 쪽이 넘기는 값입니다. 호출할 때마다 인자가 매개변수에 연결됩니다. 매개변수는 함수 안에서 지역 변수처럼 동작합니다.

반복문을 담은 함수

함수 본문에 반복문을 넣을 수 있습니다. 누적 변수는 호출할 때마다 새로 초기화하고, 완성된 합을 돌려주도록 return은 반복문 뒤에 둡니다. 이 버전은 n이 0 이상의 정수라고 가정합니다.

def sum_to(n):
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(5))    # 15
print(sum_to(3))    # 6
print(sum_to(0))    # 0

일찍 퇴근하는 바리스타

손님 세 명이 커피를 기다리고 있습니다. 아래 코드는 메시지를 몇 개 출력할까요? 0개, 1개, 3개 중에 투표한 뒤 첫 번째 반복을 추적해 봅니다.

def serve():
    for number in range(1, 4):
        return f"Coffee for {number}"

print(serve())

답은 하나, Coffee for 1입니다. return은 현재 함수 호출을 즉시 끝내기 때문입니다. 슬라이드는 이어서 묻습니다. 반복문 안의 return을 print로 바꾸고 마지막 줄을 serve()로 바꾸면 어떻게 될까요? 그러면 반복이 끝까지 돌아 세 메시지가 모두 출력됩니다.

return은 함수 전체를 끝낸다

return은 함수를 빠져나가며, 그 안의 반복문도 함께 끝냅니다. break는 가장 가까운 반복문만 빠져나간다는 점과 다릅니다. 반복문 안에서 돌려주면 누적이 너무 일찍 멈출 수 있습니다.

def too_early(n):
    total = 0
    for value in range(1, n + 1):
        total += value
        return total    # Wrong indentation

print(too_early(5))     # 1, not 15
print(too_early(0))     # None

too_early(0)이 None인 이유는 반복이 한 번도 실행되지 않아 return에 닿지 못했기 때문입니다. 두 결과는 sum_to에서 확인할 수 있습니다.

함수의 입력과 출력 규칙

코딩하기 전에 허용하는 입력과 기대하는 출력을 정해 둡니다. sum_to는 0 이상의 정수를 받아들이고, 음수가 들어오면 잘못된 입력이라는 신호로 None을 돌려줍니다. 호출하는 쪽은 정수를 넘긴다고 가정하며, 자료형 오류 처리는 나중에 배웁니다.

def sum_to(n):
    if n < 0:
        return None
    total = 0
    for value in range(1, n + 1):
        total += value
    return total

print(sum_to(-1))   # None
print(sum_to(5))    # 15

실습 3: 1부터 n까지의 합

sum_to.py의 sum_to(n)을 반복문으로 완성합니다. 1부터 n까지 정수의 합을 돌려주고, n이 0이면 0을, 음수면 None을 돌려줍니다. sum()이나 등차수열 공식은 쓰지 않습니다. 출력은 호출하는 쪽에서만 합니다. 특별한 값 None인지는 is None으로 검사합니다.

def sum_to(n):
    # Validate, accumulate, then return.
    pass

result = sum_to(5)
if result is None:
    print("Invalid input")
else:
    print("Total:", result)

시작 코드는 None을 돌려주므로 호출하는 쪽이 Invalid input을 출력합니다. 함수를 완성하면 Total: 15가 나와야 합니다.

실습 3 확인

경계값 n = 0과 음수 입력을 테스트하고, 함수를 여러 번 호출합니다. 호출할 때마다 새 total로 시작해야 합니다. 올바른 결과 0과 None을 혼동하지 않습니다.

호출기대 반환값
sum_to(1)1
sum_to(5)15
sum_to(0)0
sum_to(-1)None
sum_to(3)6
sum_to(5)다시 15

파일 아래쪽의 호출은 sum_to(5) 하나뿐이므로, 표 전체를 확인하려면 호출을 직접 추가해 보거나 sum_to의 마지막 두 단계를 씁니다. 이 단계는 from sum_to import sum_to로 함수를 불러와 표의 여섯 호출을 한 번에 실행합니다. 첫 단계는 현재 폴더에 있는 내 파일을, 둘째 단계는 답안을 불러옵니다. import는 다음 장 '모듈과 표준 라이브러리'에서 배울 모듈 기능이며, 파일을 불러올 때 아래쪽 코드가 한 번 실행되어 그 출력이 먼저 나옵니다.

작은 함수 조합하기

한 함수의 반환값은 다른 함수의 인자가 될 수 있습니다. 함수마다 목적을 분명히 유지합니다. 아래 예는 가격을 계산한 뒤 수수료를 더합니다.

def total_price(price, quantity):
    return price * quantity

def add_fee(amount, fee=5):
    return amount + fee

subtotal = total_price(20, 3)
final = add_fee(subtotal)
print(final)    # 65

실습 4: 계산기 함수

요구 사항

calculate(a, b, operator)를 정의합니다. "+", "-", "*", "/"를 지원하고, a와 b는 숫자, operator는 문자열이라고 가정합니다. 지원하지 않는 연산자이거나 0으로 나누는 경우에는 None을 돌려줍니다. 올바른 연산에는 결과가 0이어도 숫자 결과를 돌려줍니다.

호출반환값
calculate(8, 2, "+")10
calculate(8, 2, "-")6
calculate(8, 2, "*")16
calculate(8, 2, "/")4.0
calculate(8, 0, "/")None
calculate(8, 2, "%")None

calculator.py 완성하기

if, elif, return으로 calculator.py를 완성합니다. 입력과 출력은 calculate() 밖에 둡니다. 숫자 결과를 표시하기 전에 None인지 먼저 검사하고, 올바른 결과 0은 정상적으로 표시되어야 합니다.

def calculate(a, b, operator):
    # Return a result or None.
    pass

result = calculate(8, 2, "+")
if result is None:
    print("Invalid operation")
else:
    print("Result:", result)

선택 과제는 호출하는 쪽에서 a, b, 연산자를 입력받아 calculate()를 호출하는 것입니다.

실습 4 확인

지원하는 네 연산을 모두 확인하고, 0으로 나누기와 지원하지 않는 연산자를 테스트합니다. 음수와 결과가 0인 경우도 시험합니다. 함수는 출력하지 않고 값만 돌려줘야 합니다.

추가 호출반환값
calculate(2, 2, "-")0
calculate(-3, 2, "*")-6
calculate(0, 5, "/")0.0

결과를 검사할 때 if not result는 쓰지 않습니다. 올바른 결과 0을 거짓으로 취급하기 때문입니다. 대신 if result is None을 씁니다. calculator에서 두 표의 아홉 호출을 한 번에 실행하고, not result와 result is None이 0에 대해 다르게 판단하는 것을 확인할 수 있습니다.

함수에서 자주 하는 실수

  • 함수 이름만 쓰고 괄호를 붙이지 않으면 호출되지 않습니다.
  • 필수 인자를 너무 적게 넘기면 TypeError가 납니다.
  • 값을 출력한다고 그 값이 호출한 쪽에 돌아가지는 않습니다.
  • 반복문 안의 return은 작업을 너무 일찍 끝낼 수 있습니다.
  • 지역 변수는 함수 밖에서 바로 쓸 수 없습니다.

버그마다 함수 정의, 호출, 반환값을 각각 찾아 봅니다. 앞의 두 실수는 power의 마지막 단계에서 재현됩니다. 괄호 없이 쓰면 <function total_price at ...>만 보이고, 인자를 하나 빠뜨리면 missing 1 required positional argument 오류가 납니다.

테스트와 제출

is_even.py, power.py, sum_to.py, calculator.py를 제출합니다.

  • 함수는 값을 돌려주고, 표시는 호출하는 쪽에서 합니다.

  • 경계값과, 함수 규칙이 요구하는 잘못된 입력을 포함합니다.
  • 여러 번 호출해도 서로 독립적인 결과가 나오는지 확인합니다.

이번 연습에는 컬렉션과 예외 처리가 필요하지 않습니다. 완성한 파일은 cp calculator.py /mnt/host/처럼 복사한 뒤 페이지의 받기 상자로 내 컴퓨터에 내려받을 수 있습니다.

확인 퀴즈

  1. def power(base, exponent=2)에서 매개변수는? base와 exponent입니다.
  2. power(3)은 무엇을 돌려주는가? 기본값 2를 써서 9입니다.
  3. return이 없는 함수는 무엇을 만드는가? None입니다.
  4. sum_to()에서 return을 반복문 뒤에 두는 것이 왜 중요한가? 반복문 안에 두면 첫 반복에서 함수가 끝나 합이 완성되지 않습니다.
  5. 계산기에서 not result 대신 result is None을 쓰는 이유는? 올바른 결과 0도 not result에서는 참이 되어 잘못된 연산으로 오해받기 때문입니다.

마지막으로, 호출한 쪽이 함수로부터 어떻게 값을 받는지 자기 말로 설명해 봅니다.

다음 장: 모듈

모듈은 다시 쓸 코드를 파이썬 파일 하나로 묶은 것입니다. import로 모듈의 함수를 가져다 씁니다. 다음 장 '모듈과 표준 라이브러리'에서는 math, random 같은 표준 라이브러리 모듈을 살펴보고, 자기 함수를 모듈에 넣어 다른 파일에서 다시 쓰는 법을 배웁니다.

import math
