even_sum ~/loops/starter

Practice 1: add only the even integers from 1 to 10 to total and print 30. Before that, check how for, range() and an accumulator variable behave using the examples from the slides.연습 1: 1부터 10까지의 정수 중 짝수만 total에 더해 30을 출력한다. 그 전에 for, range(), 누적 변수의 동작을 슬라이드 예제로 확인한다.

Steps실행 순서

  1. python3 - <<'EOF' for letter in "ABC": print(letter) print("Done") EOF

    On each iteration the next character goes into letter. After A, B, C the loop ends and Done is printed once.반복마다 다음 글자가 letter에 들어간다. A, B, C 다음 반복이 끝나고 Done이 한 번 출력된다.

  2. python3 - <<'EOF' for i in range(3): print(i, end=" ") print("| range(3)") for i in range(1, 4): print(i, end=" ") print("| range(1, 4)") for i in range(2, 7, 2): print(i, end=" ") print("| range(2, 7, 2)") for i in range(3, 0, -1): print(i, end=" ") print("| range(3, 0, -1)") for i in range(3, 0): print(i, end=" ") print("| range(3, 0)") EOF

    The stop value is always left out: 0 1 2, 1 2 3, 2 4 6, 3 2 1. range(3, 0), whose direction is wrong, is empty and gives no values.stop 값은 언제나 빠진다: 0 1 2, 1 2 3, 2 4 6, 3 2 1. 방향이 맞지 않는 range(3, 0)은 비어 있어 아무 값도 없다.

  3. python3 -u -c 'range(1, 5, 0)' 2>&1 | grep -v -e '^Traceback' -e '^ '

    A step of 0 gives ValueError: range() arg 3 must not be zero.step이 0이면 ValueError: range() arg 3 must not be zero다.

  4. python3 - <<'EOF' total = 0 for n in range(1, 6): before = total total += n print(n, before, total) print("final:", total) EOF

    An accumulator trace table: each line is n, total before adding and total after adding. Each iteration carries on from the previous total, giving 1, 3, 6, 10, 15.누적 추적표: 각 줄은 n, 더하기 전 total, 더한 뒤 total이다. 이전 total을 이어받아 1, 3, 6, 10, 15가 된다.

  5. python3 - <<'EOF' for n in range(1, 6): total = 0 total += n print("final:", total) EOF

    The question from the slides: if total = 0 is put inside the loop, it is reset every time and only the last value, 5, remains.슬라이드의 질문: total = 0을 반복문 안에 두면 매번 초기화돼 마지막 값 5만 남는다.

  6. python3 even_sum.py

    The starter code has only pass, so it adds nothing and prints 0.시작 코드는 pass만 있어 아무것도 더하지 않고 0을 출력한다.

  7. python3 ../solutions/even_sum.py

    Adding only when n % 2 == 0 gives 2 + 4 + 6 + 8 + 10 = 30.if n % 2 == 0일 때만 더하면 2 + 4 + 6 + 8 + 10 = 30이다.

input_sum ~/loops/starter

Practice 2: read integers one at a time with while True, break when 0 is entered, and print the total. First check the execution order of while, break and continue.연습 2: while True로 정수를 하나씩 입력받아 0이 나오면 break하고 합계를 출력한다. while의 실행 순서, break, continue를 먼저 확인한다.

Steps실행 순서

  1. python3 - <<'EOF' count = 1 while count <= 3: print(count) count += 1 print("Done", count) EOF

    The condition is tested first and then the body runs. The loop exits when count becomes 4 and the condition is False, so you get Done 4. Without count += 1 it is an infinite loop.조건을 먼저 검사하고 본문을 실행한다. count가 4가 되어 조건이 False일 때 빠져나오므로 Done 4다. count += 1이 없으면 무한 반복이다.

  2. cat > /tmp/echo_q.py <<'EOF' while True: text = input("Message (q: quit): ") if text == "q": break print("Input:", text) print("Done") EOF printf 'hello\nhi\nq\n' | python3 /tmp/echo_q.py

    The break example is saved as /tmp/echo_q.py and given hello, hi and q. hello and hi are echoed back with Input:, and q ends the loop with no output, so Done is printed.break 예제를 /tmp/echo_q.py로 저장하고 hello, hi, q를 넣었다. hello와 hi는 Input:으로 되돌려 주고, q에서는 출력 없이 반복을 끝내 Done이 나온다.

  3. python3 - <<'EOF' for n in range(1, 6): if n == 3: continue print(n) EOF

    continue skips only the rest of the current iteration. Only 3 is left out, and 1, 2, 4, 5 are printed.continue는 이번 반복의 나머지만 건너뛴다. 3만 빠지고 1, 2, 4, 5가 출력된다.

  4. printf '3\n5\n0\n' | python3 input_sum.py

    The starter code does stop at 0, but there is no code that adds, so it prints Total: 0.시작 코드는 0에서 멈추긴 하지만 더하는 코드가 없어 Total: 0이다.

  5. printf '3\n5\n0\n' | python3 ../solutions/input_sum.py printf '0\n' | python3 ../solutions/input_sum.py printf -- '-2\n5\n0\n' | python3 ../solutions/input_sum.py

    Three tests: 3, 5, 0 gives Total: 8; 0 right away gives Total: 0; -2, 5, 0 gives Total: 3. Check for 0 first, then add.세 테스트: 3, 5, 0은 Total: 8, 바로 0이면 Total: 0, -2, 5, 0은 Total: 3. 0인지 먼저 검사한 뒤 더한다.

You can also run python3 input_sum.py yourself, enter numbers one at a time and finish with 0. If you get stuck in an infinite loop by mistake, stop it with Ctrl+C (the Stop button in Colab).직접 python3 input_sum.py로 실행해 숫자를 하나씩 입력하고 0으로 끝내 봐도 된다. 실수로 무한 반복에 빠지면 Ctrl+C로 멈춘다(Colab에서는 Stop 버튼).

multiplication ~/loops/starter

Lab 3: read a table number from 2 to 9 and print its 9 equations (Invalid table if out of range), then use nested loops to print all 72 equations of the tables from 2 to 9.실습 3: 2~9 사이의 단을 입력받아 그 단의 9개 식을 출력하고(범위 밖이면 Invalid table), 이어서 중첩 반복문으로 2단부터 9단까지 72개 식을 모두 출력한다.

Steps실행 순서

  1. python3 - <<'EOF' for row in range(1, 3): for col in range(1, 4): print(row, col) EOF

    For each outer row, the inner col goes through all of 1, 2, 3. 2 × 3 = 6 pairs are printed.바깥 row 하나마다 안쪽 col이 1, 2, 3을 모두 돈다. 2 × 3 = 6쌍이 출력된다.

  2. echo 7 | python3 multiplication.py

    Starter code: the part that prints one table is empty, and the inner part of the full tables is pass, so after All tables: there are only 8 empty lines (one print() per table).시작 코드: 단 하나 출력 부분이 비어 있고, 전체 구구단도 안쪽이 pass라 All tables: 뒤에 빈 줄 8개만 나온다(단마다 print() 한 번).

  3. echo 7 | python3 ../solutions/multiplication.py | head -11

    Solution: 9 equations from 7 x 1 = 7 to 7 x 9 = 63, followed by All tables: and 2 x 1 = 2.답안: 7 x 1 = 7부터 7 x 9 = 63까지 9개 식 다음에 All tables:와 2 x 1 = 2가 이어진다.

  4. echo 7 | python3 ../solutions/multiplication.py | grep -c ' = ' echo 1 | python3 ../solutions/multiplication.py | grep -c ' = '

    Counts the equations. The valid 7 gives 9 + 72 = 81; the invalid 1 gives only the 72 of the full tables.식의 개수를 센다. 유효한 7은 9 + 72 = 81개, 잘못된 1은 전체 구구단 72개뿐이다.

  5. for t in 1 10; do echo $t | python3 ../solutions/multiplication.py | head -1; done

    1 and 10 give Invalid table. The full tables come after the input validation block, so that part always runs.1과 10은 Invalid table이다. 입력 검증 블록 다음에 전체 구구단이 있으므로 그 부분은 항상 실행된다.

  6. echo 9 | python3 ../solutions/multiplication.py | grep -n '9 x 9 = 81'

    Boundary value 9: 9 x 9 = 81 appears twice, at the end of the single table (line 9) and at the end of the full tables (line 89). After line 89 comes the empty line that follows the 9 table.경계값 9: 9 x 9 = 81이 단 하나 출력의 마지막(9번 줄)과 전체 구구단의 마지막(89번 줄)에 두 번 나온다. 89번 줄 다음은 9단 뒤의 빈 줄이다.

Loops반복문

This chapter is about loops. We learn for, range() and while as ways to do the same task many times, and trace how an accumulator variable changes on each iteration and when a loop stops. After learning to use break and continue as intended, we use nested loops, a loop inside a loop, to make multiplication tables and star patterns.

There are four examples: the even-number sum of Practice 1 (even_sum), the sum until zero of Practice 2 (input_sum), the multiplication tables of Lab 3 (multiplication), and the star triangle of Lab 4 (stars). Each example page also includes, as run steps, the slide examples taught before it.

Review: One Student's Result

An if statement selects which block runs. A score of 60 or more is a pass.

score = 75
if score >= 60:
    print("Pass")
else:
    print("Fail")
# Output: Pass

But what if there are 30 students? Instead of copying the same code 30 times, we repeat the same processing with a loop.

for: One Value at a Time

Place the sequence after the in that follows for. On each iteration, the next value goes into the variable. The colon and four-space indentation define the body of the loop. After the last value is processed, the loop ends and the code outside the indentation runs.

for letter in "ABC":
    print(letter)
print("Done")

# Output
# A
# B
# C
# Done

Integer Ranges with range()

range(stop) starts at 0. range(start, stop) includes start. In either case, the stop value is always left out. A range represents a sequence of integers; it is not a list.

for i in range(3):
    print(i)
# 0, 1, 2 on separate lines

for i in range(1, 4):
    print(i)
# 1, 2, 3 on separate lines

Steps & Reverse Ranges

The third argument is the step. A negative step counts backwards. If the direction does not match, the range is empty and the body never runs, and a step of 0 raises a ValueError.

for i in range(2, 7, 2):
    print(i)
# 2, 4, 6

for i in range(3, 0, -1):
    print(i)
# 3, 2, 1

for i in range(3, 0):
    print(i)
# No output

In the first steps of even_sum you can print five ranges, one per line, and also see the ValueError from range(1, 5, 0).

Accumulating a Total

Initialize the variable total, which holds the sum, before the loop. total += n is the same as total = total + n. Print the final result after the loop ends.

total = 0
for n in range(1, 6):
    total += n
print(total)
# 15

The question on the slides is "What happens if total = 0 is put inside the loop?" Then it goes back to 0 on every iteration, so only the 5 added in the last iteration remains. Run both cases in even_sum.

Practice 1: Sum of Even Numbers

Go through the integers from 1 to 10 in order, pick out the even ones with if and %, and add them to total. The expected result is 30. Take 5 minutes to solve it.

total = 0
for n in range(1, 11):
    # Add your condition and update here.
    pass
print(total)

pass is a placeholder statement that does nothing. It temporarily fills a place where the syntax requires a body. So if you run the starter code as it is, it adds nothing and prints 0. Adding only when n % 2 == 0 gives 2 + 4 + 6 + 8 + 10 = 30 (even_sum).

while: Repeat While True

while tests the condition before running the body. If the condition is false from the start, the body never runs. To end the loop, the body must change the value used in the condition.

count = 1
while count <= 3:
    print(count)
    count += 1
print("Done", count)
# 1
# 2
# 3
# Done 4

Execution Order & Infinite Loops

It proceeds in this order: initialize, check the condition, run the body, check the condition again.

countcount <= 3Action
1TruePrint 1
2TruePrint 2
3TruePrint 3
4FalseExit the loop

Without count += 1, the condition stays true and the loop never ends. Stop a running loop with Ctrl+C in a terminal, or with the Stop button in Colab. Ctrl+C also works in this lab's terminal.

break: Exit the Loop

Consider repeating input until the user asks to stop. break exits the nearest loop that encloses it. If the input is q, it skips the echo output and leaves the loop.

while True:
    text = input("Message (q: quit): ")
    if text == "q":
        break
    print("Input:", text)
print("Done")

In input_sum this code is saved to a file, and you can see the result of entering hello, hi and q in turn.

continue: Skip This Iteration

continue skips the remaining statements in the current iteration and moves on to the next iteration. When you use it in a while loop, be careful not to skip, by mistake, the update statement that makes the loop stop.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

# Output
# 1
# 2
# 4
# 5

Choosing for or while

  • To process each character in a string: for
  • To repeat a fixed number of times: for with range()
  • To repeat while a condition holds: while
  • Both loops can contain if statements.

while: 조건이 참인 동안 반복

while은 본문을 실행하기 전에 조건을 검사합니다. 처음부터 조건이 거짓이면 본문은 한 번도 실행되지 않습니다. 반복을 끝내려면 조건에 쓰인 값을 본문에서 바꿔야 합니다.

count = 1
while count <= 3:
    print(count)
    count += 1
print("Done", count)
# 1
# 2
# 3
# Done 4

실행 순서와 무한 반복

초기화하고, 조건을 검사하고, 본문을 실행하고, 다시 조건을 검사하는 순서로 진행됩니다.

count += 1이 없으면 조건이 계속 참이라 반복이 끝나지 않습니다. 터미널에서는 Ctrl+C로, Colab에서는 Stop 버튼으로 실행 중인 반복을 멈춥니다. 이 실습실의 터미널에서도 Ctrl+C가 동작합니다.

break: 반복문 빠져나가기

사용자가 끝내자고 할 때까지 입력을 반복하는 경우를 생각해 봅니다. break는 자신을 감싸는 가장 가까운 반복문을 빠져나갑니다. 입력이 q이면 되돌려 주는 출력을 건너뛰고 반복을 떠납니다.

while True:
    text = input("Message (q: quit): ")
    if text == "q":
        break
    print("Input:", text)
print("Done")

input_sum에서는 이 코드를 파일로 저장해 hello, hi, q를 차례로 입력한 결과를 볼 수 있습니다.

continue: 이번 반복만 건너뛰기

continue는 현재 반복의 나머지 문장을 건너뛰고 다음 반복으로 넘어갑니다. while 반복문에서 쓸 때는 반복을 멈추게 하는 갱신문까지 실수로 건너뛰지 않도록 주의합니다.

for n in range(1, 6):
    if n == 3:
        continue
    print(n)

# Output
# 1
# 2
# 4
# 5

for와 while 고르기

  • 문자열의 문자를 하나씩 처리할 때: for
  • 정해진 횟수만큼 반복할 때: range()와 함께 쓰는 for
  • 조건이 유지되는 동안 반복할 때: while
  • 두 반복문 모두 안에 if 문을 넣을 수 있습니다.

다음 세 경우에 어떤 반복문을 쓸지 고르고 이유를 설명해 봅니다. (1) 단어의 각 문자 출력하기, (2) 사용자가 q를 입력할 때까지 메시지 읽기, (3) 7단을 1부터 9까지 출력하기. 차례로 문자열에 대한 for, 끝나는 시점을 미리 모르는 while, 횟수가 정해진 range()의 for가 자연스럽습니다.

  • 행을 끝내는 print()는 안쪽 반복문 뒤에 둡니다.

실행하기 전에는 첫 번째 반복, 마지막 반복, 최종 출력을 예측합니다. 디버깅할 때는 반복 변수와 누적 변수를 임시로 출력해 봅니다.

다음 장: 함수

다음 장 '함수'에서는 def로 재사용할 작업에 이름을 붙이고, 매개변수로 값을 넘기고, 결과를 돌려받아 호출한 쪽에서 쓰는 방법을 배웁니다. 반복문으로 계산하던 코드를 재사용할 수 있는 함수로 바꾸는 것도 해 봅니다. 준비로, 짝수 합 프로그램의 입력과 출력이 무엇인지 생각해 둡니다. 리스트, 튜플, 딕셔너리, 집합은 뒤에서 다룹니다.
