math_practice ~/modules/starter

Practice 1. Read a radius and print the circle's area and circumference, then read two legs and print the hypotenuse. math.pi and math.hypot, loaded with import math, are reached with the dot (.).Practice 1. 반지름을 읽어 원의 넓이와 둘레를, 두 변을 읽어 빗변을 출력한다. import math로 불러온 math.pi와 math.hypot을 점(.)으로 꺼내 쓴다.

Steps실행 순서

  1. printf '3\n3\n4\n' | python3 math_practice.py

    Runs the program with the inputs 3, 3, 4 fed in ahead of time (you can also run python3 math_practice.py yourself and type them). The starter only has TODOs, so the prompts Radius: First leg: Second leg: come out run together on one line with no results. Piped input is not echoed to the screen, which is why the prompts look glued together.입력 3, 3, 4를 미리 넣어 실행한다(직접 python3 math_practice.py로 실행해 입력해도 된다). 스타터는 TODO만 있어서 프롬프트 Radius: First leg: Second leg: 만 한 줄로 이어 나오고 결과는 없다. 파이프로 넣은 입력은 화면에 다시 찍히지 않기 때문에 프롬프트가 붙어 보인다.

  2. printf '3\n3\n4\n' | python3 ../solutions/math_practice.py

    The finished version prints Area: 28.27, Circumference: 18.85, Hypotenuse: 5.0. round(..., 2) keeps two decimal places.완성본은 Area: 28.27, Circumference: 18.85, Hypotenuse: 5.0을 출력한다. round(..., 2)로 소수 둘째 자리까지 맞췄다.

  3. printf '1\n5\n12\n' | python3 ../solutions/math_practice.py

    Second test: with radius 1 the area is 3.14 (equal to π) and the circumference is 6.28. The hypotenuse of 5 and 12 is 13.0.두 번째 테스트: 반지름 1이면 넓이는 π와 같은 3.14, 둘레는 6.28이다. 5와 12의 빗변은 13.0이다.

  4. python3 - <<'EOF' import math print(math.floor(2.5), math.ceil(2.5), math.factorial(5), math.gcd(12, 18), math.hypot(3, 4)) EOF

    Checks the math functions from the slides in one go: 2 3 120 6 5.0. Floor, ceil, factorial, greatest common divisor and hypotenuse.슬라이드의 math 함수들을 한 번에 확인한다: 2 3 120 6 5.0. 내림·올림, 계승, 최대공약수, 빗변이다.

  5. python3 -c 'print(sqrt(16))'

    Using sqrt without importing it gives NameError: name 'sqrt' is not defined. Read the traceback from the last line.import 없이 sqrt를 쓰면 NameError: name 'sqrt' is not defined가 난다. Traceback은 마지막 줄부터 읽는다.

  6. python3 -c 'from math import sqrt, pi; print(sqrt(16)); print(pi)'

    from math import sqrt, pi brings the names in directly, so you can use them without a prefix: 4.0 and 3.141592653589793.from math import sqrt, pi로 이름을 직접 가져오면 접두사 없이 쓸 수 있다: 4.0과 3.141592653589793.

The NameError in the fifth step is on purpose. In the actual practice, fill in the TODOs with nano math_practice.py, then rerun the first step and compare its output with the finished version.다섯 번째 단계의 NameError는 일부러 낸 오류다. 실제 실습에서는 nano math_practice.py로 TODO를 채운 뒤 첫 단계를 다시 실행해 완성본과 같은 출력이 나오는지 비교한다.

Read a date in YYYY-MM-DD format, turn it into a date with datetime.strptime, and print its weekday name (strftime("%A")) and the number of days remaining from today (date.today()).Practice 2. YYYY-MM-DD 형식의 날짜를 읽어 datetime.strptime으로 날짜로 바꾸고, 요일 이름(strftime("%A"))과 오늘(date.today())부터 남은 날 수를 출력한다.

  2. date +%F

    This is today's date as the virtual machine sees it. The days remaining below are counted from this date.가상 머신이 생각하는 오늘 날짜다. 아래 남은 날 수는 이 날짜를 기준으로 계산된다.

  3. printf '2026-12-25\n' | python3 ../solutions/date_check.py

    Christmas 2026 is a Friday. The Days remaining value depends on today's date.2026년 성탄절은 Friday다. Days remaining 값은 오늘 날짜에 따라 달라진다.

  4. date +%F | python3 ../solutions/date_check.py

    Feeding in today's date gives Days remaining: 0.오늘 날짜를 그대로 넣으면 Days remaining: 0이다.

  5. printf '2026-01-01\n' | python3 ../solutions/date_check.py

    A date that has already passed gives a negative number of days remaining. 2026-01-01 is a Thursday.이미 지난 날짜는 남은 날 수가 음수로 나온다. 2026-01-01은 Thursday다.

  6. python3 - <<'EOF' from datetime import date, timedelta today = date(2026, 9, 27) exam = date(2026, 11, 13) print((exam - today).days) print(today + timedelta(days=100)) EOF

    Date arithmetic from the slides: the difference of two dates is a timedelta whose .days is 47, and the date + 100 days is 2027-01-05.슬라이드의 날짜 계산: 두 날짜의 차는 timedelta이고 .days는 47, 날짜 + 100일은 2027-01-05다.

def average(numbers):
    return sum(numbers) / len(numbers)
 
 
def count_above(numbers, limit):
    count = 0
    for value in numbers:
        if value > limit:
            count += 1
    return count

Modules and import

What Is a Module?

A module is a file containing Python definitions (functions, variables and so on). The file name minus .py is the module name. For example, greetings.py is the greetings module. Importing a module runs its top-level code once. In fact, every program you have written so far was already a module.

# File: greetings.py
def hello(name):
    return "Hello, " + name + "!"

import and the Dot

import math loads the math module. The dot reaches a name inside the module: math.sqrt(2) means "the sqrt inside the math module". Keeping the prefix makes it clear from the code alone where each name came from. Python remembers (caches) a module after its first import, so importing the same module again does not run it again.

import math

print(math.pi)           # 3.141592653589793
print(math.sqrt(2))      # 1.4142135623730951
print(math.floor(2.9))   # 2

from module import name

If you import only the names you need, you can use them without a prefix. You can list several names separated by commas, and you can also rename a name while importing it. Only the imported names become visible: writing math.pi after from math import sqrt fails because there is no name math.

from math import sqrt, pi

print(sqrt(16))   # 4.0
print(pi)         # 3.141592653589793

Formatting Dates: strftime

strftime turns a date into a string in the layout you want. %Y, %m and %d are the year, month and day, and %A is the full weekday name. You can build exactly the string a report needs.

random: Random Numbers

Floats and Integers

random() returns a float from 0.0 up to, but not including, 1.0, and uniform(a, b) returns a float over a wider range. randint(a, b) picks an integer with both ends included. The results differ on every run.

import random

print(random.random())        # 0.639... (varies)
print(random.uniform(1, 10))  # 8.11... (varies)
print(random.randint(1, 6))   # one die, 1..6
print(random.randint(1, 6))   # a second roll

Pick, Shuffle, Sample

choice(seq) picks one element. shuffle(list) mixes the list in place and returns None, so writing names = random.shuffle(names) loses the list. sample(seq, k) picks k different elements. All of these work on lists.

import random

names = ["Ara", "Ben", "Cho", "Dan"]
print(random.choice(names))            # one name
random.shuffle(names)
print(names)                           # new order
print(random.sample(range(1, 46), 6))

Repeatability: seed

The same seed produces the same sequence, and different seeds give different results. Seeds are used for testing and for reproducing a run; games and lotteries rely on unseeded randomness that differs every time.

import random

random.seed(42)
print(random.randint(1, 100))   # 82
print(random.randint(1, 100))   # 15

random.seed(42)
print(random.randint(1, 100))   # 82 again

np.array: Lists Become Arrays

np.array turns a list into an ndarray. A nested list becomes a 2D array. In the example below, rows are stores and columns are products. The ingredients are lists you already know.

import numpy as np

r1 = [270000, 150000, 420000, 234000]
r2 = [189000, 100000, 315000, 180000]
r3 = [108000, 75000, 180000, 126000]
sales = np.array([r1, r2, r3])
print(sales)

Arrays by Recipe

arange(1, 10, 2) makes a range that excludes the end; zeros((2, 3)) and ones((2, 2)) make arrays of a given shape filled with 0 or 1; full((4,), 0.03) makes an array repeating one value; and linspace(0, 1, 5) makes evenly spaced values including both ends.

import numpy as np

print(np.arange(1, 10, 2))    # [1 3 5 7 9]
print(np.full((4,), 0.03))    # [0.03 0.03 0.03 0.03]
print(np.linspace(0, 1, 5))   # [0.   0.25 0.5  0.75 1.  ]

Random Arrays, Seeded

np.random is similar to the random module. randint(50, 151, size=5) draws five integers, and as with range the end 151 is excluded. With seed(42) everyone gets the same result.

import numpy as np

np.random.seed(42)
print(np.random.randint(50, 151, size=5))   # [101 142 64 121 110]
print(np.random.randint(1, 7, size=3))      # [5 2 3]

Reading an Array: shape and dtype

shape is (rows, columns); the sales above is (3, 4). ndim is the number of dimensions, size the number of elements, and dtype the single data type all elements share. When you receive new data, ask for its shape and dtype first.

print(sales.shape, sales.ndim, sales.size)   # (3, 4) 2 12
print(sales.dtype)                           # int64

The default dtype of an integer array depends on the environment. On a 64-bit PC it is usually int64, but on this 32-bit virtual machine it comes out as int32.

One dtype per Array

An array stores only one data type. Mixing integers and floats gives float64, and mixing numbers and strings turns everything into strings. astype(np.float64) converts to floats.

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
print(prices.mean())                 # 14000.0
print(prices.astype(np.float64))     # [ 9000. 25000.  4000. 18000.]
print(np.array([9000, "event"]))     # ['9000' 'event']

Indexing and Slicing

Indexes and slices work just like with lists. prices[1:3] starts at 1 and stops before 3. The difference is that a slice is a view onto the same memory: changing the view changes the original too. When you need a real copy, use prices[1:3].copy().

import numpy as np

prices = np.array([9000, 25000, 4000, 18000])
view = prices[1:3]
view[0] = 9900
print(prices)   # [ 9000  9900  4000 18000]

2D Indexing: [row, column]

Write the row and column inside one pair of brackets, separated by a comma. sales[1, 2] is a single cell, and sales[:, 1] is one whole column. Both directions can be sliced: sales[:2, 1:3].

sales = np.array([r1, r2])
print(sales[1, 2])   # 315000
print(sales[:, 1])   # [150000 100000]

Choosing by Condition: Masks

A comparison returns a Boolean array, and using it as an index keeps only the elements that are True. To combine masks, use & and |, not and/or, and put parentheses around each comparison.

revenue = prices * counts
print(revenue[revenue >= 100000])   # [108000 180000 126000]
mask = (revenue >= 100000) & (revenue < 150000)
print(revenue[mask])                # [108000 126000]

Fancy Indexing

Passing a list of positions picks elements in the order you want, and the same position may be repeated. The result is a new array, not a view. We use this later to pair names with rankings.

print(prices[[3, 0]])      # [18000  9000]
print(prices[[0, 0, 1]])   # [ 9000  9000 25000]

Vectorized Math and Broadcasting

Operators are applied element by element. prices * 2 doubles every value, whereas * 2 on a list repeats the whole list. np.sqrt and np.round also apply to the whole array. NumPy computes by stretching a smaller shape to fit a larger one (broadcasting). A single number spreads over the whole array, so prices * 0.9 discounts every product. The trailing dimensions must be equal or 1.

print(prices * 2)                     # [18000 50000  8000 36000]
print(prices + 1000)                  # [10000 26000  5000 19000]
print(np.sqrt(np.array([1, 4, 9])))   # [1. 2. 3.]
print(prices * 0.9)                   # [ 8100. 22500.  3600. 16200.]
promo = np.array([1000, 2000, 500, 3000])
print(prices + promo)                 # [10000 27000  4500 21000]

Aggregation with axis

sum, mean, max and min fold an array into a single value. axis=0 computes each column from top to bottom, and axis=1 computes each row across. Check with the length of the result: 4 products, 3 stores.

sales = np.array([r1, r2, r3])
print(sales.sum(axis=0))   # [567000 325000 915000 540000]
print(sales.sum(axis=1))   # [1074000  784000  489000]
print(sales.sum())         # 2347000

reshape, Stacking, Sorting

reshape(4, 3) groups the same data into a new shape, for example splitting 12 months into four quarters. -1 means "whatever is left", and .T swaps rows and columns. The number of elements (size) cannot change. vstack joins arrays as new rows and hstack as new columns (a new store is vstack, a new period is hstack). sort returns the sorted values and argsort the sorted positions, so together with fancy indexing you can line up names in order. argsort(-x) ranks from largest to smallest.

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))            # [470 533 592 666]
print(monthly.reshape(2, -1).shape)   # (2, 6)

wonju = np.array([90000, 60000, 120000, 70000])
sales = np.array([r1, r2])
print(np.vstack([sales, wonju]).shape)   # (3, 4)
print(np.hstack([sales, sales]).shape)   # (2, 8)

revenue = np.array([108000, 75000, 180000, 126000])
names = np.array(["mug", "shirt", "stickers", "tumbler"])
print(names[np.argsort(revenue)])
# ['shirt' 'mug' 'tumbler' 'stickers']

import math는 math 모듈을 불러옵니다. 모듈 안의 이름은 점으로 꺼냅니다. math.sqrt(2)는 "math 모듈 안의 sqrt"라는 뜻입니다. 접두사를 붙여 쓰면 각 이름이 어디에서 왔는지 코드만 보고도 알 수 있습니다. Python은 처음 import한 모듈을 기억해(캐시) 두므로, 같은 모듈을 다시 import해도 다시 실행하지 않습니다.

from module import name

datetime: 날짜와 시각

date와 datetime

date는 연·월·일을, datetime은 거기에 시·분·초까지 담습니다. today()와 now()는 현재 시점을 알려 주고, 각 부분은 .year, .month, .day, .hour 같은 속성으로 읽습니다. 웹 실습의 가상 머신은 내 컴퓨터의 시계를 따라 오늘 날짜를 정하며, 터미널에서 date 명령으로 확인할 수 있습니다.

from datetime import date, datetime

today = date.today()
print(today)    # 2026-09-27 (example)
print(today.year, today.month, today.day)

now = datetime.now()
print(now.hour, now.minute)

날짜 서식: strftime

strftime은 날짜를 원하는 모양의 문자열로 바꿉니다. %Y, %m, %d는 연·월·일, %A는 요일의 전체 이름입니다. 보고서에 필요한 문자열을 정확히 만들 수 있습니다.

from datetime import date

today = date.today()
print(today.strftime("%Y-%m-%d"))       # 2026-09-27
print(today.strftime("%A, %d %B %Y"))   # Sunday, 27 September 2026 (example)

날짜 계산: timedelta

두 날짜를 빼면 일 단위의 timedelta가 나오고, .days로 정수 일수를 꺼냅니다. 날짜에 timedelta를 더하면 미래의 날짜가 됩니다. 일수가 음수이면 그 날짜가 이미 지났다는 뜻입니다.

from datetime import date, timedelta

print(today + timedelta(days=100))  # 2027-01-05

실수와 정수

random()은 0.0 이상 1.0 미만의 실수를, uniform(a, b)는 더 넓은 범위의 실수를 돌려줍니다. randint(a, b)는 양 끝을 모두 포함하는 정수를 고릅니다. 결과는 실행할 때마다 다릅니다.

import random

names = ["Ara", "Ben", "Cho", "Dan"]

print(names)                           # new order
print(random.sample(range(1, 46), 6))

재현성: seed

print(sales[:, 1])   # [150000 100000]

조건으로 고르기: 마스크

비교 연산은 불리언 배열을 돌려주고, 그것을 인덱스로 쓰면 True인 원소만 남습니다. 마스크를 결합할 때는 and/or가 아니라 &와 |를 쓰고, 비교마다 괄호를 씌워야 합니다.

revenue = prices * counts
print(revenue[revenue >= 100000])   # [108000 180000 126000]
mask = (revenue >= 100000) & (revenue < 150000)
print(revenue[mask])                # [108000 126000]

팬시 인덱싱

위치의 리스트를 넘기면 원하는 순서로 고를 수 있고, 같은 위치를 반복해도 됩니다. 결과는 뷰가 아닌 새 배열입니다. 뒤에서 이름과 순위를 짝지을 때 씁니다.

print(prices[[3, 0]])      # [18000  9000]
print(prices[[0, 0, 1]])   # [ 9000  9000 25000]

벡터화 연산과 브로드캐스팅

연산자는 원소별로 적용됩니다. prices * 2는 모든 값을 두 배로 만들지만, 리스트에 * 2를 하면 리스트 전체가 반복됩니다. np.sqrt, np.round도 배열 전체에 적용됩니다. NumPy는 작은 모양을 큰 모양에 맞게 늘려(브로드캐스팅) 계산합니다. 숫자 하나는 배열 전체에 퍼지므로 prices * 0.9는 모든 상품을 할인합니다. 끝쪽 차원이 같거나 1이어야 합니다.

print(prices * 2)                     # [18000 50000  8000 36000]
print(prices + 1000)                  # [10000 26000  5000 19000]
print(np.sqrt(np.array([1, 4, 9])))   # [1. 2. 3.]
print(prices * 0.9)                   # [ 8100. 22500.  3600. 16200.]
promo = np.array([1000, 2000, 500, 3000])
print(prices + promo)                 # [10000 27000  4500 21000]

axis로 집계하기

sum, mean, max, min은 배열을 하나의 값으로 접습니다. axis=0은 각 열을 위에서 아래로, axis=1은 각 행을 가로로 계산합니다. 결과 길이로 확인합니다: 상품 4개, 매장 3개.

sales = np.array([r1, r2, r3])
print(sales.sum(axis=0))   # [567000 325000 915000 540000]
print(sales.sum(axis=1))   # [1074000  784000  489000]
print(sales.sum())         # 2347000

reshape, 쌓기, 정렬

reshape(4, 3)은 같은 데이터를 새 모양으로 묶습니다. 12개월을 네 분기로 나누는 식입니다. -1은 "남는 만큼"이라는 뜻이고, .T는 행과 열을 바꿉니다. 원소 개수(size)는 바뀔 수 없습니다. vstack은 배열을 새 행으로, hstack은 새 열로 이어 붙입니다(새 매장은 vstack, 새 기간은 hstack). sort는 정렬된 값을, argsort는 정렬된 위치를 돌려주므로 팬시 인덱싱과 함께 이름을 순서대로 늘어놓을 수 있습니다. argsort(-x)는 큰 것부터 순위를 매깁니다.

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))            # [470 533 592 666]
print(monthly.reshape(2, -1).shape)   # (2, 6)

wonju = np.array([90000, 60000, 120000, 70000])
sales = np.array([r1, r2])
print(np.vstack([sales, wonju]).shape)   # (3, 4)
print(np.hstack([sales, sales]).shape)   # (2, 8)

revenue = np.array([108000, 75000, 180000, 126000])
names = np.array(["mug", "shirt", "stickers", "tumbler"])
print(names[np.argsort(revenue)])
# ['shirt' 'mug' 'tumbler' 'stickers']

따라 하기: 연간 보고서

12개월 매출(단위: 만 원)을 네 분기로 reshape하고, axis=1로 분기별 합계를 구하고, argmax로 최고 매출 달의 인덱스를, argsort(-monthly)[:3]로 상위 세 달을 찾습니다.

import numpy as np

monthly = np.array([150, 162, 158, 170, 175, 188,
                    190, 197, 205, 214, 220, 232])
quarter = monthly.reshape(4, 3)
print(quarter.sum(axis=1))               # [470 533 592 666]
print(monthly.sum(), monthly.argmax())   # 2261 11
print(np.argsort(-monthly)[:3])          # [11 10  9]

NumPy 다섯 줄 요약

  • ndarray: 여러 차원, 하나의 dtype.
  • 만들기: array, arange, zeros, linspace.
  • 고르기: 슬라이스, 마스크, 팬시 인덱싱.
  • 계산: 벡터화, 브로드캐스팅, axis.
  • 재배치: reshape, vstack, hstack, argsort.

흔한 실수

  • import를 빠뜨린 것이 NameError의 첫 번째 용의자입니다. 디버깅할 때는 맨 위의 import 줄부터 봅니다.
  • randint(1, 6)은 6을 포함하지만 range(1, 6)은 포함하지 않습니다.
  • shuffle(names)는 그 자리에서 섞고 None을 돌려줍니다.
  • print(*numbers)는 리스트를 풀어 따로따로 출력합니다.
  • NumPy 마스크는 괄호와 함께 &, |를 씁니다. and/or는 쓰지 않습니다.

확인 퀴즈와 제출

  1. math.sqrt의 점은 무엇을 잇는가? 모듈 math와 그 안의 함수 sqrt입니다.
  2. import하지 않은 이름을 쓰면 어떤 오류가 나는가? NameError입니다.
