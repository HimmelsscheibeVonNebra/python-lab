01 · Getting started with Python01 · Python 시작하기

Check the installed Python version and open the interactive shell (REPL).설치된 Python 버전을 확인하고 대화형 셸(REPL)을 열어 봅니다.

  1. python3 -V

    The Python version (python is the same command)Python 버전 (python도 같은 명령입니다)

  2. python3

    The interactive shell (REPL): type code after >>>대화형 셸(REPL). >>> 뒤에 코드를 입력합니다

  3. print("Hello, Python!")

    Run inside the REPL — the result is printed right awayREPL 안에서 실행 — 결과가 바로 출력됩니다

  4. [n * n for n in range(1, 11)]

    The value of an expression is shown even without print식의 값은 print 없이도 보입니다

    Leave the REPL (Ctrl+D works too)REPL 종료 (Ctrl+D도 됩니다)

# 리스트, 딕셔너리, 함수, 파일 입출력 예제: python3 grades.py
import csv
from statistics import mean
 
scores = {"민수": [88, 92, 79], "지영": [95, 90, 98], "현우": [72, 85, 80]}
 
 
def grade(avg):
    if avg >= 90:
        return "A"
    if avg >= 80:
        return "B"
    return "C"
 
 
with open("grades.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["이름", "평균", "학점"])
    for name, values in scores.items():
        avg = mean(values)
        writer.writerow([name, f"{avg:.1f}", grade(avg)])
        print(f"{name:4} 평균 {avg:5.1f}  학점 {grade(avg)}")
 
print("grades.csv 파일을 만들었습니다. cat grades.csv 로 확인하세요.")
