flask_hello ~/web/flask_hello

The smallest Flask app: two addresses (routes), each connected to one function, and a value read from the query string. Learn how to start a server and send it requests with the web command first.가장 작은 Flask 앱. 주소(라우트) 두 개가 각각 함수 하나에 연결되고, 쿼리 문자열로 값을 받는다. 서버를 띄우고 web 명령으로 요청을 보내는 방법을 먼저 익힌다.

Steps실행 순서

  1. web start app.py

    Start app.py as a background server (about 10 seconds). When it is ready, the app preview panel opens under the terminal with the first page. The preview panel plays the browser's role in this lab.app.py를 백그라운드 서버로 띄운다(10초 정도). 준비되면 터미널 아래에 앱 미리보기 창이 열리고 첫 화면이 보인다. 미리보기 창이 이 실습의 브라우저 역할을 한다.

  2. web get /

    Send a request to the address /. The HTML returned by home(), the function marked @app.get("/"), is shown as text. HTTP 200 means success.주소 /로 요청을 보낸다. @app.get("/")가 붙은 home()이 돌려준 HTML이 글자로 보인다. HTTP 200은 성공이라는 뜻이다.

  3. web show '/hello?name=Mina'

    web show puts an address in the preview panel; web get shows the same page as text in the terminal.web show는 주소를 미리보기 창에 띄운다. web get은 같은 화면을 터미널에 글자로 보여 준다.

  4. web get '/hello?name=Mina'

    name=Mina after the ? is the query string. hello() reads it with request.args.get("name") and builds Hello, Mina!. Typing /hello?name=Mina in the preview panel's address box and pressing Open does the same.? 뒤의 name=Mina가 쿼리 문자열이다. hello()가 request.args.get("name")으로 읽어 Hello, Mina!를 만든다. 미리보기 창의 주소 칸에 /hello?name=Mina를 넣고 열기를 눌러도 같다.

  5. web get /hello

    Without name, get() uses its default "world": Hello, world!name이 없으면 get()의 기본값 "world"를 쓴다: Hello, world!

  6. web html '/hello?name=<b>Mina</b>'

    web html shows the raw HTML. Thanks to escape(), <b> became &lt;b&gt;, so the tag you typed is shown as text instead of being run.web html은 HTML 원문을 보여 준다. escape() 덕분에 <b>가 &lt;b&gt;로 바뀌어, 입력한 태그가 실행되지 않고 글자로 표시된다.

  7. web get /nothing

    For an address that does not exist, Flask answers HTTP 404 (Not Found).없는 주소는 Flask가 HTTP 404(Not Found)로 답한다.

  8. web log

    The server log has one line per request with its address and status code (200, 404).서버 로그: 요청마다 주소와 상태 코드(200, 404)가 한 줄씩 남는다.

  9. web stop

    Stop the server. While it runs, saving a change to app.py is enough: web notices it, restarts the app by itself, and the preview panel redraws with the new code.서버를 끈다. 서버가 켜져 있는 동안 app.py를 고쳐 저장하면 web이 알아채고 앱을 저절로 다시 시작하며, 미리보기 창도 새 코드로 다시 그려진다.

"""The smallest Flask app: two routes.  Run: web start app.py"""
from flask import Flask, request
from markupsafe import escape
 
app = Flask(__name__)
 
 
@app.get("/")
def home():
    return "<h1>Hello, Flask!</h1><p>Try /hello?name=Mina</p>"
 
 
@app.get("/hello")
def hello():
    name = request.args.get("name", "world")
    # escape(): a name like <b>hi</b> is shown as text, not run as HTML
    return f"<p>Hello, {escape(name)}!</p>"
 
 
if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000)

"""Flask routes: input → analysis → escaped Jinja view."""
from pathlib import Path
from flask import Flask, render_template, request
from logic import MARKETS, analyze, summarize
from storage import load_quotes
 
BASE = Path(__file__).resolve().parent
app = Flask(__name__)
app.config['DATA_PATH'] = BASE / 'data/prices.csv'
 
@app.get('/')
def index():
    market = request.args.get('market', 'ALL')
    rows, summary, day, error, status = [], summarize([]), None, None, 200
    try:
        quotes = load_quotes(app.config['DATA_PATH'])
        rows = analyze(quotes, market)
        summary = summarize(rows)
        day = quotes[0]['date'] if quotes else None

"""SQLite connections are short-lived; imports commit as one transaction."""
import sqlite3
from pathlib import Path
from logic import FIELDS, analyze, parse_row
 
 
def import_snapshot(path, quotes):
    # Validate before deleting any existing rows, including calls outside Flask CLI.
    quotes = [parse_row({key: str(row[key]) for key in FIELDS}) for row in quotes]
    analyze(quotes, 'ALL')
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    connection = sqlite3.connect(path)
    try:
        with connection:
            connection.execute('''CREATE TABLE IF NOT EXISTS quotes (
                date TEXT NOT NULL, code TEXT PRIMARY KEY, name TEXT NOT NULL,
                market TEXT NOT NULL CHECK(market IN ('KOSPI','KOSDAQ')),
                previous_close INTEGER NOT NULL CHECK(previous_close > 0),
                close INTEGER NOT NULL CHECK(close > 0),
                volume INTEGER NOT NULL CHECK(volume >= 0))''')
            connection.execute('DELETE FROM quotes')
            connection.executemany(
                'INSERT INTO quotes VALUES (?, ?, ?, ?, ?, ?, ?)',
                [tuple(row[key] for key in FIELDS) for row in quotes])
    finally:
        connection.close()

    # mode=rw prevents an accidental empty database on a missing path.
    connection = sqlite3.connect(Path(path).resolve().as_uri() + '?mode=rw', uri=True)
    connection.row_factory = sqlite3.Row
    try:
        rows = connection.execute('SELECT * FROM quotes ORDER BY code').fetchall()
        return [parse_row({key: str(row[key]) for key in FIELDS}) for row in rows]
    finally:
        connection.close()

FIELDS = ["date", "code", "name", "market", "previous_close", "close", "volume"]
MARKETS = ("ALL", "KOSPI", "KOSDAQ")
 
 
def parse_row(row):
    """Return a typed quote; raise ValueError for any invalid field. No I/O."""
    if set(row) != set(FIELDS) or any(not isinstance(v, str) for v in row.values()):
        raise ValueError("each row needs exactly seven fields")
    quote = {key: value.strip() for key, value in row.items()}
    day = quote["date"]
    if date.fromisoformat(day).isoformat() != day:
        raise ValueError("date must be YYYY-MM-DD")
    code = quote["code"]
    if len(code) != 6 or not code.isascii() or not code.isdigit():
        raise ValueError("code must be six ASCII digits")
    if not quote["name"] or quote["market"] not in MARKETS[1:]:
        raise ValueError("name and KOSPI/KOSDAQ market are required")
    for field in ("previous_close", "close", "volume"):
        text = quote[field]
        if not text.isascii() or not text.isdigit():
            raise ValueError(f"{field} must be a whole number")
        quote[field] = int(text)
        minimum = 0 if field == "volume" else 1
        if quote[field] < minimum:
            raise ValueError(f"{field} must be >= {minimum}")
    return quote
 
 
def change_pct(previous_close, close):
    """Return unrounded daily percent change; both prices must be positive."""
    if previous_close <= 0 or close <= 0:
        raise ValueError("prices must be positive")
    return (close - previous_close) / previous_close * 100
 
 
def analyze(quotes, market):
    """Validate snapshot identity; filter and sort by change desc, then code asc.
 
    Return fresh quote dicts with change_pct. Empty input/selection returns [].
    Mixed dates, duplicate codes or an unknown market raise ValueError.
    quotes must already contain typed, validated values from parse_row().
    """
    if market not in MARKETS:
        raise ValueError("market must be ALL, KOSPI or KOSDAQ")
    if len({q["date"] for q in quotes}) > 1:
        raise ValueError("snapshot must contain one date")
    codes = [q["code"] for q in quotes]
    if len(set(codes)) != len(codes):
        raise ValueError("duplicate code in snapshot")
    rows = [dict(q, change_pct=change_pct(q["previous_close"], q["close"]))
            for q in quotes if market == "ALL" or q["market"] == market]
    return sorted(rows, key=lambda q: (-q["change_pct"], q["code"]))
 
 
def summarize(rows):
    """Return sample count, up/down/flat counts and equal-weight mean (or None)."""
    count = len(rows)
    return {"count": count,
            "up": sum(q["change_pct"] > 0 for q in rows),
            "down": sum(q["change_pct"] < 0 for q in rows),
            "flat": sum(q["change_pct"] == 0 for q in rows),
            "mean": sum(q["change_pct"] for q in rows) / count if count else None}

Extending the project into a Flask web appFlask 웹 앱으로 확장하기

The stock MVP from the 'Building a Project' chapter was a command-line program: it read a CSV (storage.py), validated and analyzed it (logic.py) and wrote an HTML report to a file (report.py). These examples move the same flow into a Flask web app. Instead of writing a report file, the app reads and analyzes the data each time a browser sends a request and builds the HTML on the spot. First learn how to start a server and send it requests with flask_hello, the smallest app with two routes; then sample2_korea, the closest to the lecture, then sample1_us with a different currency and code format, and finish with sample4_sqlite, which stores the data in SQLite. All numbers are fictional class data for 2026-11-05, not live prices.

The smallest Flask app

A Flask app is an app object made with Flask(__name__), with connections (routes) attached that say "when a request comes to this address, run this function". The string the function returns becomes the response HTML.

from flask import Flask, request
from markupsafe import escape

app = Flask(__name__)

@app.get("/")
def home():
    return "<h1>Hello, Flask!</h1><p>Try /hello?name=Mina</p>"

@app.get("/hello")
def hello():
    name = request.args.get("name", "world")
    return f"<p>Hello, {escape(name)}!</p>"
  • @app.get("/hello"): connects GET requests for the address /hello to hello().
  • request.args.get("name", "world"): reads the value from the ?name=Mina part of the address (the query string), with a default when it is missing.
  • escape(name): replaces special characters in a value the user sent before it goes into the HTML, so a tag they typed is not run.
  • For an address with no route, Flask answers 404 (Not Found).

The stock apps below have the same structure, except that they use a template file instead of building strings, and split the work across several files.

Project structure

All three projects are split into the same four parts. Each file does one job, so you can change the page or the way data is stored without touching the other files.

@app.get('/') connects GET requests for the address / to the function index(). The chosen market arrives in the query string after the address, ?market=KOSPI, and is read with request.args.get('market', 'ALL'). Without a value it defaults to ALL.

Note that error handling splits into two branches. When the input is wrong, such as an unknown market name or a bad CSV row, a ValueError is raised and the app answers 400 (Bad Request). When the problem is on the server side, such as an unreadable data file, it answers 500. Either way the program does not crash; it returns a page with the error message.

Calculation rules

The change is (close − previous close) / previous close × 100. The computed value is kept unrounded and shown with two decimal places only on screen. The mean is an equal-weight sample mean of the selected stocks, so it is not a market index return. A CSV with only a header is a valid empty sample and shows the mean as N/A, but a missing file is an error.

  • Korean stocks (sample2, sample4): prices are whole won and volumes whole shares. Codes such as 005930 are handled as strings to keep the leading 0. Means: ALL +0.40%, KOSPI +0.33%, KOSDAQ +0.50%.
  • US stocks (sample1): prices are stored as whole cents and converted to USD on screen (scale=100). The markets are NASDAQ/NYSE and codes are uppercase tickers. The ALL mean is +0.40%.

Jinja auto-escaping

Jinja, Flask's template engine, automatically replaces HTML special characters when it prints a value such as {{ row.name }}. So even if a stock name contains a tag like <script>, it is not executed but printed literally as &lt;script&gt;. That is why we don't write code that pastes data straight into the page ourselves.

Storing data in SQLite (sample4)

sample4 draws the page from an SQLite database instead of the CSV. Loading the data is not done by a web request but by a separate command, flask --app app init-db, registered with @app.cli.command('init-db').

python app.py

  • One transaction: the delete and the inserts are committed together inside with connection:, so if anything fails the previous data stays.
  • Read-only connection: read_quotes() opens the file with mode=ro. When the database file is missing it fails instead of creating an empty database, and the page tells you to run init-db first.

이 웹 실습에서 실행하기

실제 PC에서는 프로젝트마다 가상환경을 만들고 pip install -r requirements.txt로 Flask를 설치한 뒤 python app.py로 실행하고, 브라우저에서 http://127.0.0.1:5002 같은 주소를 엽니다. 이 웹 실습의 가상 머신에는 Flask가 이미 들어 있지만, 내 브라우저와 네트워크로 연결되어 있지 않아 브라우저로 서버에 접속할 수는 없습니다. 대신 실습용 도우미 명령 web을 씁니다. web start로 서버를 띄우면 터미널 아래에 앱 미리보기 창이 열립니다. 이 창이 브라우저 역할을 해서, 링크를 누르거나 폼에서 시장을 고르고 조회를 누르면 요청이 가상 머신 안의 서버로 전달되고 응답 화면이 다시 그려집니다. 창 위의 주소 칸에 /?market=KOSPI 같은 주소를 넣고 열기를 눌러도 됩니다. 서버를 끄면 창이 흐려집니다.

미리보기 창은 공유 폴더 /mnt/host/.web를 통해 요청과 응답을 파일로 주고받으므로, 요청 하나에 0.2~1초쯤 걸립니다. 앱의 CSS와 그림은 응답에 함께 넣어 보여 주고, 앱 페이지의 JavaScript는 실행하지 않습니다.

web start는 안에서 python3 app.py를 그대로 실행합니다. 다만 터미널이 하나뿐이라 서버를 백그라운드로 돌리고, 미리보기 창과 이어 주는 중계 프로그램을 함께 띄웁니다. 서버가 켜진 동안 nano app.py로 코드를 고쳐 저장하면 앱이 저절로 다시 시작되고 미리보기 창이 새 코드로 다시 그려집니다. 고친 코드에 오류가 있으면 미리보기 창에 오류 메시지가 나오고, 고쳐 저장하면 다시 살아납니다. Flask 패키지는 처음 쓸 때 한 번에 내려받으므로 첫 web start는 조금 더 걸립니다.

터미널에서 쓸 수 있는 명령은 다음과 같습니다.
